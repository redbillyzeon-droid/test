# 成人向け（R18）の場面の決まり（ロスト・アイランド）

2026-10-17、利用者の指示：「R18は全て同意のもとの設定と書いておいて」。

- 成人向けの場面は、**すべて、登場人物どうしの同意のもとで行われる**設定にする。
- 同意できない状態（眠っている、酔っている、幻や魔法や力で操られている、脅されている など）での成人向けの描写はしない。
- GM の「喪失の幻」は、失ったものを見せて誘うだけの力で、心や体を操る力ではない。誘いに乗るかどうかは、最後は本人が自分の意思で選ぶ。NTR エンドも、相棒が自分で GM の側を選んだうえでの場面にする。
- 登場人物は全員、成人として描く（見た目も中身も）。
- 台本では、成人向けの場面は位置だけを `［成人向け］` で示し、性的な描写の中身は書かない。
- 絵（NovelAI のプロンプト）も、この決まりに合わせる。

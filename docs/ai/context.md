# プロジェクトの前提（context）

最終更新：2026-10-05（Claude Code の環境設定時に作成）

## 目的

このリポジトリには、性質の違う案件が同居しています。

| 案件 | 内容 | 状態 |
|---|---|---|
| aialbum | 生成画像を埋め込みタグで検索・整理するローカルWebアプリ（Python 3.10 以上、FastAPI、SQLite） | 実装済み。テストあり（`tests/`） |
| ComfyUI V2V メモ | 自分で撮った動画から、実写風の動画を作る手順の調査（`HANDOFF.md`） | 調査メモ。方式A/Bは未決定 |
| ゲーム開発 | 無人島に転生した主人公と、人外の女性5人の物語。企画は `docs/game/plan.md` | 方針決定済み（ティラノビルダー、成人向け、14日構成、NTRは相棒と挑んで負けたときの展開。発売時はコノハの1つだけ）。キャラクターは `docs/game/characters.md`、骨組みは `docs/game/outline.md`、遊び方（探索育成型シミュレーション）は `docs/game/system.md`。台本はプロローグ〜1日目の初稿のみ |

## 利用者

- 主な利用者はリポジトリの持ち主本人。Windows の PC を使っている（`run.bat` があることから推測。OS の明言はない）。
- スマホの Claude アプリからも指示を出す。

## 参照すべき資料

- `README.md`：aialbum の機能、起動方法、検索の書き方、ファイルごとの役割、テスト方法。
- `HANDOFF.md`：ComfyUI の環境（RTX 5080 / VRAM 16GB / RAM 32GB、Stability Matrix）、推奨設定、商用ライセンスの調査メモ。
- `pyproject.toml`、`requirements.txt`、`requirements-dev.txt`：依存パッケージ。

## 確定事項

- aialbum のサーバーは `127.0.0.1` だけで待ち受け、画像を外部に送らない（README の記載）。
- aialbum の索引とサムネイルは既定で `~/.aialbum/` に保存される（リポジトリの外）。
- aialbum に削除機能はない。移動・コピーは実ファイルを動かす。

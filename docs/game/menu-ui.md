この文書は **見た目と配置だけ** を書く。何を出すか・いつ出すか・クリック数・条件と変数は `design/screens.md` が正本。食い違ったら screens.md に合わせる。

### 1-2. ボタンの大きさ

| 種類 | 大きさ（最小） | 形 |
|---|---|---|
| 大きなボタン（行動のボタン、「次の日へ」） | 高さ 64px、幅 280px 以上 | 白地、黒の線 4px、skewX −10度。Dela Gothic One 28〜30px |

- 押せる範囲は、見た目の枠より上下左右 4px 広くとる（斜めの形で、すみが押しにくいため）。

### 1-3. 欠けと継ぎ（喪失と再生の印）

評価役の指摘（日常の画面に、喪失と再生を感じさせる部品がない）への案。

- 白い札とカード（状態画面の行、まとめの欄、結果のカード）は、**右上の角を斜めに欠けさせる**（欠けの大きさは短い辺の約 15%）。会話画面の斜めの切り方と同じ向き。
- 何かが「つながった」ときだけ、その欠けに **金の継ぎ線**（太さ 3px の金の線。欠けの斜めの辺に沿って引く）を入れる。使う場所：
  - 状態画面：段階4以上の人の行。
  - 「全員と心を通わせるまで」の欄：全員が段階4以上になったとき。
  - 結果のカード：段階が上がったカード。
  - 1日のまとめ：その日に段階4・5になった人の行。
- 金は「取り戻したもの・つながったもの」だけに使う（`adv-ui.md` の色の決まり）。ふだんの飾りには使わない。
- ヒロインの顔の切り抜きは、まだ段階0〜1の間は少し彩度を落とし（−20%）、段階が上がるごとに元の色に近づける（案。段階2で −10%、段階3以上で 0%）。

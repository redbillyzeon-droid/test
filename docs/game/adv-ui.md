# 会話画面（日常パート）の設計

作成：2026-10-16　／　状態：案

利用者が見本の画像（市販ゲームの、日常パートの会話画面）を示し、「A. 2D で雰囲気を寄せる」に決めた（2026-10-16）。見本から取り入れるのは**画面の構成と雰囲気**だけで、絵・部品のデザインはこのゲーム用に作る。見本の画像はリポジトリに入れていない。

配置のモック：`outputs/adv_mock.png`（仮の図形だけで作ったもの）

## 3D ではなく 2D にする理由

- 見本の印象の多くは、大きな日付の表示、斜めにデザインされた会話の枠、顔の絵の見せ方から来ている。これらは 2D で作れる。
- 3D にすると、島とキャラクター全員の 3D モデルとアニメーションが必要になり、作る量が大きく増える。NovelAI では 3D は作れない。

## 画面の部品

| 場所 | 部品 | 中身 |
|---|---|---|
| 左上 | 日付と時間帯 | 「5日目」を大きく、少し傾けて表示。横に天気と時間帯（朝・昼・夜）。時間帯は色で分ける（案：朝＝水色、昼＝朱色、夜＝紺） |
| 右上 | 残り日数と次にやること | 「GM との勝負まで ○日」と、次にやるとよいことを1行（`system.md` の「迷わせない」） |
| 中央 | 背景と立ち絵 | 背景は NovelAI の絵。立ち絵は2人まで並べる |
| 左下 | 顔の絵（バストアップ） | 話している人物の胸から上を、斜めに切った枠で大きく出す。主人公が話すときは出さない（案） |
| 下 | 会話の枠 | 黒い、斜めに切った吹き出しの形。左に、話している人物へ向かう「しっぽ」 |
| 会話の枠の上 | 名前の札 | 白い札に黒い太字。少し傾ける |
| 右下 | 操作の案内 | 早送り、オート、ログ |

## フォント（2026-10-16）

利用者の希望：「もう少しおしゃれな感じに」。ゲームに同梱でき、商用でも使える **SIL Open Font License 1.1** の日本語フォントから、3つの組み合わせを作った。見比べた画像：`outputs/font_compare.png`。

| 組み合わせ | 見出し（日付、名前の札など） | 本文（会話の文） | 雰囲気 |
|---|---|---|---|
| A（試作の既定） | Dela Gothic One | Zen Kaku Gothic New | くっきり、スタイリッシュ。見本の雰囲気にいちばん近い |
| B | RocknRoll One | Zen Maru Gothic | 丸くて、やわらかい。ポップ |
| C | Kaisei Decol | Zen Kaku Gothic New | 和風で上品。妖怪や吸血鬼の雰囲気に合う |

- どれにするかは、**利用者の回答待ち**。
- フォントの取り方：`python game/tools/fetch_fonts.py`（google/fonts リポジトリから、ライセンス文 OFL.txt と一緒に取ってくる）。
- フォントのファイル（約18MB）は、採用が決まるまで Git の管理に入れない（`.gitignore`）。決まったら、使うものとライセンス文だけを管理に入れる。
- ゲームに同梱するときは、ライセンス文（OFL.txt）もゲームの中に入れる。

## 色と文字（案）

- 基本の色：黒（#111）と白。差し色に朱色（#e8502a）と金色（#f0c43a）。
- ヒロインごとに、名前の札の色を変えてもよい（例：コノハ＝橙、ノクティア＝深紅、カバネ＝白金、ハクレン＝白と黒、イグニア＝赤銅）。
- 文字は太めのゴシック体。会話の文は 24px 前後。

## 絵の数への影響

- 顔の絵（バストアップ）は、立ち絵の上半分を切り抜いて使う（新しく描かない）。立ち絵の表情差分がそのまま使える。
- そのため、`art/asset-list.md` の枚数は増えない。

## 試作（2026-10-16）

`game/tyrano-proto/` に作った。ティラノスクリプト Ver6.00 で動かし、自動テストが 15/15 合格した（`game/tyrano-proto/tools/check_adv.js`）。画面：`outputs/adv_in_engine.png`。

| ファイル | 中身 |
|---|---|
| `data/others/adv_ui/adv_ui.js` | 日付の表示、顔の絵、名前の札の色、早送り・オート・ログのボタン |
| `data/others/adv_ui/adv.css` | 見た目。フォントの組み合わせ A・B・C の切りかえもここ |
| `data/scenario/adv_test.ks` | 動作確認用のシナリオ（昼にコノハ、夜にノクティア） |
| `data/scenario/test_menu.ks` | 会話画面と戦闘画面のテストを選ぶメニュー |
| `data/bgimage/proto_*.png`、`data/fgimage/chara/proto/*.png` | 仮の背景と立ち絵（`game/tools/make_placeholders.py` で作ったもの） |

しくみ：

- 文字送り、ログ、オート、既読の早送りは、ティラノスクリプトの機能をそのまま使う。
- 名前の行（`#コノハ`）を書くと、名前の札が変わる。それを見張って、顔の絵と札の色を切りかえる。台本の書き方は、ふつうのティラノスクリプトと同じ。
- 日付と時間帯は `[adv_date day=5 slot="noon" weather="晴れ" next="..."]` で変える（`f.day`、`f.slot` などに入る）。
- 早送り・オート・ログのボタンは、ティラノスクリプトのクリックを受ける層より上、メニュー画面より下の層に置いた（最初は下に置いて、押しても反応しなかった。テストで見つけて直した）。

確かめていないこと：

- 早送りのボタン（既読の文だけを飛ばす動き）は、自動テストに入れていない。
- ティラノビルダーで動くか（PC で確かめる。`handoff-local-engine-check.md`）。

## ティラノスクリプトで作るときの考え（案、未確認）

- 会話の枠と名前の札は、画像（枠の絵）か CSS で作る。ティラノスクリプトのメッセージ枠の設定（`[position]` の枠画像、`[ptext]`）で置ける見込み。
- 日付と時間帯の表示は、ゲーム変数（`f.day`、`f.slot`）から JavaScript で書きかえる。
- 顔の絵は、ティラノスクリプトの「顔の表示」の機能（キャラクターの表情を、メッセージ枠に出す機能）が使えるか確かめる。
- どれも、PC で試すまで確かめられない。戦闘画面の試作（`game/tyrano-proto/`）と同じやり方で、試作を作れる。

# 素材の入手方法の候補

作成：2026-10-17　／　状態：案

- このゲームは、DLsite と FANZA で売る商用の成人向け作品（`../plan.md`）。素材は、その使い方が規約で認められているものだけを使う。
- この文書を書いた担当は、Web の規約を読んでいない。**ここに挙げたサイトやサービスの名前は、候補の例であり、規約はすべて未確認**。使えるかどうかは、下のチェック表で1つずつ確かめる。
- 規約は変わることがある。確かめた日付と、確かめたときの規約の写し（スクリーンショットや PDF）を残す。
- 素材の購入、ダウンロード、生成、サービスへの登録は、主担当が利用者の承認を得てから行う。

## 入手方法の比べ方

| 方法 | 良い点 | 気をつける点 |
|---|---|---|
| A. 商用利用できるフリー素材のサイト | お金がかからない。数が多く、すぐに試聴できる | 成人向け作品での利用を禁止・制限しているサイトや作者がある可能性がある。サイトによっては、作者ごとに規約が違う場合がある。クレジット表記が必要なことが多い。ほかの作品でも使われている曲なので、印象がかぶる。編曲違い（BGM-02・03・06・08）を揃えにくい |
| B. 有料の素材集（買い切り・ロイヤリティフリー） | 規約がはっきりしているものが多い。音質や数が揃っている。同じ作者の曲で、ゲーム全体の雰囲気をそろえやすい | お金がかかる。「1作品ごとのライセンス」「ゲームへの同梱は別料金」などの条件がある場合がある。月額制のサービスは、解約したあとも使い続けてよいかを確かめる |
| C. 作曲・効果音制作の依頼 | このゲームだけの曲になる。編曲違いや、旋律をそろえたタイトル曲を作れる。ループの位置も指定できる | お金と時間がかかる。成人向け作品であることを最初に伝える。権利（著作権の譲渡か、利用の許可か）、クレジット、作曲者の実績への掲載、修正の回数を、契約で決める |
| D. 音の生成サービス（AI で作曲・効果音を作る） | 早い。何度でも作り直せる。足りない効果音を埋めやすい | サービスの規約で、商用利用、成人向け作品での利用、権利が誰のものになるかが、有料プランかどうかで変わる場合がある。生成した音が、既存の曲に似てしまう危険がある。DLsite・FANZA で「AI 生成」の表示が必要かを確かめる（絵と同じく要確認。`../plan.md` の「売る前に確かめること」） |
| E. 自分で作る・録る | 権利の心配が少ない。短い効果音（決定音、足音、拍手など）は作りやすい | 手間と道具が要る。録音の環境で音質が決まる。音源ソフトや楽器の音色にもライセンスがある |

組み合わせの案：

- 曲（BGM）は、雰囲気をそろえたいので、B（1つの素材集）か C（依頼）を中心にする。予算がなければ A。
- 効果音は数が多いので、A と B を中心にして、足りないものを D か E で埋める。
- BGM-07 を加工して BGM-08 を作る、SE-03 から SE-04 を作る、などの加工をするなら、その素材は「改変してよい」ものに限る。

## 候補の例（すべて要確認）

名前は、担当が知っている例を挙げただけ。規約の中身、成人向け作品で使えるか、料金は、どれも確かめていない。

| 方法 | 名前（例） | 状態 |
|---|---|---|
| A. フリー素材（BGM） | 魔王魂、DOVA-SYNDROME、甘茶の音楽工房、MusMus | 要確認（規約は未確認） |
| A. フリー素材（効果音） | 効果音ラボ、OtoLogic、ポケットサウンド、On-Jin ～音人～ | 要確認（規約は未確認） |
| B. 有料の素材 | Audiostock、BOOTH で売られている音の素材集、Unity Asset Store の音の素材 | 要確認（規約は未確認） |
| C. 依頼 | ココナラ、SKIMA などの依頼サイト、作曲者への直接の依頼 | 要確認（規約は未確認。依頼サイト自体の規約と、作曲者との取り決めの両方を確かめる） |
| D. 生成サービス | Suno、Stable Audio、ElevenLabs（効果音の生成） | 要確認（規約は未確認） |

使うと決めたら、`../credits.md` の「音楽・効果音」に、次を書く（書き方は既存のフォントの表に合わせる）：

- 素材の名前（曲名・音の名前）と、この一覧の ID（BGM-01 など）
- 作者
- 入手元（サイト名、URL）
- ライセンス（規約の名前、確かめた日付）
- クレジットの書き方（規約が指定する書き方）

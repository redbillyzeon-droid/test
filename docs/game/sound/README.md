## 決まり（案）

### 流し方

- 台本の `【BGM：……】` は「ここから、この曲に切りかえる」という意味。次の指示まで、同じ曲が続く。
- 場面が変わっても指示がなければ、曲は変えない。場面ごとにはっきりさせたいときは、シナリオ担当に指示を足してもらう。
- 同じ曲の指示が続いたときは、曲を最初から流し直さない。
- `【BGM：なし】` は「曲を止める」。止めるときは、1〜2秒でフェードアウトする（案）。
- 曲を切りかえるときは、前の曲を1〜2秒でフェードアウトしてから、次の曲を始める（案）。
- 環境音（SE-01、SE-06、SE-11、SE-26、SE-27）は、BGM と重ねて流せるようにする。場面が変わったら止める。
- 心臓の音（SE-03、SE-04）は、次の `【効果音：……】` か、場面が変わるまで鳴らす（案）。

### ループ

- BGM は、BGM-18（スタッフロール）を除いて、すべてループする。
- ループする曲は、終わりから最初へ、つなぎめが分からないように戻るものを選ぶ。
- ティラノスクリプトで、曲の途中の決まった位置からループさせる（イントロをとばす）ことができるかは、要確認。できない場合は、曲の最初から最後まで、そのままループできる素材を選ぶか、ループ用に加工する（改変してよい素材のときだけ）。
- 環境音もループする。数十秒のものを、つなぎめが分からないように加工して使う。

### 音量の目安

- すべての音のファイルを、だいたい同じ大きさに揃えてから入れる（素材ごとの音量の差をなくす）。
- 目安の関係：会話のじゃまにならないように、BGM は控えめ。効果音は BGM より少しはっきり聞こえる大きさ。環境音は BGM より小さめ。
- 心臓の音（SE-03、SE-04）と BGM-11 が重なる場面（`06_day14_battle.md` の後半）は、心臓の音がはっきり聞こえる大きさにする。
- 具体的な数値（ティラノスクリプトの音量の設定など）は、試作で聞いて決める（未定）。
- 設定画面で、BGM と効果音の音量を別々に変えられるようにする（案。ティラノスクリプトでの作り方は要確認）。

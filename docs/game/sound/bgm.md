# BGM の一覧

作成：2026-10-17　／　状態：案

- 台本（`docs/game/script/`）の `【BGM：……】` をすべて拾い、同じ意味の指示を1つの曲にまとめた。
- 台本に指示はないが、画面のしくみ（`system.md`、`adv-ui.md`、`battle-ui.md`）から曲が必要な画面も入れた（BGM-13〜18）。
- 行番号は 2026-10-17 時点のもの。台本が直されると、ずれる。
- 一覧の見方と、曲の流し方の決まりは `README.md`。素材の入手方法は `sources.md`。
- テンポ・楽器・長さは、素材を選ぶときの目安（案）。決まったものではない。

## BGM-01 明るい日常の曲

- 使う場面（台本の指示）：
  - `00_prologue_day1.md` 226行目：1日目の昼、森の広場でカバネと出会う（ハクレンとの出会いまで続く）
  - `01_day2_tutorial.md` 20行目：2日目の朝、遊び方の説明
  - `endings/true.md` 91行目：真エンドの後日談
- 指示はないが使う場面（案）：朝・昼の自由行動、日常の会話（`daily/`）、個別イベントの段階1・2（`README.md` の「時間帯の既定の曲」）
- 雰囲気：明るい南の島。のんびりして楽しい。
- テンポ・楽器の案：ふつう〜少し速め（BPM 100〜120 くらい）。ウクレレ、アコースティックギター、マリンバ、軽い打楽器、口笛。
- 長さの目安：1分30秒〜2分30秒
- ループ：する
- 台本での表記：`【BGM：明るい日常の曲】`
- 気をつけること：いちばん長く流れる曲になる。何度聞いても疲れない、音の少なめの曲がよい。

- 使う場面（15か所）：
  - `03_day8_midpoint.md` 108行目：8日目、主人公の幻（前の世界の墓地、泣いているミサキ）
  - `04_day12_feast.md` 73行目：12日目、宴の笑い声が途切れる「聞けないこと」

  - `events/noctia_4-5.md` 16行目、`events/kabane_4-5.md` 17行目、`events/ignia_4-5.md` 17行目：段階4
  - `endings/_common_win.md` 12行目：個別エンドの「勝利のあと」
  - `endings/true.md` 13行目：真エンドの「勝利のあと」
  - `endings/ntr_konoha.md` 95行目：NTR エンドの最後、一人の浜辺

- テンポ・楽器の案：ゆっくり（BPM 60〜75 くらい）。ピアノだけ、またはピアノと弦。
- 長さの目安：2分〜3分
- ループ：する
- 台本での表記：`【BGM：静かな曲】`
- 気をつけること：1つの曲で、打ち明け話、GM の幻、作戦会議、勝ったあと、NTR エンドの最後まで受け持つ。雰囲気の幅が広いので、悲しすぎず、明るすぎない曲を選ぶ。分けるかどうかは報告の「利用者の判断が必要なこと」。

## BGM-08 静かな曲（ゆがんだ版）

- 使う場面：`endings/utsu.md` 83行目：鬱エンドの最後。島が「前と同じ」に戻り、みんなの目に光がない
- 雰囲気：BGM-07 と同じ曲なのに、どこかおかしい。音程が揺れる、テープが伸びたような音。
- テンポ・楽器の案：BGM-07 を加工する（ピッチを少し下げる、揺らす、雑音を足す）。
- 長さの目安：BGM-07 と同じ
- ループ：する
- 台本での表記：`【BGM：静かな曲（ゆがんだ版）】`
- 気をつけること：BGM-07 を加工して作るなら、BGM-07 の素材が「改変してよい」ものである必要がある（`sources.md` のチェック表）。

## BGM-13 タイトルの曲（台本に指示なし）

## BGM-18 スタッフロールの曲（台本に指示なし）

- 使う場面：`【スタッフロール】`（`endings/true.md`、`endings/noctia.md`、`endings/konoha.md`、`endings/kabane.md`、`endings/hakuren.md`、`endings/ignia.md`）、`【スタッフロール（短い版）】`（`endings/utsu.md`、`endings/ntr_konoha.md`）

- テンポ・楽器の案：ゆっくり〜ふつう。ピアノと弦。歌のない曲。
- 長さの目安：スタッフロールの長さに合わせる（2分〜4分。スタッフロールの長さは未定）
- ループ：しない（曲の終わりで、スタッフロールも終わるように合わせる）
- 気をつけること：鬱エンドと NTR エンドの「短い版」で同じ曲を使うかは、決めていない（案：BGM-08 か BGM-07、または無音）。

# 効果音（SE）の一覧

作成：2026-10-17　／　状態：案

- 台本（`docs/game/script/`）の `【効果音：……】` をすべて拾い、同じ意味の指示を1つの音にまとめた（SE-01〜18）。
- 台本に指示はないが、場面に合う音（SE-19〜30）、画面の操作の音（SE-31〜37）、戦闘の音（SE-38〜47）も、案として入れた。
- ずっと鳴り続ける環境音（雨、波、嵐、焚き火）も、ここに入れた。ループするものは「ループ」の欄に書いた。
- 行番号は 2026-10-17 時点のもの。長さは目安（案）。
- 一覧の見方と決まりは `README.md`。

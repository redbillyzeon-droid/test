## 1. いまの数字では届かない理由

### 1-1. 自由行動の回数（台本から数えた）

`design/battle.md` の 1-3 では33回としていたが、台本で固定の場面に置きかわる時間帯を引くと **28回** になる。

| 日 | 自由行動 | 理由 |
|---|---|---|
| 2日目 | 昼・夜（2） | 朝は決まった探索（浜辺、コノハ +3）。`01_day2_tutorial.md` |
| 3日目 | 3 | |
| 4日目 | 夜（1） | 朝と昼は嵐の場面。`02_day4_storm.md` |
| 5〜7日目 | 9 | |
| 8日目 | 朝・昼（2） | 夜は中間発表。`03_day8_midpoint.md` |
| 9〜11日目 | 9 | |
| 12日目 | 朝・昼（2） | 夜は宴。`04_day12_feast.md` |
| 合計 | **28** | 朝9回、昼10回、夜9回 |

- ハクレンに会えるのは朝だけなので **9回**。ノクティアは夜だけなので **9回**（雨の日の昼は数に入れない。雨の日がどれだけあるかは決まっていない）。
- 12日目の宴の +3（5人）は、そのあとに自由行動がないので、段階4のイベントには間に合わない（13日目の相棒の決め方の「好感度がいちばん高い人」にだけ効く）。

### 1-2. いまの数字での計算

段階4（`f.ev_<名前>` が4以上。`05_day13_gm.md`）にするには、段階1〜4のイベントを見る「過ごす」が、1人4回、5人で **20回** 要る。28回のうち20回は、イベントを見る回で決まってしまう。

いまの決まりでは、イベントは「選んだときに、すでに段階の値に届いている」ときに起きる。そのため、段階の値を越える回はふつうの会話になり、イベントは次の回になる。1人あたりの回数は次のくらい（コノハの例。会話は平均 +5.5、イベントは良いほうの選択）。

| 回 | 中身 | 好感度 |
|---|---|---|
| 固定の場面 | 1日目 +2、2日目 +3、嵐 +7 | 12 |
| 1 | 段階1（+4） | 16 |
| 2〜4 | 会話 ×3 | 32 |
| 5 | 段階2（+5） | 37 |
| 6・7 | 会話 ×2 | 50 |
| 8 | 段階3（+6） | 56 |
| 9〜11 | 会話 ×3 | 72 |
| 12 | 段階4 | — |

1人12回前後、5人で約55回。28回の倍ちかくになる。いちばん固定の場面が多いコノハでこの回数なので、ハクレン・イグニア・ノクティアはもっと多い。

## 2. 新しい決まり（しくみの側だけで直す）

台本の数字（日常の会話の +5〜8、イベントの中の選択の値、固定の場面の値）は変えない。段階の境目も変えない。足すのは次の5つ。

| # | 決まり | 中身（数字は目安） |
|---|---|---|
| A | 段階のイベントの回の数え方 | 「過ごす」を選んだとき、いまの好感度に **+5（会えた分）** を足して段階の値に届き、その段階をまだ見ていなければ、会話の代わりに段階のイベントを出す。その回は「+5 ＋ 段階ボーナス ＋ イベントの中の選択の値」が上がる。届かなければ、いつもどおり会話を出す（会話の値だけ上がる）。段階4は段階3を見たあと、段階5は9日目以降（台本どおり） |
| B | 段階ボーナス | 段階1・2・3のイベントを見ると、しくみで **+8**（「心が近づいた」）。段階4・5にはない |
| C | みんなと過ごす | 「ヒロインと過ごす」の中に足す。その時間帯に会える全員（2〜3人。雨の日の昼はノクティアも出て4人）が **+3**。かまどがあれば **+4**（みんなでごはん）。段階のイベントは起きない（イベントは二人きりの場面のため）。結果は短い文（2〜4行）と結果のカード |
| D | 探索に誘う | 誘ったヒロイン **+3**（「探索で出会う」と同じ。「過ごす」の +5〜8 より少ない）。段階のイベントは起きない。誘っている回は、そのヒロインの「出会い」の結果を出さない（引いたら引き直す。`plan.md`） |
| E | 鍛える | 「ハクレンと稽古」（朝）でハクレン **+3**。「ノクティアと薬の勉強」（夜）でノクティア **+3**。稽古でもハクレンの段階のイベントが起きる（台本どおり）。そのときは A のとおりに数え、力 +1 と稽古の回数 +1 もそのまま足す |

いまのまま残すもの：好物を渡す +10、探索で出会う +3、施設を一緒に建てる +3、固定の場面の値。

### 2-1. 決まりごとの理由

- A：イベントを見る回も「会えた回」として数える。段階の値を越える回と、イベントの回が同じになり、1人あたり4回ぶんの行動が浮く。イベントを見たあとの好感度は、必ず段階の値以上になる（+5 を足した値で判定するため）。
- B：段階の境目は20ずつ。A だけでは、イベントとイベントの間に会話が2〜3回要る。+8 を足すと、間の会話が0〜1回になる。段階4・5に付けないのは、段階5に届く人数を1〜2人に抑えるため（4章）。
- C：ハクレン（朝だけ）とノクティア（夜だけ）は、二人きりの回だけでは間の分が足りない。同じ時間帯の人とまとめて上げられるようにする。二人きりより1人あたりは少ない（+3）。
- D・E：探索や稽古を選んでも、好感度が少し進むようにする。真エンドを狙うときも、探索・稽古を少し混ぜられる。

## 4. 計算：段階5に届く人数

段階5の条件：段階4を見たあと、9日目以降、判定（好感度 +5）が90以上（台本の条件と A）。段階4のあとはボーナス B がないので、段階4を見たときの好感度（だいたい78〜87）から、会話1〜2回か、みんなと過ごす2〜3回が要る。

| 遊び方 | 段階5 | 計算 |
|---|---|---|
| 真エンドの計画（3章） | 2人（コノハ、カバネ）まで | 空き2回を、2人の段階5に使う場合 |
| 1人にしぼる | 1人（9日目以降すぐ） | 二人きり5〜6回で段階4、そのあと1〜2回 |
| 2人にしぼる | 2人 | 1人あたり二人きり約7回 × 2 ＝ 14回 ＋ 間をうめる分 |
| 3人にしぼる | 3人も届く見込み | 1人あたり約7回 × 3 ＝ 21回。段階5は9日目以降の11回のうちに3回入れる必要があり、ハクレン・ノクティアを含むと時間帯が足りなくなりやすい。届くかは時間帯の組み合わせしだい（細かく計算していない） |
| 4人以上 | 届かない見込み | 1人あたり約7回 × 4 ＝ 28回で、全部の回を使っても足りない（建てる・固定の場面のずれ・間をうめる分が入らない） |

「段階5は1〜2人が目安」は、ふつうの遊び方では合う。3人は、しぼって計画すれば届く可能性がある。

2026-10-17 プロデューサー決定：**段階5に3人届く遊び方は止めない**（計画した人へのごほうびとして許す）。そのため、段階4のあとの上がり方を制限するしくみは足さない。

### 6-2. プログラム（.ks）

- 「過ごす」：会話を1つ選ぶ前に、好感度 +5 で段階の判定をする（A）。届けば、イベントへ。イベントのあと、+5 と段階ボーナス（段階1〜3：+8）を足す。
- カバネの嵐の夜の会話：段階のイベントが起きる回は出さない。段階のイベントが起きない最初の「カバネと過ごす」（5日目以降）で、会話の代わりに出す（2026-10-17 決定）。
- 次に会うとイベントになるヒロインに、印を出す（例：ハートの印）。「みんなと過ごす」ではイベントが起きないことを、プレイヤーが分かるようにするため。印の条件・棒の計算・締め切りの警告は `design/screens.md`（2026-10-17、案）。
- 「みんなと過ごす」：その時間帯に会える全員に +3（`f.built_stove` が1なら +4）。
- 探索の誘い：`f.explore_partner` のヒロインに +3。その回は、そのヒロインの出会いの結果を引き直す。
- 稽古：ハクレン +3。薬の勉強：ノクティア +3。

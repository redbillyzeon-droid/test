# キャラクター設定

作成：2026-10-05　／　状態：案（おすすめで決定。直したいところがあれば変えます）

登場するヒロインは全員、見た目も中身も成人の女性です。人外なので実年齢は人間とちがいます。

**共通のテーマ：全員が「何かを失った者」**。ゲームマスター（GM）は、大きなものを失った者だけを選んで、この島に集めています。GM は「勝てば、失ったものを一つ取り戻せる」と約束し、その約束で一人ひとりを揺さぶります。

## 主人公

| 項目 | 内容 |
|---|---|
| 名前 | ユウ（初期値。プレイヤーが変えられる） |
| 年齢 | 25歳 |
| 前の世界 | 会社員。終電帰りの毎日。付き合って5年、同棲して2年の恋人ミサキの誕生日に、会社に泊まる予定を切り上げ、指輪を持って帰ると、ミサキが会社の先輩と浮気している場面に出くわす。そのショックで心臓が止まって死ぬ |
| 失ったもの | 恋人ミサキと、5年間の付き合いと2年の同棲生活。「信じていた日々」そのもの |
| GM の誘い | 「勝てば、あの夜より前に戻してやる。ミサキとやり直せる」 |
| 心の傷 | 「大事な人は、自分の見ていないところで奪われる」。島での暮らしで、5人に大事にされることを少しずつ受け入れていく。NTRルートでは、この傷がもう一度えぐられる |
| 性格 | お人よしで、頼まれると断れない。仕事を優先して、身近な人を後回しにしがちだった。体力も特別な力もない |
| 島での強み | 前の世界の知識（火の起こし方、ろ過、簡単な建築）。5人にとっては「人間」が珍しい |
| 一人称 | 俺 |

## ゲームマスター（GM）：黒瀬カイ

最初の企画にあった「最後に出てくる転生者」です。「ゲームマスターと対決する」という利用者の指示に合わせて、同じ人物にしました。下の表は、指示にない部分（過去、力、経緯など）はすべて案です。12日目までは姿を見せず、声と島の石碑の文字だけで現れます。13日目に、主人公と同じ転生者だと分かります。

| 項目 | 内容 |
|---|---|
| 見た目 | 30歳くらい。整った顔だが、目に光がない。白いコート。12日目までは、仮面をつけた影としてだけ現れる |
| 前の世界 | 仕事の成果、婚約者、家族からの信頼を、親友にすべて奪われた。婚約者は親友と結婚した。最後は自分から命を絶った |
| 失ったもの | すべて。主人公と同じ形の裏切りを経験している |
| 経緯 | 主人公より何十年も前に、この島に流れ着いた最初の転生者。神から「奪う力」を授かり、イグニアから島を奪った。それ以来、失った者を集めて「ゲーム」を続けている |
| ゲームのルール | 「14日目に、私と勝負しろ。勝てば、失ったものを一つ取り戻せる。負ければ、残っているものもすべていただく」 |
| 力 | 「喪失の幻」：相手が失ったものの幻を見せて、心を揺さぶる。幻にかかった相手は GM に逆らえなくなり、決戦では主人公を支援しなくなる。好感度が高いヒロインには効かない |
| 考え方 | 「失った者は、目の前の絆より、失ったものを選ぶ。人は必ず裏切る」。それを証明するために、ゲームを繰り返している |
| 主人公を選んだ理由 | 自分と同じ裏切られ方をした男だから。「お前も、最後には仲間より、あの女を選ぶ」 |
| 決戦 | ヒロインに「失ったもの」の幻を見せて寝返らせようとする。主人公には、ミサキと先輩のあの夜の場面を見せる |
| 結末 | 真エンド：主人公が「取り戻す」より「いまある絆」を選んだことで、GM の考えが崩れる。島はイグニアに返され、GM は島を去る（島に残る男性は主人公だけ）。鬱エンド：主人公はあの夜の幻に閉じこめられ、5人は GM のゲームの駒になる。NTRエンド：コノハを奪われ、主人公は島の外れでひとりになる |

## 前の世界の人物（冒頭のフック）

プロローグで、プレイヤーの気持ちをつかむための人物です。島に来たあとも、GM の幻として何度か現れます。

| 人物 | 内容 |
|---|---|
| ミサキ | 主人公の恋人。付き合って5年、同棲して2年。明るくて、さびしがり。仕事で帰りの遅い主人公に、さびしさをぶつけられずにいた。誕生日や記念日の約束を、主人公の仕事のせいで何度も破られている |
| 先輩（佐久間） | 主人公の会社の先輩。「いい靴は男の名刺だ」が口ぐせ。主人公に仕事を押しつけ、その間にミサキに近づいた |

ミサキが本当はどう思っていたかは、物語の途中で少しずつ見えてくるようにする（8日目の幻、決戦、真エンド）。答えをはっきり出すかどうかは、台本の段階で決める。

# 制作の役割分担

作成：2026-10-17（利用者の指示「ゲームを制作するので役割を分けておきたい。シナリオ、デザインなど」）。同じ日に、音楽・効果音の担当を足した（利用者の指示）。

AI のエージェントは、役割ごとに分けて使う。Claude Code では、それぞれがサブエージェントとして `.claude/agents/` に定義してある。ほかのツールで作業するときも、この表の担当範囲を守る。

## 役割

| 役割 | 担当 | 書いてよい場所 | 使える道具 |
|---|---|---|---|
| プロデューサー（まとめ役） | メインのセッション | すべて（利用者の承認の範囲で） | すべて |
| シナリオ担当 | `game-scenario` | `docs/game/script/` | 読む・書く（コマンドは使わない） |
| ゲームデザイン担当 | `game-design` | `docs/game/system.md`、`docs/game/design/`、`battle-ui.md` のしくみの部分 | 読む・書く（コマンドは使わない） |
| アート・画面デザイン担当 | `game-art` | `docs/game/art/`、`adv-ui.md`・`battle-ui.md` の見た目の部分、`outputs/` のモック、`docs/game/credits.md` のフォントと絵の部分 | 読む・書く（コマンドは使わない。画像の生成はプロデューサーが行う） |
| 音楽・効果音担当 | `game-sound` | `docs/game/sound/`、`docs/game/credits.md` の音の部分 | 読む・書く（コマンドは使わない。素材の購入・ダウンロード・生成はプロデューサーが行う） |
| プログラム担当 | `game-programmer` | `game/` | 読む・書く・コマンド（テストの実行など） |
| 確認役 | `project-reviewer` | なし（読むだけ） | 読むだけ |
| 評価役（ゲーム全体） | `game-director-review` | なし（読むだけ） | 読むだけ |

- 成人向けの場面は、すべて同意のもとで行われる設定（`.claude/rules/game-adult-content.md`）。どの担当も、この決まりに従う。
- 設定の正本（`docs/game/plan.md`、`characters.md`、`outline.md`）を直すのは、プロデューサー。担当は、直したほうがよい点を提案する。
- commit と push、公開、外部への送信、ファイルの削除と移動は、プロデューサーだけが行う（利用者の承認の範囲で）。

- 評価役は、全部が組み上がったとき（または区切りの版ができたとき）に、遊びの手ざわりと、暮らし・絆・戦闘・物語のつながりを点数で評価する。物差しは、桜井政博さんと橋野桂さんが公に語ってきた考え方や手がけた作品の特徴を要約したもので、本人の意見ではない（2026-10-17、利用者の指示「全てが組み上がった時に評価ができる人格を実在するゲーム監督から作成」、選択「二人を組み合わせる」）。本人になりきらせない、発言を引用させない。

## 仕事の流れ

```
利用者の依頼
  → プロデューサー：対象と完成条件を決めて、担当に頼む
  → 担当：書く・作る（担当の場所だけ）
  → プロデューサー：テストを実行する（プログラムのとき）
  → 確認役：設定・前の資料との食い違い、誤り、依頼外の変更を探す
  → プロデューサー：指摘を直す（または担当に直してもらう）→ commit・push → 利用者に報告
```

- 担当どうしは、直接やりとりしない（サブエージェントは、ほかのサブエージェントを呼べない）。受け渡しは、プロデューサーが行う。
- 1つの依頼で複数の担当が関わるとき（例：新しい場面＝シナリオ＋絵の一覧＋音＋実装）は、シナリオ → アート・音楽 → プログラムの順にする。

## 頼むときの書き方（例）

- シナリオ担当へ：「`docs/game/script/daily/` に、雨の日だけ出るコノハの会話を2本足して。条件は README の決まりに合わせて」
- ゲームデザイン担当へ：「12日間で、1人を段階5まで上げられるか、`system.md` の数字で計算して。足りなければ調整案を出して」
- アート担当へ：「13日目の GM の立ち絵4種のプロンプトを `nai-prompts.md` に足して」
- 音楽・効果音担当へ：「台本の【BGM】と【効果音】の指示を全部拾って、`docs/game/sound/` に一覧を作って。素材の候補も、ライセンスを確かめて挙げて」
- プログラム担当へ：「`02_day4_storm.md` を `.ks` にして、試作に入れて。`check_adv.js` で確かめて」

## 確かめていないこと

- 担当のサブエージェントは、このセッションの途中で作った。シナリオ・ゲームデザイン・アート・プログラムの4つは、このセッションでも呼び出せる一覧に出たことを確かめた（まだ呼び出してはいない）。音楽・効果音担当（2026-10-17 に追加）は、まだ一覧に出るか確かめていない。新しいセッションで `/agents` を開くと、一覧に出るはず（未確認）。

作成：2026-10-05　／　状態：方針決定済み（2026-10-05）。キャラクターは `docs/game/characters.md`、シナリオの骨組みは `docs/game/outline.md`。

| 種族 | 指定 |
|---|---|
| 吸血鬼 | セクシー系 |
| 獣人 | 狐、元気な子 |
| 妖怪 | ガシャドクロ、ギャル、タトゥーあり |
| 四神 | 白虎 |

- 転生して、無人島で暮らす。
- NTRエンドがある。

- 最後に転生者が出てきて、バトルになる。勝てば真エンド、負ければ鬱エンド。

## 仮タイトル

『漂着転生 ～失った者たちの島～』（仮）

## あらすじ（案）

恋人ミサキの誕生日。主人公は指輪を持って早く帰り、ミサキと会社の先輩の浮気を目撃する。そのショックで、心臓が止まって死ぬ。

目を覚ますと、見知らぬ無人島の浜辺にいた。そこにいたのは、人ではない5人の女性。吸血鬼、狐の獣人、ガシャドクロ、白虎、ドラゴン。5人とも、前の世界で大きなものを失っていた。

その夜、浜の石碑に文字が浮かぶ。島の「ゲームマスター」からの知らせだった。「十四日目の夜明け、私と勝負してもらう。勝てば、失ったものを一つ取り戻せる。負ければ、残っているものも、すべていただく」

主人公は5人と一緒に食べ物を集め、家を建て、少しずつ心を通わせていく。13日目、ゲームマスターが姿を現す。それは、主人公と同じように愛する人を奪われた、最初の転生者だった。

## ヒロイン（案）

全員を成人の女性として描くことを提案します（人外なので実年齢は数百歳でもかまいませんが、見た目も成人にします）。

| # | 種族 | 名前（仮） | 性格・見た目 | 島での役割 | 物語の鍵 |
|---|---|---|---|---|---|
| 1 | 吸血鬼 | ノクティア | セクシーで余裕のあるお姉さん。からかうのが好きだが、本当はさびしがり | 夜の見張り、薬づくり | 日光に弱く、昼は洞窟にいる。夜のイベントが中心 |
| 2 | 狐の獣人 | コノハ | 元気で人なつっこい。考える前に体が動く | 狩り、釣り、島の案内 | しっぽの数が絆とともに増える（見た目で好感度が分かる） |
| 3 | ガシャドクロ | カバネ | ギャル。骨の模様のタトゥー。口は悪いが面倒見がいい | 力仕事、建築 | 本気を出すと巨大な骸骨になる。その姿を見られるのを嫌がっている |
| 4 | 白虎 | ハクレン | 武人。まじめで不器用。四神の役目を失ったことを気にしている | 島の守り、戦いの稽古 | 西を守る神だった誇りと、守る相手がいない今の空しさ |
| 5 | ドラゴン | イグニア | （おまかせ）おっとりして食いしん坊。ほとんど寝ている。島のもとの主 | 火おこし、たまに空から島を見回る | 島のもとの主。ゲームマスターに島を奪われ、力を封じられている。真エンドの鍵 |

ドラゴンをこの性格にした理由：ほかの4人（セクシー、元気、ギャル、まじめ）と重ならず、物語の謎を握る役を置けるためです。

## ゲームの流れ（案）

```
プロローグ（浮気の目撃・死・GM の声）
  → 島の暮らし（1〜12日目）
       朝・昼・夜の3つの時間帯に、行動を1つずつ選ぶ
       探索・採集・釣り・建築・料理・ヒロインと過ごす
       好感度に応じて、個別イベントが進む
  → 13日目：ゲームマスター（黒瀬カイ）が姿を現す
       深夜：いちばん好感度の高いヒロインが会いに来て、決戦の相棒になる
  → 14日目：相棒と二人で GM に挑む
       勝つ → そのヒロインの個別エンド（5人全員と挑んで勝てば真エンド）
       相棒が幻に負ける → その相棒の NTR エンド
       主人公がミサキを選ぶ → 鬱エンド
```

### エンディング（案）

| エンド | 条件 | 内容 |
|---|---|---|
| 真エンド | 5人全員が段階4以上で、全員と挑んで勝つ | 島がイグニアに返され、5人と生きていく |
| 個別エンド ×5 | 相棒のヒロインと挑んで勝つ | 相棒と結ばれる。内容は `outline.md` |
| 鬱エンド | 決戦の後半で、主人公が「ミサキを取り戻したい」を選ぶ | 主人公は、浮気を目撃したあの夜の幻に閉じこめられる。5人はゲームマスターの駒になる |
| NTRエンド ×5 | 決戦の中盤で、相棒が「失ったもの」の幻に負ける | 相棒がゲームマスターの側につく。個別エンドの派生。内容は `outline.md` |

### 決戦のしくみ（案）

- 相棒のヒロインと二人で戦うコマンド式のバトル。ほかの4人は、島の発展度に応じて後ろから支える。
- GM は相棒に「失ったもの」の幻を見せる。相棒の好感度が段階5なら断り、段階4なら主人公の言葉しだい、段階3以下なら幻に負ける。
- 最後に GM は、主人公にミサキと先輩のあの夜を見せる。主人公が相棒の名前を呼べば、決着へ進む。
- 遊び方次第で、負ける（鬱エンド）ことが十分にありえる難しさにする。

### 長さを14日にした理由

30日にすると、行動の場面の数が12日の2倍以上になり、ティラノビルダーで作る手間が大きく増えます。5人それぞれに5段階の個別イベントを置ける長さとして、12日の暮らしを選びました。あとで日数を増やすことはできます。

### NTRの対象について（経緯）

2026-10-05 は、作る量を抑えるためにコノハ1人に絞りました。2026-10-06 に、利用者の案で「相棒と挑んで負けたときの展開」に変わり、5人全員に NTR エンドができました。作る量は増えるので、コノハから1人ずつ作ります。

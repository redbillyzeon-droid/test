# 戦闘画面の設計

作成：2026-10-06　／　状態：案

利用者が見本の画像（市販ゲームの戦闘画面のスクリーンショット）を示した。見本から取り入れるのは**画面の構成と雰囲気**だけで、絵・アイコン・ロゴなどの素材はこのゲーム用に新しく作る。見本の画像そのものは、権利の関係でリポジトリに入れていない。

## 見本から取り入れる点

| 見本の特徴 | このゲームでの使い方 |
|---|---|
| 敵を画面の中央に、正面から大きく見せる | GM（黒瀬カイ）と、GM が呼び出す「幻影」を中央に置く |
| 左上にコマンドの縦並びのメニュー。選んでいる項目が目立つ | コマンドメニュー（下の表）。選んでいる項目は、朱の帯で強調する（決戦は深紅 #c4262e の帯。下の「色とフォント」） |
| 下に味方の顔のカードが横に並ぶ。カードは写真を貼ったような見た目 | 主人公と相棒のカード。真エンドのルートでは6枚（主人公＋5人）並ぶ |
| カードの横に HP と MP の数字とバー | HP と「心」（MP の代わり）。心が0になると、幻に負けやすくなる |
| 上の中央に、特別な力のゲージ | 「絆ゲージ」。たまると、相棒の大技が使える |
| 左上に、名前の帯とマスの並び | 敵の名前と「支配の力」の残り（マスの数で見せる） |
| 暗い、色の濃い背景 | GM の館の前（もとはイグニアの巣）。夜明け前の赤黒い空 |

## 画面の配置（案）

```
┌─────────────────────────────────────────────────────────┐
│[黒瀬カイ ■■■■■■■■]        [ 絆ゲージ ◆◆◆◇◇ ]          [ログ][設定]│
│                                                         │
│ ┌──────────┐                                           │
│ │ 攻撃      │          (幻影)   GM   (幻影)              │
│ │ 守る      │                                           │
│ │▶技        │                                           │
│ │ 道具      │                                           │
│ │ 言葉      │                                           │
│ │ 絆        │                                           │
│ └──────────┘                                           │
│                                                         │
│  [主人公カード] [相棒カード]   (真エンドのルートでは6枚)       │
│   HP 836       HP 969                                    │
│   心 124       心 118                                    │
└─────────────────────────────────────────────────────────┘
```

画面の大きさは 1280×720（16:9）を想定。ティラノビルダーの既定に合わせる（PC で確認が必要）。

## コマンド

| コマンド | 中身 | `outline.md` の行動との対応 |
|---|---|---|
| 攻撃 | 主人公が攻撃する。力の能力で強さが決まる | — |
| 守る | 攻撃を受け流す。稽古の回数で効き目が変わる | 耐える |
| 技 | 相棒の通常の技を使う（相棒の番だけ） | 相棒に頼む |
| 道具 | 島で作った道具や薬を使う（体力回復、心の回復など） | — |
| 言葉 | 相棒、または GM に言葉をかける。中盤・後半の分かれ目で使う。戦闘中は、心と絆ゲージが上がる（主人公の番だけ） | 言葉をかける |
| 絆 | 絆ゲージがたまると使える。相棒の大技（段階4以上）。段階1〜3の相棒は連携攻撃 | 大技 |

「逃げる」は入れない（決戦なので。探索の戦闘も、負けたときの損が小さいので入れない）。

味方が全員倒れたとき（2026-10-17 決定。`plan.md`）：

| 戦闘 | どうなるか |
|---|---|
| 探索 | 体力 −3 で拠点に戻る。報酬はなし |
| 決戦（前半・決着） | 罰なし。「もう一度」（その段階の最初から）か「タイトルに戻る」を選ぶ。鬱エンドにはしない。「タイトルに戻る」のあとは、自動セーブ「14日目・決戦の前」から遊び直す（2026-10-17 決定（`plan.md` の「決戦の途中のセーブ」）。`design/screens.md` 4章） |

- 戦闘画面（探索・決戦）では、セーブと「状態」の画面は使えない（探索の戦闘は案。`design/screens.md` 4-2）。14日目は、出発からエンドの終わりまで手動セーブを止める（2026-10-17 決定（`plan.md` の「決戦の途中のセーブ」：作らない）。`design/screens.md` 4-2・4-3）。セーブできないときの文は `script/ui_text.md` 7-2。

探索の戦闘の相棒は、その探索に誘ったヒロイン（誘っていなければ主人公だけで、絆ゲージは出さない）。

計算式、相棒の技と大技の効果、絆ゲージのたまり方、敵の数字は `design/battle.md`（2026-10-17、案）。上の配置図の HP・心の数字（836、124 など）は見た目の例で、実際の数字は100前後になる。

## 色とフォント（案、2026-10-17）

会話画面とメニューの画面（`adv-ui.md` の「色の決まり（案）」、`menu-ui.md`）とそろえる案。まだ決まっていない。ただし、選んでいるコマンドの帯の色は **2026-10-17 決定**（`plan.md` の「選択の色」：帯は朱、金は「取り戻したもの・つながったもの」だけ）。

| 戦闘 | 画面全体 | 部品 |
|---|---|---|
| 探索の戦闘 | 背景はエリアの絵（森・洞窟など）。時間帯の色は会話画面と同じ（夜は紺の影） | 朱は「いま選べるもの」と、マウスを重ねたとき・選んでいるコマンドの帯（白の字）。金は絆ゲージと、段階4以上の相棒のカードの継ぎ線（`menu-ui.md` 1-3）だけ。HP の棒は緑のまま、心の棒は青のまま（いまの試作） |
| 決戦（前半・決着） | 夜明け前の赤黒い空 | 朱を深紅 #c4262e に。マウスを重ねたとき・選んでいるコマンドの帯も深紅（白の字）。金は探索の戦闘と同じく、絆ゲージと、段階4以上の相棒のカードの継ぎ線だけ |
| 決戦の中の幻（会話の場面） | 会話画面の「幻」の色 | `adv-ui.md` |

- 選んでいるコマンドの帯：いまの試作は橙寄りの金のグラデーション（`battle.css` 33行 `.ib-item.ib-sel` の #f0a52a〜#e8b04a）。自動戦闘のオンの地（25行 `.ib-auto.ib-on`）も #f0a52a。上の決まりに合わせて、探索は朱 #e8502a、決戦は深紅 #c4262e に寄せる。直すのはプログラム担当（資料に書くだけ）。
- フォント：いまの試作（`island_battle/battle.css`）は、画面全体の文字が明朝体（5行 `.ib-root` の font-family："Noto Serif CJK JP"、"Noto Serif JP"、"Yu Mincho"、serif）で、HP・心の数字と道具の説明（61・62・72行）だけ、ふつうのゴシック体（sans-serif）を使っている。会話画面と同じ組み合わせ A（見出しと数字は Dela Gothic One、説明の文は Zen Kaku Gothic New）にそろえる案。明朝体を残すかどうかも含めて、直すのはプログラム担当。Noto Serif は試作では端末のフォントを使っていて、ゲームに同梱していない（同梱するなら `credits.md` に書く）。
- 試作の地の色（#e9e2d2、黒茶 #1a1410）は、会話画面の黒 #111・白とずれている。コマンドの地は、会話画面の夜と同じ **生成り #efe9dc**（`adv-ui.md` の色の役目）にそろえ、枠の線を黒 #111 にそろえる案。生成りは #efe9dc の1色だけにする。
- ヒロインの色は `adv-ui.md` の表にそろえる（ノクティアを紫から深紅に、カバネを灰から白金に）。

## 敵

| 敵 | 中身 |
|---|---|
| GM（黒瀬カイ） | 中央。「支配の力」を0にすれば勝ち。全員で挑むときは、支配の力の量を島の発展度で変える（1100 − 100 × 発展度、いちばん低くて600。2026-10-17 決定、`plan.md`・`design/life-bond.md` 3章）。見た目は下の注 |
| 幻影 | GM が呼び出す影。相棒の「失ったもの」の形をとる（ノクティアにはルカ、コノハには稲荷の狐たち、など）。倒すと絆ゲージがたまる |
| ミサキと先輩の幻 | 後半だけ現れる。攻撃しても倒せない。「言葉」で向き合うと消える（戦闘の画面ではなく、会話の場面で出す。`script/06_day14_battle.md`） |
| 探索の敵 | 大イノシシ、森のぬし、洞窟のコウモリ、岩場の大トカゲ、山頂の大鷲、GM の使い魔。出る場所と行動は `design/battle.md` の 4-1 |

全員で挑む決戦の「支配の力」の見た目（2026-10-17 追加、案）：

- 左上のマスの並びの最大値は、その戦闘の支配の力（600〜1100）にする（`design/life-bond.md` 3-4）。マスの数は発展度で変えない（いつも同じ数のマスで、1マスの量が変わる）。発展度が高くても、最初から棒が短く見えることはない。発展度の違いは、カイの最初の台詞とターン数で伝える（同 3-4）。
- 中盤へ進む境目（400以下）に、マスの並びの上に小さな刻み（白の縦線 2px、高さ 8px）を入れる案。全員のときは「半分」ではなく値で決まるので、境目の位置が発展度で変わる（例：1100 なら左から 36%、600 なら 67% のところ）。刻みを入れるかは未決（入れると、あとどれだけで中盤かが見えるが、画面の情報は増える）。
- 2人で挑むときは変えない（支配の力400、半分の200で中盤へ）。

## 島の暮らしでも戦闘を使うか

**決定：B（探索で小さな戦闘）**（2026-10-06、利用者の判断）。

### 検討した案

いまの設計では、戦闘は14日目の決戦1回だけです。この画面を作るなら、島の暮らしでも使う手があります。

| 案 | 中身 | 良い点 | 気をつける点 |
|---|---|---|---|
| A. 決戦だけ | いまのまま | 作る量が少ない | 戦闘画面を作っても、1回しか使わない。決戦で初めて操作を覚えることになる |
| B. 探索で小さな戦闘 | 洞窟・岩場・山頂などで、獣や GM の使い魔と短い戦闘（1〜2分、自動戦闘あり） | 主人公の「力」や道具を育てる意味がはっきりする。決戦の前に操作に慣れる | 作る量が増える。サクサク感を守るため、戦闘は短く、自動戦闘を必ず入れる |
| C. 稽古で練習試合 | ハクレンとの稽古を、戦闘画面での練習試合にする | 作る量が少なめで、操作に慣れられる | 戦闘の回数は少ない |

おすすめは **B**。探索育成型と合わせると、「探索 → 素材 → 道具と能力 → 戦闘」の流れができる。

## ティラノビルダーで作るときの考え（案、未確認）

- 背景、敵、カードの枠は画像で用意する（`[image]`、`[chara_show]`）。
- HP・心・支配の力のバーと数字は、JavaScript（`[iscript]`）で計算して、`[ptext]` や HTML 要素で表示する。
- コマンドメニューは `[glink]` か `[button]` の縦並び。
- 前作（別のセッションで作った人狼ゲーム）で、投票画面などを JavaScript で作っていた記録がある。同じやり方が使える可能性が高いが、中身はここからは見えないので未確認。
- 実際の見た目と動きは、PC のティラノビルダーで試すまで確かめられない。

# 戦闘画面の設計

作成：2026-10-06　／　状態：案

利用者が見本の画像（市販ゲームの戦闘画面のスクリーンショット）を示した。見本から取り入れるのは**画面の構成と雰囲気**だけで、絵・アイコン・ロゴなどの素材はこのゲーム用に新しく作る。見本の画像そのものは、権利の関係でリポジトリに入れていない。

## 見本から取り入れる点

| 見本の特徴 | このゲームでの使い方 |
|---|---|
| 敵を画面の中央に、正面から大きく見せる | GM（黒瀬カイ）と、GM が呼び出す「幻影」を中央に置く |
| 左上にコマンドの縦並びのメニュー。選んでいる項目が目立つ | コマンドメニュー（下の表）。選んでいる項目は、金色の帯で強調する |
| 下に味方の顔のカードが横に並ぶ。カードは写真を貼ったような見た目 | 主人公と相棒のカード。真エンドのルートでは6枚（主人公＋5人）並ぶ |
| カードの横に HP と MP の数字とバー | HP と「心」（MP の代わり）。心が0になると、幻に負けやすくなる |
| 上の中央に、特別な力のゲージ | 「絆ゲージ」。たまると、相棒の大技が使える |
| 左上に、名前の帯とマスの並び | 敵の名前と「支配の力」の残り（マスの数で見せる） |
| 暗い、色の濃い背景 | GM の館の前（もとはイグニアの巣）。夜明け前の赤黒い空 |

## 画面の配置（案）

```
┌─────────────────────────────────────────────────────────┐
│[黒瀬カイ ■■■■■■■■]        [ 絆ゲージ ◆◆◆◇◇ ]          [ログ][設定]│
│                                                         │
│ ┌──────────┐                                           │
│ │ 攻撃      │          (幻影)   GM   (幻影)              │
│ │ 守る      │                                           │
│ │▶技        │                                           │
│ │ 道具      │                                           │
│ │ 言葉      │                                           │
│ │ 絆        │                                           │
│ └──────────┘                                           │
│                                                         │
│  [主人公カード] [相棒カード]   (真エンドのルートでは6枚)       │
│   HP 836       HP 969                                    │
│   心 124       心 118                                    │
└─────────────────────────────────────────────────────────┘
```

画面の大きさは 1280×720（16:9）を想定。ティラノビルダーの既定に合わせる（PC で確認が必要）。

## コマンド

| コマンド | 中身 | `outline.md` の行動との対応 |
|---|---|---|
| 攻撃 | 主人公が攻撃する。力の能力で強さが決まる | — |
| 守る | 攻撃を受け流す。稽古の回数で効き目が変わる | 耐える |
| 技 | 相棒の通常の技を使う | 相棒に頼む |
| 道具 | 島で作った道具や薬を使う（体力回復、心の回復など） | — |
| 言葉 | 相棒、または GM に言葉をかける。中盤・後半の分かれ目で使う | 言葉をかける |
| 絆 | 絆ゲージがたまると使える。相棒の大技（段階4以上） | 大技 |

「逃げる」は入れない（決戦なので）。

## 敵

| 敵 | 中身 |
|---|---|
| GM（黒瀬カイ） | 中央。「支配の力」を0にすれば勝ち |
| 幻影 | GM が呼び出す影。相棒の「失ったもの」の形をとる（ノクティアにはルカ、コノハには稲荷の狐たち、など）。倒すと絆ゲージがたまる |
| ミサキと先輩の幻 | 後半だけ現れる。攻撃しても倒せない。「言葉」で向き合うと消える |

## 島の暮らしでも戦闘を使うか

**決定：B（探索で小さな戦闘）**（2026-10-06、利用者の判断）。

### 検討した案

いまの設計では、戦闘は14日目の決戦1回だけです。この画面を作るなら、島の暮らしでも使う手があります。

| 案 | 中身 | 良い点 | 気をつける点 |
|---|---|---|---|
| A. 決戦だけ | いまのまま | 作る量が少ない | 戦闘画面を作っても、1回しか使わない。決戦で初めて操作を覚えることになる |
| B. 探索で小さな戦闘 | 洞窟・岩場・山頂などで、獣や GM の使い魔と短い戦闘（1〜2分、自動戦闘あり） | 主人公の「力」や道具を育てる意味がはっきりする。決戦の前に操作に慣れる | 作る量が増える。サクサク感を守るため、戦闘は短く、自動戦闘を必ず入れる |
| C. 稽古で練習試合 | ハクレンとの稽古を、戦闘画面での練習試合にする | 作る量が少なめで、操作に慣れられる | 戦闘の回数は少ない |

おすすめは **B**。探索育成型と合わせると、「探索 → 素材 → 道具と能力 → 戦闘」の流れができる。

## 試作（2026-10-06）

`game/tyrano-proto/` に、ティラノスクリプト用の戦闘画面の試作を作った。クラウドでティラノスクリプト Ver6.00 を使って動かし、自動テストが 8/8 合格した。ティラノビルダーで動くかは、PC で確かめる（`handoff-local-engine-check.md`）。

## ティラノビルダーで作るときの考え（案、未確認）

- 背景、敵、カードの枠は画像で用意する（`[image]`、`[chara_show]`）。
- HP・心・支配の力のバーと数字は、JavaScript（`[iscript]`）で計算して、`[ptext]` や HTML 要素で表示する。
- コマンドメニューは `[glink]` か `[button]` の縦並び。
- 前作（別のセッションで作った人狼ゲーム）で、投票画面などを JavaScript で作っていた記録がある。同じやり方が使える可能性が高いが、中身はここからは見えないので未確認。
- 実際の見た目と動きは、PC のティラノビルダーで試すまで確かめられない。

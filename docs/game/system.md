# ゲームシステム（探索育成型シミュレーション）

作成：2026-10-06　／　状態：案

利用者の希望：**探索育成型シミュレーションゲームで、割とサクサクな感じ**（2026-10-06）。

物語の流れ（14日間、13日目に GM、14日目に相棒と決戦）は `outline.md` のまま。この文書は、2〜12日目の「島の暮らし」の遊び方を決める。

## サクサクにするための決まり

| 決まり | 中身 |
|---|---|
| 1回の行動は短く | 行動を選んでから結果が出るまで、クリック1〜3回、10〜30秒 |
| 文章は短く | 探索の結果は、2〜4行の短い文と、結果のカード（手に入れた物、上がった数値）だけ |
| 長い場面は条件つき | 個別イベントは、好感度の段階に届いたときだけ起きる。毎回は起きない |
| 一度読んだ文は飛ばせる | 既読スキップ。2周目以降を速くする |
| 1日のまとめ | 夜の終わりに、その日に増えたもの・上がった数値を1枚で見せる |
| 迷わせない | 次にやるとよいことを、画面のすみに1行で出す（例：「見張り台を建てると、決戦の守りが上がる」）。締め切りの警告（決戦の相棒がいない見込みなど）も、この1行に出す |
| 状態を見せる | 「状態」の画面で、ヒロインの段階・次の段階までの棒・「次に会うとイベント」の印・会える時間帯と、残りの行動の回数を見せる（好感度の数字は出さない） |

- 状態の画面、締め切りの警告、セーブ（自動セーブの枠、決戦の途中のセーブ、エンドの記録）、行動を選ぶ画面・探索マップ・1日のまとめの中身とクリック数は `design/screens.md`（2026-10-17）。そのうち、自動セーブの枠、決戦の途中のセーブ（作らない）、エンドのあとのやり直し、ヒロインの状態の見せ方、心（`f.mind`）の見せ方（状態画面には出さず、段階3・4・5の結果のカードに「ユウの心が、少し強くなった」）、全員と心を通わせるまでの目安と警告（「寄り道はあと少し」は余り0のときだけ）、段階4の言葉は 2026-10-17 決定（`plan.md`）。ほかは案。

## 1日の流れ

```
朝 → 昼 → 夜（3回の行動）→ 1日のまとめ → 次の日
```

各時間帯に、次のどれかを1つ選ぶ。

| 行動 | 中身 | 主に上がるもの |
|---|---|---|
| 探索 | マップのエリアを1つ選んで探索する | 素材、食料、新しいエリア、ヒロインとの出会いイベント |
| ヒロインと過ごす | その時間帯に会えるヒロインを1人選ぶ。または「みんなと過ごす」（その時間帯に会える全員） | 好感度 |
| 建てる・作る | 素材を使って、施設を建てる、道具を作る | 島の発展度、探索の効率 |
| 鍛える | ハクレンと稽古（朝）、ノクティアと薬の勉強（夜）など | 主人公の能力、一緒にいたヒロインの好感度（少し） |
| 休む | 体力を回復する | 体力 |

- 1日の自由行動は、台本の固定の場面を引くと、2〜12日目で **28回**（朝9、昼10、夜9）。数え方は `design/affection.md` の 1-1。

| エリア | 最初から行ける？ | 主に手に入るもの | 会いやすいヒロイン | 開く条件（案） |
|---|---|---|---|---|
| 浜辺 | ○ | 魚、流木、貝殻 | コノハ | — |
| 森 | ○ | 木材、果実、薬草 | コノハ、カバネ | — |
| 川 | ○ | 水、魚、粘土 | カバネ | — |
| 洞窟 | × | 鉱石、きのこ | ノクティア（夜） | 松明を作る |
| 岩場 | × | 石材、竜のうろこ | イグニア | 森を3回探索する |
| 山頂 | × | 山頂の白い花、見晴らし | ハクレン | 「縄ばしご」を作る |

### 探索の結果

1回の探索で、次のうち1〜2つが起きる。

- 素材や食料を手に入れる（ほとんどの場合）
- めずらしい物を見つける（低い確率。探索の能力が高いほど上がる）
- ヒロインに出会う（そのエリアに会いやすいヒロインがいる時間帯）
- 小さな出来事（けがをする、動物に会う、GM の石碑のかけらを見つける）

2026-10-17 決定（`plan.md`「初めてのエリア」「誘ったときの得意な素材」「山頂の白い花」「好物がだぶるとき」、`design/life-bond.md` 1-1・2-3。数字は目安）：

- 初めて探索したエリアでは、そのエリアのめずらしい結果（好物か手がかり）が必ず出る（2日目の決まった探索は数えない。森は1回目に赤い果実、2回目に大豆の種。山頂の白い花は山頂のめずらしい結果）。めずらしい結果がないエリア（川・岩場）は、初めてでもいつもどおり。2回目からの確率は 20% ＋ 知恵 × 5%。
- 好物、またはその途中の物（大豆の種・大豆）を持っている間と、その好物を渡したあとは、探索・戦闘の報酬でも出さず、別の報酬にする（めずらしい報酬も含む）。
- 探索に誘うと、その人の得意な素材が必ず1つ足される（カバネ 木材 ×3、ハクレン 木材 ×2、コノハ 魚 ×2、イグニア 粘土 ×3、ノクティア 薬草 ×2）。

## 育成（主人公の能力）

| 能力 | 変数・初期値・範囲（目安） | 上げ方 | 効くところ |
|---|---|---|---|
| 体力 | `f.hp`・10・0〜10 | 休む、食事 | 1日に行動できる回数。0になると、次の朝の行動が1回減る。戦闘の HP（70 ＋ 体力 × 5） |
| 力 | `f.str`・1・1〜10 | 稽古（ハクレン）、力仕事（カバネと建築） | 戦闘の攻撃（8 ＋ 力 × 2）と守り（力 ÷ 3）、重い素材を運べる |
| 器用さ | `f.dex`（新しく作る）・1・1〜6 | 道具づくり、料理 | 作れる物が増える、料理の効果、戦闘の薬草の回復量 |
| 知恵 | `f.wis`・1・1〜6 | 薬の勉強（ノクティア）、イグニアの昔話 | 探索でめずらしい物を見つけやすくなる。戦闘のめずらしい報酬 |
| 心 | `f.mind`・2・0〜17 | 個別イベントの段階3・4・5を見るたびに +1。8日目の幻で「分からない」で −1 | 戦闘の心（20 ＋ 心 × 5）。決戦の後半（GM がミサキの幻を見せる場面）で、判定値（心。前半の終わりに戦闘の心が0なら −1）が **2以下** だと選択肢が1つになり、手がかりの選択肢も出ない（2026-10-17 決定） |

- 「鍛える（ハクレンと稽古）」の回数を `f.train_count` で数える。戦闘の「守る」の効き目に使う。
- 戦闘の計算と数字の目安は `design/battle.md`（2026-10-17）。心の上げ方を「ヒロインと過ごす、個別イベント」から上の形に絞った（理由は `design/battle.md` の 1-1）。

## 島づくり（施設）

施設は、素材を使って建てる。建てると、暮らしが楽になり、決戦で守りが上がる。

| 施設 | 必要な素材（案） | 効果 |
|---|---|---|
| 拠点（最初からある） | — | 寝る場所 |
| かまど | 粘土3 | 料理ができる。食事で体力の回復が増える |
| 作業台 | 木材3 | 道具を作れる（松明、縄ばしご、釣り竿など）。2日目の説明で、建てられることを案内する（建てるかどうかはプレイヤーが決める） |
| 家 | 木材10、石材5 | 休むときの回復が増える。4日目の嵐で壊れにくくなる |
| 畑 | 木材3 | 毎朝、食料が少し増える。森で見つけた「大豆の種」を植えると、3日後に大豆がとれる（コノハの好物の油揚げの材料） |
| 見張り台 | 木材8、石材5 | 決戦の守りが上がる |
| 船着き場 | 木材12、石材8 | 沈没船に行ける。決戦の守りが上がる |

島の発展度は、建てた施設の数で決まる（変数 `f.dev`。拠点を除く0〜6。4日目の嵐で作業台が壊れている間は数えない。`design/battle.md` 5-2）。

- 浜辺の「流木」は、木材として数える。
- 早い日に建てられるもの（作業台、かまど、畑）は、最初から行ける浜辺・森・川の素材だけで作れるようにする。石材が要るもの（家、見張り台、船着き場）は、岩場が開いてから。
- 2026-10-16：台本と合わせて、作業台を木材5→3、かまどを石材3→粘土3、畑の「種」をなくした。
- 2026-10-17 決定（`plan.md`「一緒に建てる」「油揚げ」「施設の『ゆかりの人』の画面の言葉」「2日目の作業台」、`design/life-bond.md` 1-2・2章。数字は目安）：建てる・直すとき、その時間帯に会える人から2人まで手伝ってもらう（各 +3）。施設の「ゆかりの人」（画面の言葉は「ゆかり」。作業台・船着き場 カバネ、かまど イグニア、畑 コノハ、家 ノクティア、見張り台 ハクレン）なら +5 で、初めて建てたときに短い場面。2日目の作業台は説明の場面なので、手伝いからカバネを外せない。畑と大豆の種があれば自動で植え、3日後に大豆、かまどがあれば自動で油揚げ（行動を使わない。油揚げは1つだけ）。

## 好感度

- `outline.md` の段階（10・30・50・70・90）は、そのまま。
- 2026-10-17 の決定（`plan.md`「真エンドの届きやすさ」）：計画して遊べば、12日目までに全員を段階4にできるようにする。段階5は1〜2人が目安（しぼって計画すれば3人届くこともあり、それは止めない。2026-10-17 プロデューサー決定）。計算は `design/affection.md`。

| 上がること | 値（目安） | メモ |
|---|---|---|
| ヒロインと過ごす（1人と） | +5〜8（台本の会話ごとの値） | いまのまま |
| 段階のイベントの回 | +5（会えた分）＋ 段階ボーナス ＋ イベントの中の選択の値 | 段階ボーナスは段階1・2・3で +8、段階4・5は0（2026-10-17 案） |
| みんなと過ごす | その時間帯に会える全員 +3。かまどがあれば +4 | 段階のイベントは起きない（2026-10-17 案） |
| 探索に誘う | 誘ったヒロイン +3 | 段階のイベントは起きない（2026-10-17 案） |
| ハクレンと稽古／ノクティアと薬の勉強 | ハクレン +3／ノクティア +3 | 2026-10-17 案 |
| 好物を渡す | +10 | 2026-10-17 決定（`plan.md`「好物」、`design/life-bond.md` 1章。数字は目安）：二人きりの「過ごす」に添えて渡す（行動もクリックも増えない）。段階の判定に入れる（いまの好感度 ＋ 5 ＋ 10）。1人に1回だけ |
| 探索で出会う | +3 | いまのまま |
| 施設を一緒に建てる | 手伝ったヒロイン +3 | 2026-10-17 決定（`plan.md`「一緒に建てる」、`design/life-bond.md` 2章。数字は目安）：2人まで +3、ゆかりの人は +5 |

- 段階のイベントの起き方（2026-10-17 案）：「過ごす」を選んだとき、いまの好感度に +5 を足して段階の値に届き、その段階をまだ見ていなければ、会話の代わりに段階のイベントを出す。届かなければ会話を出す。段階4は段階3を見たあと、段階5は9日目以降（台本どおり）。稽古でハクレンのイベントが起きたときも同じに数え、力 +1 と稽古の回数 +1 も足す。
- 段階のイベントは1から順に起きる。次に起きるのは、いつも「見た段階 + 1」（1回の「過ごす」で1段階だけ。2026-10-17 案。`design/screens.md` 1-2）。
- 次に二人きりで過ごす（ハクレンは朝の稽古も）とイベントになるヒロインには、選ぶ画面で印を出す（「みんなと過ごす」や探索に誘うではイベントが起きないため）。印と棒の計算は `design/screens.md` 2章。
- 12日目の宴の +3 は、そのあとに自由行動がないので、段階4には間に合わない（13日目の相棒を決めるときの好感度にだけ効く）。
- 好物を渡したことは、ヒロインごとに記録する（例：コノハに油揚げを渡すと `f.gave_fried_tofu = 1`。段階5とエンドの台詞が変わる）。
- 各ヒロインの好物：ノクティア＝赤い果実（森のめずらしい結果）、コノハ＝油揚げ（作るには畑の大豆が必要）、カバネ＝虹色の貝殻（浜辺のめずらしい結果）、ハクレン＝山頂の白い花（山頂のめずらしい結果。2026-10-17 決定）、イグニア＝焼き魚（生の魚を渡しても、イグニアが自分の火で焼いて食べるので、好物として数える）。

## 探索中の戦闘

2026-10-06、利用者の判断で「探索で小さな戦闘」を入れることにした（`battle-ui.md` の案B）。

- 洞窟・岩場・山頂などで、獣や GM の使い魔と出会うと戦闘になる。森では、7日目以降に「森-X2」で森のぬしが出る（2026-10-17 決定）。
- 1回の戦闘は1〜2分。自動戦闘を必ず付ける（サクサクにするため）。
- 相棒は、その探索に一緒に行ったヒロイン（いなければ主人公だけ）。
  - 2026-10-17 決定：探索を選んだあと「一人で行く／誘う」を選ぶ（クリック1回）。誘えるのは、その時間帯に会えるヒロイン1人。誘うと、その回の「過ごす」はできない。変数は `f.explore_partner`。
  - 誘ったヒロインは好感度 +3（目安）。段階のイベントは起きない。誘っている回は、そのヒロインの「出会い」の結果を出さない（引いたら引き直す）。
- 勝つと素材やめずらしい物が手に入る。負けても、体力が減って拠点に戻るだけ（ゲームオーバーにはしない）。
  - 2026-10-17 決定：負けたら体力 −3（0より下げない）。その戦闘の報酬はなし。「逃げる」は入れない。
- 1回の戦闘は3〜6ターンで終わる強さにする（目安）。敵ごとの数字と行動は `design/battle.md` の4章。
- 戦闘画面は決戦と同じもの。決戦の前に操作に慣れられる。

## 決戦とのつながり

| 育てたもの | 決戦で効くところ |
|---|---|
| 相棒の好感度 | 中盤で、相棒が幻に負けるかどうか |
| 主人公の力 | 前半の攻撃 |
| 主人公の心 | 後半、ミサキの幻に耐えられるか（選択肢が出るか） |
| 島の発展度 | GM の攻撃で行動が減るかどうか（発展度0〜2は毎回、3〜4は1回目だけ防ぐ、5以上は減らない）、ほかの4人の支援（施設ごと。`design/battle.md` の 5-2）。4以上なら、中盤で相棒への言葉をまちがえても1回だけ選び直せる（2026-10-17 決定）。全員で挑むときは、GM の支配の力 ＝ 1100 − 100 × 発展度（いちばん低くて600）で、400以下で中盤へ（2026-10-17 決定。`plan.md`「全員で挑む決戦と発展度」、`design/life-bond.md` 3章。数字は目安） |
| GM の手がかり | 洞窟の線・沈没船の日記：後半の手がかりの選択肢（台本どおり）。日記があれば、中盤で言葉をまちがえても、発展度に関係なく1回だけ選び直せる。発展度4以上の選び直しと **合わせて1回**（2026-10-17 決定。`plan.md`「沈没船の日記」、`design/life-bond.md` 4章） |

- 決戦で味方が全員倒れたときは、その段階（前半、または決着）の最初から、罰なしでやり直せる。選択肢は「もう一度」と「タイトルに戻る」（2026-10-17 決定）。「タイトルに戻る」のあとは、自動セーブ「14日目・決戦の前」から決戦をやり直せる。14日目の間は手動セーブを止める（2026-10-17 決定。`plan.md`「決戦の途中のセーブ」、`design/screens.md` 4章）。

## 1周の時間の目安（案）

- 1回の行動：10〜30秒。1日：約2〜3分（個別イベントがない日）。
- 12日の暮らし：約30〜40分。個別イベント・固定イベント・決戦・エンドを入れて、1周 約1.5〜2時間。
- 以前の目安（1周 2〜3時間）より短い。サクサクにするため。数字は遊んで確かめていない。
- 真エンドを狙う周は、段階のイベントを20回見る（`design/affection.md`）。イベント1つの長さを測っていないので、この周が2時間に収まるかは未確認。

## ティラノビルダーで作るときの考え（案）

- 数値（能力、素材、好感度、発展度）は、ゲーム変数 `f.` で持つ。
- 探索の結果や確率の計算は、`[iscript]` の JavaScript でまとめて行う。
- マップと結果のカードは、画像ボタン（`[button]` / `[glink]`）で作る。
- ティラノビルダーで、どこまで画面を作り込めるかは、PC で試して確かめる必要がある（未確認）。

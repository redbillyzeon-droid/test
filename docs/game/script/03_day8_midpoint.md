# 台本：8日目の固定イベント「中間発表」

作成：2026-10-16　／　状態：初稿

書き方の決まりは `00_prologue_day1.md` と同じ。

この場面の役目（`docs/game/outline.md`）：

- GM が、ゲームの「中間発表」をする。5人それぞれに「失ったもの」の幻を見せて、揺さぶる。
- 主人公には、ミサキが一人で主人公の墓の前にいる幻を見せる。先輩の姿はない（「ミサキは本当はどう思っていたのか」という引っかかりを作る）。
- その夜、5人が、それぞれの「失ったもの」を少しずつ打ち明け合う。
- ここから沈没船（船着き場を建てると行ける）が開く。

起きる時間：8日目の夜。この日の夜の行動は、この場面に置きかわる（朝と昼は自由行動）。

---

## 夜：石碑がふたたび光る

【日付：8日目・夜】
【背景：浜辺・夜】
【BGM：不穏な曲】

夕食のあと、浜のほうが、また青白く光った。

【背景：浜の石碑・夜（文字が光る）】
【立ち絵：コノハ（驚き）、カバネ（不機嫌）】

石碑の前に、5人がそろっていた。ノクティアも、イグニアも、黙って文字を見上げている。

【画面表示（石碑の文）】
中間発表。
残りは、六日。
今のところ、誰も、取り戻したいものを手放していない。
けっこう。それが、人だ。

？？？「――やあ。楽しくやっているかな」

【効果音：低い声が、空から降ってくる】

あの声だった。暗闇の中で、俺を「失った者」と呼んだ声。

？？？「勝てば、失ったものを一つ、返してやる。それを忘れないように、少しだけ、見せてあげよう」

【画面：石碑の光が、浜いっぱいに広がる】

---

### 5人の幻

光の中に、いくつもの影が浮かんだ。

【立ち絵：ノクティア（悲しみ）】

ノクティアの前に、金色の髪の青年が立っていた。

ノクティア「……ルカ」

ノクティアの声が、聞いたことがないくらい、細かった。

【立ち絵：コノハ（悲しみ）】

コノハの前には、朱塗りの鳥居と、小さな社があった。白い狐たちが、こっちを見ている。

コノハ「……みんな」

【立ち絵：カバネ（悲しみ）】

カバネの前には、日焼けした素足の、小さな村娘が立っていた。……カバネに、どこか似ていた。

カバネは、何も言わなかった。

【立ち絵：ハクレン（悲しみ）】

ハクレンの前には、白い虎の旗をかかげた、たくさんの人々が、ひざまずいていた。

ハクレン「……やめろ。もう、いない者たちだ」

【立ち絵：イグニア（真剣）】

イグニアの前には、何もなかった。

ただ、空の高いところに、大きな翼の影が、いくつも、いくつも、重なっていた。

イグニア「…………」

イグニアは、いつもの眠そうな目ではなかった。まっすぐに、石碑をにらんでいた。

---

### 主人公の幻

【背景：墓地・昼（幻）】
【BGM：静かな曲】

気づくと、俺の前には、見覚えのある景色が広がっていた。

前の世界の、小さな墓地だった。

新しい墓石の前に、誰かが一人で立っていた。

【立ち絵：ミサキ（泣き顔）】

（ミサキ……）

ミサキは、喪服のまま、墓石の前にしゃがみこんでいた。手に、小さな箱を持っている。

――あの夜、床を転がっていった、指輪の箱だった。

ミサキの肩が、震えていた。声は聞こえない。

まわりを見回しても、先輩の姿は、どこにもなかった。

（どうして、一人なんだ）

（どうして、泣いてるんだ。……あんなことをしておいて）

？？？「お前が勝てば、あの女を取り戻せる。あの夜より、前に戻してやる」

？？？「ほら。まだ、取り戻したいだろう？」

▼選択
- 「……分からない」 → 心 −1
- 「やめろ。見せるな」 → 変化なし

（どちらを選んでも、話は同じように続く。`f.misaki_answer` に記録して、決戦の後半の台詞を少し変える）

【画面：光が消える】

## 浜辺：打ち明ける夜

【背景：浜辺・夜】
【BGM：夜の曲】

光が消えると、浜には、波の音だけが残った。

誰も、しばらく、口を開かなかった。

【立ち絵：カバネ（普通）】

カバネ「……うざ。あいつ、マジで性格悪い」

カバネが、砂を蹴った。その声が、少しだけ、いつもより高かった。

【立ち絵：ノクティア（微笑み）】

ノクティア「……ふふ。久しぶりに、あの子の顔を見たわ。……見せられたくは、なかったけれど」

ノクティア「坊や。あなたの前にも、誰か、いたのでしょう？」

▼選択
- 「……前の世界の、恋人が」 → 5人 +2、`f.told_misaki = 1`
- 「……言いたくない」 → 変化なし

【選択1のとき】

ユウ「前の世界の……恋人だった人が、泣いてた」

ユウ「その人に、裏切られて、俺は死んだんだ。……なのに、どうして泣いてるのか、分からない」

コノハ「……ユウ」

【立ち絵：コノハ（悲しみ）】

コノハが、黙って、俺の隣に座った。

ハクレン「……そうか。貴殿も、失ったのだな」

【選択2のとき】

ユウ「……言いたくない」

ノクティア「ええ。それでいいわ。……わたくしも、全部は言わないもの」

【合流】

【立ち絵：コノハ（真面目）】

コノハ「……ボクね、帰るところが、なくなっちゃったの。さっきの、ボクがいた社」

コノハ「戻れたらいいなって、ずっと思ってた。……でも、今は、よく分かんない」

【立ち絵：ハクレン（悲しみ）】

ハクレン「私は、守る国をなくした。……あの者たちは、もう、誰も私の名を呼ばない」

【立ち絵：イグニア（真剣）】

イグニア「……わたしは、一族と、この島」

コノハ「え？　島？」

イグニア「……この島は、もとは、わたしの巣。……今は、あの声のもの」

ハクレン「……初耳だぞ、イグニア」

イグニア「……言っても、どうにもならなかったから」

イグニアは、それだけ言うと、目を閉じた。眠ったのか、眠ったふりなのか、分からなかった。

【立ち絵：カバネ（普通）】

カバネ「……あーしは、パス。……今は、まだ」

カバネは、そう言って、膝を抱えた。

（みんな、何かを失って、ここにいる）

（そしてあの声は、それを「返してやる」と言う）

（……勝てば、みんな、いなくなるのか？　取り戻したものの、ところへ）

## 夜の終わり

【背景：浜の石碑・夜】

みんなが洞窟に戻ったあと、もう一度だけ、石碑を見に行った。

光は、もう消えていた。

ただ、石碑の根元に、さっきまでなかった、小さな木の札が刺さっていた。

【画面表示（木の札の文字）】
南の岬に、船がある。
道をつくれば、行ける。

（船……？）

【次にやること：「船着き場」を建てると、沈没船に行ける】

【画面表示：8日目　終了】

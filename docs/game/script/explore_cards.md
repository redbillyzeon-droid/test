# 探索の結果の文（結果のカード）

作成：2026-10-16　／　更新：2026-10-17（森-X2、戦闘の勝ち負けの文と報酬、相棒を誘ったときの一言）　／　状態：初稿

探索で出る、短い文の一覧。1回の探索で、下の「いつもの結果」から1つ、ときどき「めずらしい結果」か「出会い」か「小さな出来事」が1つ足される（`docs/game/system.md` の「探索の結果」）。

## 書き方の決まり

- 文は2〜4行。会話は1〜2行まで（サクサク）。
- 最後に【結果のカード】で、手に入れたものと上がった数値を出す。
- 数（×2 など）は目安。遊んで調整する。
- 同じ文が続けて出ないように、各エリアに「いつもの結果」を3つ以上用意する。
- 「出会い」は、そのヒロインがその場所にいそうな時間帯だけに絞っている（`outline.md` の「時間帯ごとに会えるヒロイン」の一部）。時間帯は見出しの（）に書く。

（これがあれば、コノハの好きな、あれが作れる）
【結果のカード】大豆の種 ×1（畑に植えると、3日後に大豆がとれる）

**森-E1（カバネ、朝・昼）**
カバネが、大きな丸太を片手で引きずっていた。
カバネ「お、ちょうどいいとこに。こっち持って。……は？　重い？　ウケる」
【結果のカード】木材 ×5、カバネの好感度 +3

**森-E2（コノハ、朝・昼）**
コノハが、木の上から逆さまにぶら下がっていた。
コノハ「ユウ、ここの実、すっごく甘いよ！　はい、あーん！」
【結果のカード】果実 ×2、コノハの好感度 +3

### 小さな出来事

**森-X1**
茂みの奥で、低いうなり声がした。……何かが、こっちを見ている。
【戦闘：森の獣（大イノシシ）】
- 勝ったとき：大イノシシは、茂みの奥へ逃げていった。牙で掘り返した地面に、芋が転がっている。
  【結果のカード】食料 ×3
- 負けたとき：突き飛ばされて、気づくと森の入り口に倒れていた。なんとか拠点まで歩いて帰った。
  【結果のカード】体力 −3（拠点に戻る）

**森-X2（7日目以降。森-X1 の半分をこれに置きかえる）**
地面が、ずしんと揺れた。木々の間から、苔におおわれた大きな鹿のような獣が現れる。枝のような角に、青緑の光がまとわりついている。
（……森のぬしだ。足元に、大イノシシまで連れている）
【戦闘：森のぬし ＋ 大イノシシ】（一人だと手ごわい。相棒を誘っていると戦いやすい）
- 勝ったとき：森のぬしは、ゆっくりと森の奥へ帰っていった。通ったあとには、倒れた木と、落ちた実が残っていた。
  【結果のカード】食料 ×4、木材 ×3（めずらしい報酬：大豆の種 ×1）
- 負けたとき：大きな角に払われて、体が宙に浮いた。……気づくと、森の入り口だった。
  【結果のカード】体力 −3（拠点に戻る）

## 探索に相棒を誘ったとき

2026-10-17 の決まり（`../plan.md`「探索に相棒を誘う」、`../design/battle.md` 3-1）に合わせた一言。

- 探索を選んだあと、「一人で行く／誘う」を選ぶ。誘えるのは、その時間帯に会えるヒロイン1人（`daily/README.md` の表）。誘うと、その回の「過ごす」はできない。
- 誘ったときの好感度：（好感度はゲームデザイン担当が決める）
- 誘ったヒロインの「出会い」の結果は、その回には出ない（引いたら、引き直す）。本人と一緒にいるのに、本人と出会う文になるのを防ぐため。
- 出すところ：「誘ったとき」は出発のとき。結果が戦闘のときだけ、「戦闘の前」「勝ったあと」「負けたあと」を足す。戦闘でない結果のときは「誘ったとき」だけ。
- 〈呼び方〉は、段階4の前と後で変える。

| ヒロイン | 段階4の前 | 段階4のあと |
|---|---|---|
| ノクティア | 坊や | ユウ |
| コノハ | ユウ | ユウ（変わらない） |
| カバネ | アンタ | ユウっち |
| ハクレン | 貴殿 | ユウ |
| イグニア | 人の子 | ユウ |

### ノクティア（夜。雨の日は昼も）

- 誘ったとき：ノクティア「あら、夜のお散歩？　〈呼び方〉のお誘いなら、付き合ってあげる」
- 戦闘の前：ノクティア「下がっていて、〈呼び方〉。……嘘よ。隣にいてちょうだい」
- 勝ったあと：ノクティア「ふふ、よくできました。……怪我はない？　見せてごらんなさい」
- 負けたあと：ノクティア「無理をさせたわね。……今夜は、わたくしがそばにいるわ」

### コノハ（朝・昼）

- 誘ったとき：コノハ「いく！　ボクが案内する！　ユウ、はぐれないでね！」
- 戦闘の前：コノハ「ユウ、うしろにいて！　ボク、速いから！」
- 勝ったあと：コノハ「やったー！　ユウ、見てた？　ボク、役に立った？」
- 負けたあと：コノハ「うう……ごめんね、ユウ。次は、ぜったい勝つから！」

### カバネ（朝・昼・夜）

- 誘ったとき：カバネ「は？　あーしも？　……しゃーない、荷物持ちくらいしてやるし」
- 戦闘の前：カバネ「〈呼び方〉、下がってな。こういうの、あーしの仕事だし」
- 勝ったあと：カバネ「ウケる、楽勝。……ほら、ケガ見せな」
- 負けたあと：カバネ「あーしがいて、これとか。マジないわ。……帰って、ごはんにしよ」

### ハクレン（朝）

- 誘ったとき：ハクレン「よかろう。〈呼び方〉を一人で行かせるよりは、安心だ」
- 戦闘の前：ハクレン「私の後ろにいろ、〈呼び方〉。……稽古の成果を見せてみろ」
- 勝ったあと：ハクレン「悪くない動きだった。……べ、別に、ほめたわけではない」
- 負けたあと：ハクレン「守りきれなかった。すまない。……明日の稽古は、少し長くする」

### イグニア（昼・夜）

- 戦闘の前：イグニア「……争いは、きらい。……でも、〈呼び方〉には、さわらせない」

## この文で使う変数（.ks にするときの参考）

| 変数 | 中身 |
|---|---|
| `f.item_*` | 素材と食料の数（`food`＝ごはん1回分の食料、`fish`、`shell`、`wood`、`fruit`、`herb`、`water`、`clay`、`ore`、`mushroom`、`stone`、`scale` など） |
| `f.gift_*` | 好物（`rainbow_shell`、`red_fruit`、`white_flower`、`fried_tofu`＝油揚げ） |
| `f.item_soy_seed` / `f.item_soy` | 大豆の種と大豆（油揚げの材料） |
| `f.hp` | 体力。戦闘に負けると −3（0 より下げない。`../design/battle.md` 7-4） |
| `f.wis` | 知恵。戦闘のめずらしい報酬の出やすさ（10% ＋ 知恵 × 5%、最大 50%。`../design/battle.md` 4-1） |
| `f.battle_result` | 戦闘の結果（`win` か `lose`）。「勝ったとき」「負けたとき」の文を分ける |
| `f.explore_partner` | 探索に誘ったヒロイン（空なら一人）。誘ったときの一言と、戦闘の相棒が決まる |
| `f.ev_<名前>` | 誘ったヒロインの段階。4 以上なら、〈呼び方〉を段階4のあとのものにする |
| `f.day` | 7 以上のとき、森-X1 の半分を森-X2 に置きかえる |
| `f.clue_*` | GM の手がかり（`tally_marks`、`old_diary`）。決戦の「言葉」の選択肢が増える |
| `f.explore_forest` | 森を探索した回数（3回で岩場が開く） |

素材の名前と数は `docs/game/system.md` の「島づくり（施設）」と合わせる。流木は木材（`f.item_wood`）として数える。

# 探索の結果の文（結果のカード）

作成：2026-10-16　／　状態：初稿

探索で出る、短い文の一覧。1回の探索で、下の「いつもの結果」から1つ、ときどき「めずらしい結果」か「出会い」か「小さな出来事」が1つ足される（`docs/game/system.md` の「探索の結果」）。

## 書き方の決まり

- 文は2〜4行。会話は1〜2行まで（サクサク）。
- 最後に【結果のカード】で、手に入れたものと上がった数値を出す。
- 数（×2 など）は目安。遊んで調整する。
- 同じ文が続けて出ないように、各エリアに「いつもの結果」を3つ以上用意する。
- 「出会い」は、そのヒロインがその場所にいそうな時間帯だけに絞っている（`outline.md` の「時間帯ごとに会えるヒロイン」の一部）。時間帯は見出しの（）に書く。

## 浜辺（最初から行ける）

### いつもの結果

**浜-1**
波打ちぎわを歩くと、打ち上げられた魚が、まだぴちぴちと跳ねていた。
【結果のカード】魚 ×2

**浜-2**
流木が、砂に半分うもれていた。乾いていて、家の材料にも使えそうだ。
【結果のカード】木材（流木） ×3

**浜-3**
岩のくぼみに、小さな貝がいくつも張りついている。
【結果のカード】貝殻 ×2、食料 ×1

### めずらしい結果

**浜-R1**
砂の中で、何かが光った。拾い上げると、虹色に光る大きな貝殻だった。
（カバネが好きそうだな）
【結果のカード】虹色の貝殻 ×1（カバネの好物）

### 出会い

**浜-E1（コノハ、朝・昼）**
コノハが、海に向かって石を投げていた。
コノハ「ユウ！　見て、五回はねた！　……あ、魚とるの、手伝ってくれる？」
【結果のカード】魚 ×3、コノハの好感度 +3

### 小さな出来事

**浜-X1**
足の裏に、ちくりと痛みが走った。尖った貝を踏んだらしい。
【結果のカード】体力 −1

## 森（最初から行ける）

### いつもの結果

**森-1**
倒れた木の枝を、何本か集めた。腕いっぱいになった。
【結果のカード】木材 ×3

**森-2**
甘い匂いをたどると、黄色い実がたくさんなっている木があった。
【結果のカード】果実 ×2、食料 ×1

**森-3**
木の根元に、見覚えのある形の草が生えていた。たぶん、薬草だ。
【結果のカード】薬草 ×2

### めずらしい結果

**森-R1**
ひときわ赤く、つやのある実を見つけた。夜の洞窟の、あの人の目の色に似ている。
【結果のカード】赤い果実 ×1（ノクティアの好物）

**森-R2**
小さな鳥がつついていたのは、豆のさやだった。……大豆、かもしれない。
（これがあれば、コノハの好きな、あれが作れる）
【結果のカード】大豆の種 ×1（畑に植えると、3日後に大豆がとれる）

### 出会い

**森-E1（カバネ、朝・昼）**
カバネが、大きな丸太を片手で引きずっていた。
カバネ「お、ちょうどいいとこに。こっち持って。……は？　重い？　ウケる」
【結果のカード】木材 ×5、カバネの好感度 +3

**森-E2（コノハ、朝・昼）**
コノハが、木の上から逆さまにぶら下がっていた。
コノハ「ユウ、ここの実、すっごく甘いよ！　はい、あーん！」
【結果のカード】果実 ×2、コノハの好感度 +3

### 小さな出来事

**森-X1**
茂みの奥で、低いうなり声がした。……何かが、こっちを見ている。
【戦闘：森の獣（大イノシシ）】（勝てば、食料 ×3。負けても、体力が減って拠点に戻るだけ）

## この文で使う変数（.ks にするときの参考）

| 変数 | 中身 |
|---|---|
| `f.item_*` | 素材と食料の数（`fish`、`shell`、`wood`、`fruit`、`herb`、`water`、`clay`、`ore`、`mushroom`、`stone`、`scale` など） |
| `f.gift_*` | 好物（`rainbow_shell`、`red_fruit`、`white_flower`、`fried_tofu`＝油揚げ） |
| `f.item_soy_seed` / `f.item_soy` | 大豆の種と大豆（油揚げの材料） |
| `f.hp` | 体力 |
| `f.wis` | 知恵 |
| `f.clue_*` | GM の手がかり（`tally_marks`、`old_diary`）。決戦の「言葉」の選択肢が増える |
| `f.explore_forest` | 森を探索した回数（3回で岩場が開く） |

素材の名前と数は `docs/game/system.md` の「島づくり（施設）」と合わせる。流木は木材（`f.item_wood`）として数える。

# 探索の結果の文（結果のカード）

作成：2026-10-16　／　更新：2026-10-17（森-X2、戦闘の勝ち負けの文と報酬、相棒を誘ったときの一言。初めてのエリア、岩-E1 の魚、誘ったときの得意な素材。確認役のレビューのあと：白い花を山-R1 に移して山-2 を足す、好物がだぶるときの決まり）　／　状態：初稿

探索で出る、短い文の一覧。1回の探索で、下の「いつもの結果」から1つ、ときどき「めずらしい結果」か「出会い」か「小さな出来事」が1つ足される（`docs/game/system.md` の「探索の結果」）。

## めずらしい結果の出方（2026-10-17 決定。`../design/life-bond.md` 1-1）

- **初めて探索したエリアでは、「いつもの結果」1つに加えて、そのエリアの「めずらしい結果」が必ず出る。**
- めずらしい結果（好物か手がかり）があるのは、浜辺・森・洞窟・山頂・沈没船の5つ。**めずらしい結果がないエリアは、川と岩場**。この2つは、初めてでもいつもどおり（いつもの結果1つと、ときどき出会いか小さな出来事）。
- 森は、1回目に赤い果実（森-R1）、2回目に大豆の種（森-R2）を必ず出す。
- 浜辺の初回（虹色の貝殻）は、2日目の決まった探索を数えない（3日目からの自分で選んだ浜辺の1回目）。
- 手がかりも同じ扱い：洞窟の初回は洞-X2（壁の線）、沈没船の初回は船-X1（日記）を必ず出す。山頂の初回は山-R1（白い花）を必ず出す。
- 2回目からのめずらしい結果の確率：**20% ＋ 知恵 × 5%**（知恵1で25%、知恵6で50%）。

### 好物がだぶるとき（2026-10-17 決定。`../plan.md`「好物がだぶるとき」）

- 好物、またはその途中の物を持っている間と、その人に渡したあとは、その好物が出る結果を出さない。**探索のめずらしい結果でも、戦闘のめずらしい報酬でも同じ。**
- 「途中の物」は、コノハの油揚げの材料（大豆の種・大豆）。大豆の種を一度畑に植えたら、そのあとは大豆の種を出さない（油揚げは1つだけで、2つ目はできない）。
- 好物ごとの「出さない」条件：

| 結果 | 出さないとき |
|---|---|
| 虹色の貝殻（浜-R1） | 虹色の貝殻を持っている、またはカバネに渡した |
| 赤い果実（森-R1） | 赤い果実を持っている、またはノクティアに渡した |
| 大豆の種（森-R2、森-X2 のめずらしい報酬） | 大豆の種・大豆・油揚げのどれかを持っている、大豆の種を畑に植えた、またはコノハに油揚げを渡した |
| 山頂の白い花（山-R1、山-X1 のめずらしい報酬） | 白い花を持っている、またはハクレンに渡した |

- 出さないときの代わり：
  - 探索のめずらしい結果：同じエリアのほかのめずらしい結果を出す。ほかにないときは、めずらしい結果なし（いつもの結果だけ）。
  - 戦闘のめずらしい報酬：各戦闘の「（めずらしい報酬：……）」の下に書いた「代わり」を出す。
- 「初めてのエリアで必ず出る」と「森の2回目で必ず出る」も、出さないときは出さない（代わりの決まりは上と同じ）。
- 変数：`f.visit_<エリア>`（行ったら1。名前は案）。森は `f.explore_forest`（回数）を使う。

## 書き方の決まり

- 文は2〜4行。会話は1〜2行まで（サクサク）。
- 最後に【結果のカード】で、手に入れたものと上がった数値を出す。
- 数（×2 など）は目安。遊んで調整する。
- 同じ文が続けて出ないように、各エリアに「いつもの結果」を3つ以上用意する（いまは岩場・山頂・沈没船が2つ。行ける日が少ないエリアなので、遊んで足りなければ足す）。
- 「出会い」は、そのヒロインがその場所にいそうな時間帯だけに絞っている（`outline.md` の「時間帯ごとに会えるヒロイン」の一部）。時間帯は見出しの（）に書く。

## 探索に相棒を誘ったとき

2026-10-17 の決まり（`../plan.md`「探索に相棒を誘う」、`../design/battle.md` 3-1）に合わせた一言。

- 探索を選んだあと、「一人で行く／誘う」を選ぶ。誘えるのは、その時間帯に会えるヒロイン1人（`daily/README.md` の表）。誘うと、その回の「過ごす」はできない。
- 誘ったときの好感度：+3（誘ったヒロイン。`../design/affection.md` 2章 D）。段階のイベントは起きない。
- 誘ったヒロインの「出会い」の結果は、その回には出ない（引いたら、引き直す）。本人と一緒にいるのに、本人と出会う文になるのを防ぐため。
- 出すところ：「誘ったとき」は出発のとき。結果が戦闘のときだけ、「戦闘の前」「勝ったあと」「負けたあと」を足す。戦闘でない結果のときは「誘ったとき」だけ。
- 〈呼び方〉は、段階4の前と後で変える。

| ヒロイン | 段階4の前 | 段階4のあと |
|---|---|---|
| ノクティア | 坊や | ユウ |
| コノハ | ユウ | ユウ（変わらない） |
| カバネ | アンタ | ユウっち |
| ハクレン | 貴殿 | ユウ |
| イグニア | 人の子 | ユウ |

### 誘ったときの得意な素材（2026-10-17 決定。`../design/life-bond.md` 2-3）

誘うと、いつもの結果などとは別に、その人の得意な素材が必ず1つ足される。結果のカードに、次の1行を足す（戦闘のときは、勝っても負けても足す。案）。

| ヒロイン | 結果のカードの1行 |
|---|---|
| カバネ | カバネが丸太を運んでくれた：木材 ×3 |
| ハクレン | ハクレンが薪を割ってくれた：木材 ×2 |
| コノハ | コノハが魚をとってくれた：魚 ×2 |
| イグニア | イグニアが、においで粘土を見つけてくれた：粘土 ×3 |
| ノクティア | ノクティアが薬草を摘んでくれた：薬草 ×2 |

- 石材は足さない（石材の要る施設は、岩場が開いてから。`../system.md`）。

### ノクティア（夜。雨の日は昼も）

- 誘ったとき：ノクティア「あら、夜のお散歩？　〈呼び方〉のお誘いなら、付き合ってあげる」
- 戦闘の前：ノクティア「下がっていて、〈呼び方〉。……嘘よ。隣にいてちょうだい」
- 勝ったあと：ノクティア「ふふ、よくできました。……怪我はない？　見せてごらんなさい」

## この文で使う変数（.ks にするときの参考）

| 変数 | 中身 |
|---|---|
| `f.item_*` | 素材と食料の数（`food`＝ごはん1回分の食料、`fish`、`shell`、`wood`、`fruit`、`herb`、`water`、`clay`、`ore`、`mushroom`、`stone`、`scale` など） |
| `f.gift_*` | 好物（`rainbow_shell`、`red_fruit`、`white_flower`、`fried_tofu`＝油揚げ）。1の間は、その好物の結果を出さない（油揚げのときは大豆の種も） |
| `f.item_soy_seed` / `f.item_soy` | 大豆の種と大豆（油揚げの材料）。どちらかが1以上の間は、大豆の種の結果を出さない |
| `f.soy_plant_day` | 大豆の種を植えた日（0は植えていない。名前は案。`gifts.md`）。0でなければ、大豆の種の結果を出さない |
| `f.hp` | 体力。戦闘に負けると −3（0 より下げない。`../design/battle.md` 7-4） |
| `f.wis` | 知恵。戦闘のめずらしい報酬の出やすさ（10% ＋ 知恵 × 5%、最大 50%。`../design/battle.md` 4-1） |
| `f.battle_result` | 戦闘の結果（`win` か `lose`）。「勝ったとき」「負けたとき」の文を分ける |
| `f.explore_partner` | 探索に誘ったヒロイン（空なら一人）。誘ったときの一言と、戦闘の相棒が決まる |
| `f.ev_<名前>` | 誘ったヒロインの段階。4 以上なら、〈呼び方〉を段階4のあとのものにする |
| `f.day` | 7 以上のとき、森-X1 の半分を森-X2 に置きかえる |
| `f.clue_*` | GM の手がかり（`tally_marks`、`old_diary`）。決戦の「言葉」の選択肢が増える |
| `f.explore_forest` | 森を探索した回数（3回で岩場が開く。1回目に森-R1、2回目に森-R2 を必ず出す） |
| `f.visit_<エリア>` | そのエリアに行ったら1（`beach`、`river`、`cave`、`rock`、`summit`、`ship`。名前は案）。0のときは、めずらしい結果（手がかり）を必ず出す。浜辺は2日目の決まった探索では1にしない |
| `f.gave_*` | 渡した好物（`gifts.md`）。渡したあとは、その好物の結果（探索のめずらしい結果・戦闘のめずらしい報酬）を出さない。`f.gave_fried_tofu` ＝ 1 のあとは、大豆の種も出さない。岩-E1 で魚をあげると `f.gave_fish` ＝ 1 |

素材の名前と数は `docs/game/system.md` の「島づくり（施設）」と合わせる。流木は木材（`f.item_wood`）として数える。

## 前半：力の勝負

【戦闘：決戦（前半）】
- 敵：GM（中央）、幻影 ×2（相棒の「失ったもの」の形）
- 味方：ユウ、相棒（全員のときは6人）
- 島の発展度が低いと、GM の攻撃で主人公の行動が減る（`system.md`）
- 幻影を倒すと、絆ゲージがたまる
- GM の「支配の力」が半分になったら、中盤へ
- 前半が終わったとき、主人公の戦闘の心が0なら `f.final_mind_zero = 1`（後半の判定 −1）

## この台本で使う変数

| 変数 | 使い方 |
|---|---|
| `f.partner` | 相棒。台詞と、進むエンドが変わる |
| `f.partner_wavering` | 1 のとき、中盤で必ず幻に負ける |
| `f.<相棒>_resolve` | 1 のとき（段階5）、中盤ではっきり断る |
| `f.ev_<相棒>` | 4 以上のとき、中盤で迷う（言葉しだい） |
| `f.misaki_answer` | 後半のカイの台詞 |
| `f.mind` | 後半の判定値のもと。判定値が2以下だと、後半で選択肢が1つしか出ない |
| `f.final_mind_zero` | 1 のとき（前半の終わりに戦闘の心が0）、後半の判定値 −1 |
| `f.clue_old_diary` / `f.clue_tally_marks` | 判定値が3以上なら、後半の選択肢が増える |
| `f.ignia_awake` | イグニアの竜の姿の大技 |
| `f.dev` | 島の発展度。4 以上なら、中盤で言葉をまちがえても1回だけ選び直せる（`../design/battle.md` 5-2） |
| `f.final_retry_used` | 中盤で選び直したら 1（選び直しは1回だけ） |
| `f.battle_state` | 前半の終わりの状態。中盤・後半で絆ゲージを足す。決着のやり直しにも使う（`../design/battle.md` 7-3） |

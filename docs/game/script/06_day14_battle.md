# 台本：14日目「決戦」

作成：2026-10-16　／　状態：初稿

書き方の決まりは `00_prologue_day1.md` と同じ。戦闘の画面としくみは `docs/game/battle-ui.md`、流れは `docs/game/outline.md` の「14日目：決戦」。

- 戦闘の場面は【戦闘：……】で書く。`.ks` では `IslandBattle.start()`（`game/tyrano-proto/`）を呼ぶ。決戦用の設定（中盤・後半の割り込み）は、試作に足す必要がある（未作成）。
- 相棒（`f.partner`）ごとに台詞が変わるところは、表にした。
- 「迷いのある相棒」（`f.partner_wavering = 1`）のときは、中盤で、段階3以下と同じ扱いになる。
- 呼び方：相棒の台詞は、段階4を見たあとの呼び方で書いている。「迷いのある相棒」のときは、段階4の前の呼び方（「坊や」「アンタ」「貴殿」「人の子」）にする。

## この台本で使う変数

| 変数 | 使い方 |
|---|---|
| `f.partner` | 相棒。台詞と、進むエンドが変わる |
| `f.partner_wavering` | 1 のとき、中盤で必ず幻に負ける |
| `f.<相棒>_resolve` | 1 のとき（段階5）、中盤ではっきり断る |
| `f.ev_<相棒>` | 4 以上のとき、中盤で迷う（言葉しだい） |
| `f.misaki_answer` | 後半のカイの台詞 |
| `f.mind` | 低いと、後半で選択肢が1つしか出ない |
| `f.clue_old_diary` / `f.clue_tally_marks` | 後半の選択肢が増える |
| `f.ignia_awake` | イグニアの竜の姿の大技 |

## 決めていないこと

- 決戦用の戦闘の数字（HP、攻撃力、支配の力）。遊んで調整する。
- 「心」の値がいくつ以下だと、後半で選択肢が1つになるか。

## 書き方の決まり

- 地の文は主人公（ユウ）の一人称。
- 台詞は `名前「……」`。主人公の心の声は `（……）`。
- 演出の指示は `【 】` で書く。背景、立ち絵、BGM、効果音など。`.ks` にするときに置き換える。

- 主人公の名前は、プレイヤーが変えられる。台本では「ユウ」と書く。

## プロローグ

【背景：黒】
【効果音：雨、遠くの車の音】

終電を降りたとき、雨はもう、傘をさしても意味がないくらいになっていた。

それでも、足どりは軽かった。

上着の内ポケットには、小さな箱が入っている。三か月分の残業代で買った指輪だ。

（今日は、ミサキの誕生日だから）

付き合って五年。同棲して二年。「仕事が落ち着いたら」と言い続けて、ずいぶん待たせてしまった。

本当は、今夜も会社に泊まるはずだった。先輩に押しつけられた仕事を、無理やり終わらせて、走って帰ってきた。驚かせたかった。

【背景：アパートの玄関・夜】
【効果音：鍵を開ける音】

ユウ「ただいま。ミサキ、起きてる？」

返事はなかった。

玄関に、ミサキのサンダルが脱ぎ捨ててある。その隣に、見覚えのある、男物の革靴。

（……この靴）

会社の先輩の靴だ。いつも「いい靴は男の名刺だ」と自慢している、あの人の。

奥の部屋から、ミサキの笑い声がした。

聞いたことのない、甘い声だった。

【効果音：心臓の音】

寝室のドアが、少しだけ開いている。

その隙間から見えたものを、俺は、最後まで見ることができなかった。

ミサキ「……ユウ？」

ドアの向こうで、ミサキが息をのむ音がした。

先輩「おい、今日は帰らないって言ってたろ……」

【効果音：心臓の音（速く）】

胸が、つぶれるように痛い。

息が吸えない。視界が、端のほうから黒くなっていく。

（ああ、そうか）

（俺が会社で寝ているあいだ、ずっと、こうだったんだ）

上着のポケットから、小さな箱がこぼれ落ちて、床を転がっていく。

膝から力が抜けた。冷たい床が、頬に当たる。

ミサキ「ユウ！　ねえ、ユウ！？」

遠くで、誰かが叫んでいる。

（もう少し、ちゃんと、生きてみたかったな）

（ちゃんと、誰かに、大事にされてみたかった）

【効果音：音が消える】

【BGM：静かな波の音】

……波の音がする。

まぶたの裏が、明るい。

【背景：浜辺・朝】

目を開けると、空が青かった。

体を起こす。雨に濡れたスーツのまま、ネクタイは首に引っかかっているだけ。財布もスマホもない。内ポケットの指輪の箱も、なくなっていた。

ユウ「夢じゃない、のか」

## 1日目

### 出会い：コノハ

【効果音：茂みが揺れる】
【立ち絵：コノハ（驚き）】

コノハ「わっ！　動いた！」

茂みから飛び出してきたのは、橙色の髪の女の人だった。

頭の上で、大きな三角の耳がぴんと立っている。腰のうしろでは、ふさふさのしっぽが一本、ぶんぶん揺れている。

（耳。しっぽ。……本物？）

コノハ「生きてる！　ねえ、生きてるよね！？　昨日の夜から、ずーっと浜に倒れてたんだよ。ボク、死んでるのかと思って、何回もつっついちゃった」

ユウ「つっついた……？」

コノハ「うん！　枝で！」

【立ち絵：コノハ（笑顔）】

悪びれもせずに笑う。

ユウ「あの、ここは……。それに、君は」

コノハ「ボクはコノハ！　狐だよ。見れば分かるでしょ？」

そう言って、くるりと回ってしっぽを見せる。

コノハ「で、ここは島。名前はないんだけど、みんなは『流れつきの島』って呼んでる」

ユウ「流れつきの島……」

コノハ「うん。いろんなところから、いろんなのが流れつくの。ボクもそう。キミもそうでしょ？」

（いろんなところから……）

（俺は、死んだ。それで、ここに流れついた？）

コノハの耳が、少しだけ下がった。

コノハ「じゃあ、ここに来られてよかったね。……ボクもね、前のところには、もう帰れないんだ」

ほんの一瞬、さびしそうな顔をして、すぐに笑顔に戻る。

【立ち絵：コノハ（笑顔）】

【選択2のとき】

ユウ「……よく分からない。気づいたら、ここにいた」

コノハ「みんな最初はそう言うよ。だいじょうぶ、そのうち分かるから！」

【合流】

コノハ「ねえ、名前は？」

ユウ「ユウ。……ユウだ」

コノハ「ユウ！　いい名前！　ねえユウ、おなかすいてない？　すいてるよね！　あっちにみんないるから、行こ！」

ユウ「みんな？」

答える前に、コノハは俺の手をつかんで走り出していた。

（力、強いな……！）

### 出会い：カバネ

【背景：森の中の広場・昼】
【BGM：明るい日常の曲】

森を抜けた先に、小さな広場があった。

大きな木の根元に、葉っぱで屋根をかけただけの小屋がある。その前で、誰かが太い丸太を肩にかついでいた。

【立ち絵：カバネ（普通）】

白に近い金髪。日焼けした肌。長いつけまつげ。へそを出した服から伸びた腕に、骨の形をした模様が、ぐるりと彫られている。

（タトゥー……？　というか、あの丸太、俺の胴より太いぞ）

カバネ「お、コノハ。……って、誰それ。拾ったん？」

コノハ「拾った！」

ユウ「拾われた……のか」

カバネ「ウケる」

【立ち絵：カバネ（笑い）】

ドン、と丸太を地面に下ろして、その人は俺を上から下まで眺めた。

カバネ「スーツじゃん。ガチの人間？　うわ、人間とか何十年ぶりに見たし」

ユウ「何十年……？」

カバネ「あーしはカバネ。ガシャドクロ。知らん？　まあいいや。で、アンタは？」

ユウ「ユウです。……ガシャドクロって、あの、大きい骸骨の妖怪の」

【立ち絵：カバネ（不機嫌）】

カバネの笑顔が、すっと消えた。

カバネ「……あーしは、あーし。骸骨とかじゃねーし」

（まずいことを言ったかもしれない）

▼選択
- 「ごめん。カバネさん、だよな」 → カバネ +3
- 「でも、その腕の模様、骨だよな？」 → カバネ -2

【選択1のとき】

ユウ「ごめん。カバネさん、だよな」

カバネ「……ん。分かればいーし。あと『さん』いらない。キモい」

【立ち絵：カバネ（普通）】

ぶっきらぼうな声だったけれど、少しだけ、口元がゆるんだ気がした。

【選択2のとき】

ユウ「でも、その腕の模様、骨だよな？」

カバネ「は？　これはファッションだし。……アンタ、デリカシーとか、前の世界に置いてきたん？」

【立ち絵：カバネ（普通）】

カバネはふいと顔をそむけた。

【合流】

カバネ「とりま、腹へってんでしょ。魚焼いてあっから、食べな」

ユウ「いいのか？」

カバネ「いいもなにも、ここで飢え死にされたら寝覚め悪いし」

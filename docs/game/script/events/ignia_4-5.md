# 個別イベント：イグニア（段階4〜5）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：昼か夜に「イグニアと過ごす」を選んだとき、いまの好感度に +5 を足すと70・90に届いていて、その段階をまだ見ていなければ、会話の代わりに起きる。段階4は、段階3を見たあと。段階5は、8日目の中間発表のあと（9日目以降）にだけ起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」も出す（例：「イグニアの好感度 +5（会えた分）＋6」）。段階4・5には「+8（心が近づいた）」はない。選択のない段階5は「+5（会えた分）」だけ。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 呼び方：段階4の途中で、「人の子」から「ユウ」に変わる。
- GM の正体（人間の転生者）は、13日目まで伏せる。13日目より前に起きた場合も、「あの声の主」と呼ぶ。
- 段階4は成人向けにしない。段階5の［成人向け］は、位置だけを示す。

---

## 段階4（好感度70）：この島を、あなたに返したい

【日付：○日目・夜】
【背景：岩場・夜】
【BGM：静かな曲】
【立ち絵：イグニア（眠り）】

イグニアは、いつもより深く眠っていた。呼んでも、肩をゆすっても、目を覚まさない。

（……封印に、力を吸われているんだ）

イグニアの手が、冷たかった。竜の体温とは思えないほど。

ユウ「イグニア。起きてくれ」

ユウ「言いたいことがあるんだ」

【立ち絵：イグニア（ぼんやり）】

イグニア「……人の子……？」

ユウ「この島は、イグニアのものだ。何千年も、一人で守ってきた場所だ」

ユウ「俺は、この島を、イグニアに返したい。……あいつから、取り返して」

イグニア「……返す」

イグニアは、その言葉を、口の中で、何度か転がした。

イグニア「……誰かに、何かを返してもらうの、初めて」

▼選択
- 「呼んでくれて、ありがとう。この島に」 → イグニア +8、`f.ignia_s4 = 1`
- 冷たい手を、両手で包む → イグニア +6、`f.ignia_s4 = 2`

【選択1のとき】

イグニア「……わたしが、呼んだわけじゃない。……あの声の主の、ゲーム」

ユウ「それでもだ。待っててくれたのは、イグニアだろ」

イグニア「……うん」

【選択2のとき】

包んだ手が、少しずつ、温かくなっていく。

イグニア「……あったかい」

【合流】

【画面：イグニアの目が、金色に強く光る】
【立ち絵：イグニア（真剣）】

イグニアの目が、初めて、はっきりと開いた。眠そうな影が、どこにもなかった。

イグニア「……ユウ」

イグニア「……目が、覚めた。……封印が、少しだけ、ゆるんだ」

【画面表示：イグニアの呼び方が「ユウ」になった】
【画面表示：イグニアには、GM の「喪失の幻」が効きにくくなった。決戦で、竜の姿に戻れるようになった】

## 段階5（好感度90）：結ばれる

【背景：岩場・夜（星空）】
【BGM：やさしい曲】
【立ち絵：イグニア（照れ）】

イグニア「ユウ。……背中に、乗って」

イグニアの背中に、大きな翼が広がった。まだ、ほんの少しのあいだだけしか、飛べない。

それでも、イグニアは、島の上を、ゆっくりと一周した。

【画面：夜の島を、上から見下ろす】

イグニア「……ここが、わたしの島。……ユウのいる島」

イグニア「……あの声の主は、わたしには、何も約束しなかった。……でも、ほしいものは、もう、ある」

岩場に降りると、イグニアは、俺の胸に額を押しつけた。

イグニア「……ユウ。ずっと、いて」

［成人向け］（イグニアとの場面。位置だけを決めておき、中身は別に作る）

【背景：岩場・夜明け】

イグニアは、俺の腕の中で、ひさしぶりに、ぐっすり眠っていた。今度の眠りは、封印のせいではなかった。

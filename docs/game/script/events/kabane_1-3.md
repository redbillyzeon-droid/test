# 個別イベント：カバネ（段階1〜3）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：「カバネと過ごす」を選んだとき（朝・昼・夜）、いまの好感度に +5 を足すと段階の値（10・30・50）に届いていて、その段階をまだ見ていなければ、会話の代わりに起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」と「+8（心が近づいた）」も出す（例：「カバネの好感度 +5（会えた分）＋8（心が近づいた）＋4」）。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 呼び方：段階3までは「アンタ」。段階4で「ユウっち」に変わる。
- 4日目の嵐のあとの夜の会話（`../02_day4_storm.md`）とは別の場面。

---

## 段階1（好感度10）：みんなのごはん

【日付：○日目・昼】
【背景：拠点・昼】
【立ち絵：カバネ（普通）】

カバネが、焚き火の上の鍋をかき混ぜていた。魚と、森のきのこと、よく分からない葉っぱが入っている。

カバネ「味見して。……ほら、口開けな」

ユウ「……うまい」

カバネ「でしょ。あーし、料理だけは自信あんの」

カバネ「みんなで食べるごはんが、いちばんうまいんだよね。一人で食べると、なんか、味しないし」

▼選択
- 「毎日、カバネのごはんが食べたい」 → カバネ +4
- 「片づけは、俺がやるよ」 → カバネ +3

【選択1のとき】

カバネ「……は？　なに、それ。プロポーズ？　ウケる」

カバネは、鍋に目を落とした。耳まで、赤くなっていた。

カバネ「……ま、作ってやらなくもない」

【選択2のとき】

カバネ「お、分かってんじゃん。じゃ、よろしく」

【合流】

## 段階2（好感度30）：貝殻の首飾り

【背景：浜辺・夕方】
【立ち絵：カバネ（照れ）】

浜辺で、カバネが、貝殻に小さな穴をあけていた。

カバネ「……なに。見てんなし」

ユウ「首飾り？」

カバネ「そ。かわいいっしょ。……あーし、こういうの、好きなの」

カバネは、出来上がった首飾りを、自分の首にあてて、それから、ふいに外した。

ユウ「つけないのか？」

カバネ「……鏡、ないし。似合ってるか、分かんないし」

（そういえば、カバネは、水たまりも、のぞきこまない）

▼選択
- 「似合ってる」と言う → カバネ +5
- 「俺が鏡の代わりになる」と言う → カバネ +4

【選択1のとき】

カバネ「……テキトーに言ってんでしょ」

ユウ「本気で言ってる」

カバネ「……そ」

カバネは、もう一度、首飾りをつけた。

【選択2のとき】

カバネ「……は？　クサ。……でも、ちょっとウケた」

カバネは、首飾りをつけて、俺の前で、くるりと回った。

カバネ「……どう？」

ユウ「似合ってる」

【合流】

カバネ「……これ、もう一個作ってあるんだけど。アンタの分」

カバネは、俺の手に、小さな貝殻の首飾りを押しつけて、さっさと歩いていった。

【結果のカード】
貝殻の首飾り を手に入れた
カバネの好感度が上がった

## 段階3（好感度50）：失ったもの（人間だった自分と、名前）

【背景：浜辺・夜】
【BGM：静かな曲】
【立ち絵：カバネ（悲しみ）】

カバネは、波打ちぎわで、自分の腕のタトゥーを、指でなぞっていた。

カバネ「……アンタさ。あーしが、もとは人間だったって言ったら、信じる？」

ユウ「……信じる」

カバネ「即答とか、ウケる」

カバネは、笑わなかった。

カバネ「あーし、戦の時代の、ちっちゃい村の娘だったの。……たぶん。もう、よく覚えてない」

カバネ「村が焼かれて、あーしも死んで。そのへんに転がってた、ほかの人の骨と一緒に、ぐちゃぐちゃに集まって、でっかい骸骨になった」

カバネ「それが、ガシャドクロ。あーしは、その中の、ひとかけら」

カバネは、腕のタトゥーを見せた。骨の模様の、すき間に、小さな花の形が彫ってあった。

カバネ「これ、人間だったころの、最後のやつ。……なんで彫ったのかも、覚えてない」

カバネ「名前も、忘れちゃった。カバネってのは、骸（かばね）。あとで、自分でつけた」

カバネ「で、何百年もそのへんをうろついてたら、陰陽師ってやつに祓われてさ。骨が、ばらばらに砕けて」

カバネ「……気づいたら、この島にいた。人の姿で。ウケるっしょ」

カバネ「嵐のとき、腕、見たっしょ。あれの、もっとでかいのが、あーしの本当の姿」

（4日目の嵐は固定イベントなので、段階3の時点では必ず見ている）

【分岐：8日目の中間発表を見たあとかどうか】

【見たあとのとき】

カバネ「あの声、言ってたよね。勝てば人間に戻してやるって。名前も返してやるって」

カバネ「……そんなの、欲しいに決まってんじゃん」

【見る前のとき】

カバネ「人間に戻れたら、名前も思い出せんのかな。……なんてね」

【合流】

▼選択
- 「カバネは、今のカバネのままでいい」 → カバネ +4
- 「その花の模様、きれいだな」と言う → カバネ +6、`f.kabane_flower = 1`

【選択1のとき】

カバネ「……簡単に言うなし」

カバネは、そう言いながら、少しだけ、肩の力を抜いた。

【選択2のとき】

カバネ「…………」

カバネは、しばらく黙って、自分の腕の花を見下ろした。

カバネ「……これ、ほめられたの、初めて。……人間だったころは、知らないけど」

カバネ「……アンタ、ほんと、変なやつ」

【合流】

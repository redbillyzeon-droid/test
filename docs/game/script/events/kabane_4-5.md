# 個別イベント：カバネ（段階4〜5）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：「カバネと過ごす」を選んだとき（朝・昼・夜）、好感度が70・90に届いていて、その段階をまだ見ていなければ起きる。段階4は、段階3を見たあと。
- 呼び方：段階4の途中で、「アンタ」から「ユウっち」に変わる。
- カバネの本当の名前は未定（利用者の判断待ち）。台本では「（本当の名前）」と書く。
- 段階4は成人向けにしない。段階5の［成人向け］は、位置だけを示す。

---

## 段階4（好感度70）：本当の姿

【日付：○日目・夜】
【背景：岩場・夜】
【BGM：静かな曲】
【立ち絵：カバネ（普通）】

カバネ「……アンタ、ちょっと付き合って。誰もいないとこ」

岩場のいちばん奥まで来ると、カバネは、こっちを振り向かずに言った。

カバネ「あーしの、全部。……見せる」

カバネ「逃げたら、それでいい。……怒んないから」

【画面：白く光る】
【効果音：骨がきしむ、大きな音】

目の前に、白い骨の壁が、そびえ立った。

見上げても、てっぺんが見えない。月を隠すほどの、巨大な骸骨。

暗い眼窩の奥で、小さな光が、ふたつ、揺れていた。

（……これが、カバネ）

▼選択
- 「でかくて、かっこいい」 → カバネ +8
- 骨の指に、そっと手をあてる → カバネ +6

【選択1のとき】

ユウ「……でかいな。それに、かっこいい」

骸骨の、指の先が、ぴくりと動いた。

【選択2のとき】

骨の指は、ひんやりとしていて、ところどころ、ざらついていた。

その指が、ほんの少しだけ、震えた。

【合流】

【画面：光が消える】
【立ち絵：カバネ（悲しみ）】

気づくと、いつものカバネが、岩の上に座りこんでいた。

カバネ「……逃げなかったし」

カバネ「……マジで、逃げなかったし。ウケる。……全然、ウケないけど」

カバネの目から、ぽろぽろと涙がこぼれていた。

【分岐：段階3で花の模様をほめたか（`f.kabane_flower`）】

【ほめたとき】

ユウ「カバネ。その腕の花、何の花か、一緒に調べよう。……名前の手がかりになるかもしれない」

カバネ「……覚えてたんだ」

【ほめていないとき】

ユウ「カバネ。腕の、その小さな花。……名前の手がかりになるかもしれない。一緒に探そう」

【合流】

カバネ「……うん。……ユウっち」

（呼び方が、変わった）

【画面表示：カバネの呼び方が「ユウっち」になった】
【画面表示：カバネには、GM の「喪失の幻」が効きにくくなった】

## 段階5（好感度90）：結ばれる

【背景：浜辺・夜】
【BGM：やさしい曲】
【立ち絵：カバネ（照れ）】

カバネ「ユウっち。……あの花、分かったかも」

カバネ「山の上に、同じのが咲いてた。……見たら、急に、思い出したの」

カバネ「あーしの名前。……（本当の名前）」

カバネ「……呼んでみて」

ユウ「（本当の名前）」

カバネ「……っ」

カバネは、顔を両手で覆った。

カバネ「……あの声は、勝てば、人間に戻してやるって言った。名前も返すって」

カバネ「でも、名前は、ユウっちが見つけてくれた。……だから、人間には戻らない」

カバネ「骨でも、でかくても、あーしはあーし。……ユウっちが、そう言ったんじゃん」

カバネ「……だから、責任とってよね」

［成人向け］（カバネとの場面。位置だけを決めておき、中身は別に作る）

【背景：浜辺・夜明け】

朝の光の中で、カバネは、貝殻の首飾りを二つ並べて、眺めていた。

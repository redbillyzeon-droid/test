# 個別イベント：コノハ（段階1〜3）★メインヒロイン

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：朝か昼に「コノハと過ごす」を選んだとき、いまの好感度に +5 を足すと段階の値（10・30・50）に届いていて、その段階をまだ見ていなければ、会話の代わりに起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」と「+8（心が近づいた）」も出す（例：「コノハの好感度 +5（会えた分）＋8（心が近づいた）＋4」）。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 心の1行：段階3の結果のカードの最後に「ユウの心が、少し強くなった」と出す（数字は出さない。`f.mind` +1 に合わせる。段階1・2には出さない）。文は 2026-10-17 の決定のまま（`../../plan.md` の「心（`f.mind`）の見せ方」）。`../ui_text.md` 6章。
- しっぽの数（立ち絵の差分）：最初は1本。段階1で2本、段階2で3本、段階3は3本のまま、段階4で4本、段階5で5本。段階1〜3の本数は 2026-10-16 にこの台本で決めた（`../../characters.md` は「最大5本」、`../../outline.md` は「段階4で4本」）。
- 呼び方：最初から「ユウ」。

## 段階1（好感度10）：釣り勝負

【日付：○日目・朝】
【背景：浜辺・朝】
【立ち絵：コノハ（笑顔）】

コノハ「ユウ！　釣り勝負しよ！　負けたほうが、今日のお皿洗い！」

ユウ「釣り竿もないのに？」

コノハ「ボクは手で取るの！　ユウは、なんでもいいよ！」

それから一時間。コノハは、海に飛びこんでは、魚をくわえて……いや、手に持って、上がってきた。

俺は、木の枝に蔓を結んだ竿で、小さい魚を一匹だけ釣った。

コノハ「ボクの勝ち！　七対一！」

ユウ「……完敗だ」

コノハ「えへへ。でもね、ユウの魚、いちばんきれいな色してる」

▼選択
- 「コノハはすごいな」とほめる → コノハ +4
- 「次は負けない」と言う → コノハ +2

【選択1のとき】

コノハ「……っ！」

コノハの耳が、ぴんと立った。

コノハ「ほ、ほめられた……。ボク、ほめられたの、いつぶりだろ」

【画面：コノハのしっぽが2本になる（光って増える演出）】

ユウ「……コノハ、しっぽ、増えてないか？」

コノハ「え？　あ、ほんとだ！　なんで！？」

【選択2のとき】

コノハ「ふふーん。何回でも勝つもんね！」

【画面：コノハのしっぽが2本になる】

コノハ「……あれ？　しっぽ、増えてる？」

【合流】

【結果のカード】
魚 ×8 を手に入れた
コノハの好感度が上がった（しっぽ：2本）

## 段階2（好感度30）：油揚げの話

【背景：拠点・昼】
【立ち絵：コノハ（普通）】

昼ごはんのあと、コノハが、ぽつりと言った。

コノハ「ねえユウ。油揚げって、知ってる？」

ユウ「知ってるよ。豆腐を揚げたやつだろ」

コノハ「知ってるの！？　すごい！　ボク、社にいたころ、お供え物でもらうのが、いちばんの楽しみだったの」

コノハ「甘くて、じゅわってして……。この島には、ないんだよね」

（大豆があれば、豆腐から作れるかもしれない）

▼選択
- 「いつか作ってやる」と約束する → コノハ +5、`f.promise_tofu = 1`
- 「この島じゃ、無理かもな」と言う → コノハ +1

【選択1のとき】

コノハ「ほんと！？　約束！　ゆびきり！」

コノハは、小指を突き出した。

【画面：コノハのしっぽが3本になる】

コノハ「……また増えた。ユウといると、しっぽ、どんどん増えるね」

【次にやること：森で「大豆の種」を探して、畑に植えると、油揚げの材料になる】

【選択2のとき】

コノハ「……そっか。そうだよね」

コノハは、笑ったまま、耳だけ少し下げた。

【画面：コノハのしっぽが3本になる】

【合流】

## 段階3（好感度50）：失ったもの（社）

【背景：森の奥・昼】
【BGM：静かな曲】
【立ち絵：コノハ（真面目）】

コノハは、森の奥の、小さな岩の前にしゃがんでいた。

岩の前に、拾った花と、木の実が、きれいに並べてある。

ユウ「コノハ。それは？」

コノハ「……お社の、まね。ボクが作ったの」

コノハ「ボクね、稲荷の社の見習いだったの。毎朝、お掃除して、お供え物を並べて」

コノハ「でもね、ある冬に、大事な鏡を割っちゃったの。ご神体の。……お掃除しようとして、手がすべって」

コノハ「みんな、すっごく怒って。『役立たずは出ていけ』って」

コノハは、並べた木の実を、指でそっと直した。

コノハ「雪の山を、ずっと歩いたの。どこにも、帰るところがなくて。……それで、雪の中で、眠くなって」

コノハ「起きたら、この島の浜にいた」

【分岐：8日目の中間発表を見たあとかどうか】

【見たあとのとき】

コノハ「あの声、勝てば社に戻してやるって、言ってたね」

コノハ「……戻りたいって、ずっと思ってた。でも、戻ったら、またいつか、追い出されるのかな」

【見る前のとき】

コノハ「……戻れたらいいなって、ずっと思ってたの」

【合流】

コノハ「ボク、役に立たないと、また、捨てられちゃう気がするの。だから、いっぱい魚とって、いっぱい走って……」

▼選択
- 「コノハは、もう十分すぎるくらい、役に立ってる」 → コノハ +4
- 何も言わずに、手作りの社に、自分も木の実を一つ供える → コノハ +6

【選択1のとき】

コノハ「……ほんと？」

ユウ「本当だ。コノハがいなかったら、俺は初日に飢え死にしてた」

コノハ「……えへへ。それは、そうかも」

【選択2のとき】

コノハは、目を丸くして、俺と木の実を交互に見た。

コノハ「……ユウ」

コノハは、何か言おうとして、やめて、俺の袖をぎゅっとつかんだ。

【合流】

（しっぽは3本のまま。「役に立たなくても、ここにいていい」と伝えるのは、段階4）

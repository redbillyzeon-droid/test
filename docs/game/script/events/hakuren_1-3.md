# 個別イベント：ハクレン（段階1〜3）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 山頂がまだ開いていなくても、段階3の場面ではハクレンが山頂へ案内する（イベントのときだけの例外。探索のエリアとしては開かない）。
- 起きる条件：朝に「ハクレンと過ごす」か「鍛える（稽古）」を選んだとき、いまの好感度に +5 を足すと段階の値（10・30・50）に届いていて、その段階をまだ見ていなければ、会話（稽古のときは稽古の結果）の代わりに起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。
- 稽古でイベントが起きたとき：好感度は「過ごす」と同じに数える（+5 ＋ 段階ボーナス ＋ 選択の値。稽古の +3 は足さない）。そのうえで、稽古の分の力 +1 と稽古の回数（`f.train_count`）+1 も足す（`../../system.md`）。段階1の「もう一回」の力 +1 は、これとは別に足す。
- 好物つき（2026-10-17 決定。`../gifts.md`、`../../design/life-bond.md` 1-4）：［好物を渡して過ごす］を選んだときは、判定を「いまの好感度 ＋ 5 ＋ 10」にする。渡す短い文のあとにイベントを出し、上がる値に +10（好物）を足す。同じ人には1回だけ。稽古では渡せない（二人きりの「過ごす」のときだけ）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」と「+8（心が近づいた）」も出す（例：「ハクレンの好感度 +5（会えた分）＋8（心が近づいた）＋4」）。稽古で起きたときは「力 +1」も出す。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 心の1行：段階3の結果のカードの最後に「ユウの心が、少し強くなった」と出す（数字は出さない。`f.mind` +1 に合わせる。段階1・2には出さない。稽古で起きたときにも出す）。文は 2026-10-17 の決定のまま（`../../plan.md` の「心（`f.mind`）の見せ方」）。`../ui_text.md` 6章。
- 呼び方：段階3までは「貴殿」。段階4で「ユウ」に変わる。
- かわいいものが好きだが、隠している（`../../characters.md`）。

## 段階1（好感度10）：最初の稽古

【日付：○日目・朝】
【背景：浜辺・朝】
【立ち絵：ハクレン（真剣）】

ハクレン「構えろ。……違う。腰が高い。それでは、風で倒れる」

木の枝を握らされて、もう三十回は、砂に転がされていた。

ハクレン「貴殿は弱い。力もない。速さもない」

ユウ「……知ってる」

ハクレン「だが、起き上がるのは、速い」

ハクレン「……悪くない。倒れても起きる者は、最後まで立っていられる」

▼選択
- 「もう一回、お願いします」 → ハクレン +4、力 +1
- 「今日は、ここまでにしてくれ……」 → ハクレン +2

【選択1のとき】

ハクレン「……いい返事だ」

ハクレンの尻尾が、ほんの少しだけ、揺れた。

【選択2のとき】

ハクレン「よかろう。……明日も来い」

【合流】

## 段階2（好感度30）：小さな秘密

【背景：森・朝】
【立ち絵：ハクレン（照れ）】

朝の稽古の前、森の中で、ハクレンの声がした。

ハクレン「……ほら。食べろ。……怖くない、怖くないぞ」

茂みの向こうで、ハクレンがしゃがみこんでいた。手のひらの木の実を、小さな白い兎が、ちょこちょこと食べている。

ハクレン「……ふふ。よく食べる。……かわいいな、お前は」

（……ハクレン、だよな？）

足元の枝が、ぱきりと鳴った。

【立ち絵：ハクレン（驚き）】

ハクレン「――っ！　き、貴殿、いつから！」

▼選択
- 「かわいいな、その兎」と言う → ハクレン +5
- 見なかったふりをする → ハクレン +3

【選択1のとき】

ハクレン「……そ、そうだろう。この島で、私を怖がらない、ただ一匹の者だ」

ハクレン「……ほかの者には、言うなよ。特に、カバネには」

【選択2のとき】

ユウ「……何も見てない。稽古、行こう」

ハクレン「……う、うむ。それでいい」

ハクレンは、そっぽを向いた。耳が、真っ赤だった。

【合流】

## 段階3（好感度50）：失ったもの（守る国）

【背景：山頂・朝】
【BGM：静かな曲】
【立ち絵：ハクレン（悲しみ）】

山頂の岩の上で、ハクレンは、西の海を見ていた。

ハクレン「……ここからは、どこの国も見えないな」

ハクレン「私は、西を守る神だった。白虎。……四神の一柱だ」

ハクレン「私の国の民は、毎年、秋になると、白い旗をかかげて、私の名を呼んだ。……ハクレン様、と」

ハクレン「だが、百年、二百年と経つうちに、祭りは、小さくなっていった。名を呼ぶ声も、一人、また一人と、減っていった」

ハクレン「最後の一人が死んだとき、私の体は、少しずつ、薄くなりはじめた」

ハクレンは、自分の手のひらを、朝日に透かした。

ハクレン「誰にも祈られない神は、消える。……そういうものだ」

ハクレン「気づいたら、この山の上に、立っていた。……守る国も、民も、何もない島で」

【分岐：8日目の中間発表を見たあとかどうか】

【見たあとのとき】

ハクレン「あの声は言った。勝てば、国も、民も、元どおりにしてやる、と」

ハクレン「……戦わずに手に入るものなど、信じない。そう言いたいが」

ハクレンは、拳を握った。

ハクレン「……揺れた。私は」

【見る前のとき】

ハクレン「……守る相手のいない守り神が、何の役に立つ」

【合流】

▼選択
- 「ハクレン」と、まっすぐに名前を呼ぶ → ハクレン +6
- 何も言わずに、隣で同じ海を見る → ハクレン +4

【選択1のとき】

ハクレン「……っ」

ハクレンが、ゆっくりと、こっちを振り向いた。

ハクレン「……もう一度」

ユウ「ハクレン」

ハクレン「……そんなふうに名を呼ばれたのは、何百年ぶりだろうな。祭りの日に、民が呼んだときのようだ」

ハクレンは、目を閉じて、しばらく、そのまま風に吹かれていた。

【選択2のとき】

しばらく、二人で黙って、西の海を見ていた。

ハクレン「……付き合わせたな。稽古に戻るぞ」

【合流】

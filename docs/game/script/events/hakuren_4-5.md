# 個別イベント：ハクレン（段階4〜5）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：朝に「ハクレンと過ごす」か「鍛える（稽古）」を選んだとき、いまの好感度に +5 を足すと70・90に届いていて、その段階をまだ見ていなければ、会話（稽古のときは稽古の結果）の代わりに起きる。段階4は、段階3を見たあと。段階5は、8日目の中間発表のあと（9日目以降）にだけ起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。
- 稽古でイベントが起きたとき：好感度は「過ごす」と同じに数える（+5 ＋ 選択の値。稽古の +3 は足さない）。そのうえで、稽古の分の力 +1 と稽古の回数（`f.train_count`）+1 も足す（`../../system.md`）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」も出す（例：「ハクレンの好感度 +5（会えた分）＋6」）。段階4・5には「+8（心が近づいた）」はない。選択のない段階5は「+5（会えた分）」だけ。稽古で起きたときは「力 +1」も出す。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 呼び方：段階4の途中で、「貴殿」から「ユウ」に変わる。
- 段階4は成人向けにしない。段階5の［成人向け］は、位置だけを示す。

---

## 段階4（好感度70）：守るものを選び直す

【日付：○日目・朝】
【背景：浜辺・朝】
【立ち絵：ハクレン（真剣）】

ハクレン「構えろ。今日は、本気で打つ」

ハクレンの槍は、いつもの稽古の何倍も速かった。

一撃目で、枝が折れた。二撃目で、砂に転がされた。

ユウ「……っ、まだだ！」

三度、四度、立ち上がる。そのたびに、転がされる。

ハクレン「なぜ、立つ。勝てないと、分かっているだろう」

ユウ「……守りたいからだ」

ハクレン「……何を」

ユウ「この島と、みんなを。……ハクレンも、含めて」

ハクレンの槍が、止まった。

【立ち絵：ハクレン（驚き）】

ハクレン「……私を、守る、だと？　貴殿が？」

ユウ「俺は弱い。だから、一人じゃ無理だ」

ユウ「ハクレン。俺が、ハクレンを信じる。だから、俺と、この島を守ってほしい」

ハクレン「…………」

▼選択
- 手を差し出す → ハクレン +8
- 「……一人目の民で、悪いけど」と笑う → ハクレン +6

【選択1のとき】

ハクレンは、差し出された手を、長いあいだ見つめていた。

それから、槍を砂に突き立てて、その手を、強く握った。

【選択2のとき】

ハクレン「……ふ。……ふふ、ははは！」

ハクレンが、初めて、声を上げて笑った。

ハクレン「民が、たった一人か。……十分すぎる」

【合流】

ハクレン「……よかろう。今日から、この島が、私の守る国だ」

ハクレン「……ユウ。お前が、最初の民だ」

【画面表示：ハクレンの呼び方が「ユウ」になった】
【画面表示：ハクレンには、GM の「喪失の幻」が効きにくくなった】

## 段階5（好感度90）：結ばれる

【背景：山頂・夕方】
【BGM：やさしい曲】
【立ち絵：ハクレン（照れ）】

ハクレン「ユウ。……少し、話がある」

ハクレン「あの声は、勝てば国も民も元どおりにしてやると言った。……昔の私なら、迷わず、それを選んだだろう」

ハクレン「だが、今は違う。……勝っても、私は、ここに残る。守るものは、ここにある」

ハクレン「……それと、もう一つ」

ハクレンは、目をそらして、尻尾をぎこちなく揺らした。

ハクレン「守り神が、民の一人を、特別に思うのは……おかしいだろうか」

ユウ「おかしくない」

ハクレン「……そうか。なら、いい」

ハクレン「……私は、不器用だ。こういうことは、どうしていいか、分からない」

ハクレン「……だから、お前が、教えてくれ」

【背景：山頂・夜明け】

夜明けの山頂で、ハクレンは、西の海ではなく、島のほうを見ていた。

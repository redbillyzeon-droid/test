# 個別イベント：ノクティア（段階1〜3）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：夜に「ノクティアと過ごす」を選んだとき、いまの好感度に +5 を足すと段階の値（10・30・50）に届いていて、その段階をまだ見ていなければ、会話の代わりに起きる（`../../outline.md`、`../../design/affection.md` 2章）。「みんなと過ごす」と「探索に誘う」では起きない。
- 雨の日の昼に「ノクティアと過ごす」を選んだときは、段階のイベントは起きず、日常の会話を出す（イベントの場面は夜の設定のため。2026-10-17 プロデューサーの決定）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」と「+8（心が近づいた）」も出す（例：「ノクティアの好感度 +5（会えた分）＋8（心が近づいた）＋4」）。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 心の1行：段階3の結果のカードの最後に「ユウの心が、少し強くなった」と出す（数字は出さない。`f.mind` +1 に合わせる。段階1・2には出さない）。文は 2026-10-17 の決定のまま（`../../plan.md` の「心（`f.mind`）の見せ方」）。`../ui_text.md` 6章。
- 呼び方：段階3までは「坊や」。段階4で「ユウ」に変わる。
- 1つの場面は、選択肢を1つまで。長くしない。

## 段階1（好感度10）：月の話

【日付：○日目・夜】
【背景：洞窟の前・夜】
【立ち絵：ノクティア（微笑み）】

ノクティア「坊や。あなたの世界の月も、こんな色だった？」

ユウ「……もっと、白かったかな。街の明かりで、星はほとんど見えなかった」

ノクティア「まあ。星の見えない夜なんて、さびしいわね」

ノクティアは、膝の上で指を組んだ。白い指先が、月の光で透けて見えた。

ノクティア「わたくしの城の窓からは、星がよく見えたの。……毎晩、誰かと一緒に、数えていたわ」

▼選択
- 「誰と？」 → ノクティア +2
- 「じゃあ、今夜は俺が数えるよ」 → ノクティア +4

【選択1のとき】

ノクティア「ふふ。……それは、もう少し仲良くなってから、教えてあげる」

【選択2のとき】

ノクティア「……あら」

ノクティアは、少しだけ目を丸くして、それから、声を出さずに笑った。

ノクティア「いいわ。ひとつ目は、あの、いちばん赤い星からよ」

【合流】

## 段階2（好感度30）：薬づくり

【背景：洞窟の奥・夜】
【立ち絵：ノクティア（普通）】

洞窟の奥で、ノクティアは、すり鉢で何かをすりつぶしていた。

ノクティア「手伝ってくれる？　その葉を、細かくちぎって」

ユウ「これ、森で採った薬草？」

ノクティア「ええ。傷によく効くの。……坊やは、すぐけがをするから」

ちぎった葉を渡すと、ノクティアは、手際よく瓶に詰めていった。

ユウ「詳しいんだな」

ノクティア「長く生きていると、いろいろ覚えるのよ。……覚えたくなかったことも、ね」

洞窟の入り口のほうが、少しずつ明るくなりはじめていた。

ノクティアは、手を止めて、光から顔をそむけた。

ノクティア「……もうすぐ夜明けね。坊やは、行きなさい」

ユウ「ノクティアさんは、朝日が……」

ノクティア「嫌いよ。……とても」

【結果のカード】
薬 ×2 を手に入れた
ノクティアの好感度が上がった

→ ノクティア +5

## 段階3（好感度50）：失ったもの（ルカ）

【背景：洞窟の前・夜明け前】
【BGM：静かな曲】
【立ち絵：ノクティア（悲しみ）】

この夜、ノクティアは、いつもの席にいなかった。

洞窟の入り口の、朝日が当たるぎりぎりのところに、膝を抱えて座っていた。

ユウ「ノクティアさん。そこ、もうすぐ日が当たる」

ノクティア「……分かっているわ」

ノクティア「坊や。わたくしが、どうしてこの島に来たか、話したかしら」

ユウ「……いいや」

ノクティア「ルカという人がいたの。金色の髪の、よく笑う人間」

ノクティア「出会ったとき、あの人は二十歳だった。……一緒にいたのは、四十年」

ノクティア「あの人の髪が白くなって、手がしわだらけになっても、わたくしは、何も変わらなかった」

ノクティアは、自分の白い手を見下ろした。

ノクティア「最後の夜、あの人は言ったわ。『きみを一人にして、ごめん』って」

ノクティア「……一人にされるのは、あれで何度目だったかしら。数えるのも、やめてしまった」

ノクティア「だからね。あの人を見送った夜、城を出て、そのまま夜明けを待ったの。……朝日の中を、まっすぐ歩いていったわ」

ノクティア「……気づいたら、この島の、この洞窟で、目を覚ましていた」

【分岐：8日目の中間発表を見たあとかどうか】

【見たあとのとき】

（8日目に、あいつが見せた幻。金色の髪の青年）

ノクティア「あの声は言ったわね。勝てば、ルカを返してやる、って」

ノクティア「……ずるいわ。そんなこと言われたら、欲しくなってしまうじゃない」

【見る前のとき】

ノクティア「……ふふ。重たい話を、してしまったわね」

【合流】

▼選択
- 黙って、隣に座る → ノクティア +5
- 「そこにいたら、また焼けてしまう。中に入ろう」 → ノクティア +3

【選択1のとき】

隣に座ると、ノクティアは、少しだけ驚いた顔をした。

空が、だんだん白くなっていく。

ノクティア「……坊やも、焼けてしまうわよ」

ユウ「俺は、人間だから焼けない」

ノクティア「……そうね。人間だものね」

ノクティアは、それ以上何も言わずに、日が差す直前に、洞窟の奥へ戻っていった。

【選択2のとき】

ノクティア「……ええ。そうね」

ノクティアは、素直に立ち上がった。洞窟の奥へ戻る背中が、いつもより小さく見えた。

【合流】

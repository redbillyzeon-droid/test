# 個別イベント：ノクティア（段階4〜5）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：夜に「ノクティアと過ごす」を選んだとき、好感度が70（段階4）・90（段階5）に届いていて、その段階をまだ見ていなければ起きる。段階4は、段階3を見たあとでないと起きない。
- 呼び方：この段階4の途中で、「坊や」から「ユウ」に変わる。
- 段階4は成人向けにしない。段階5の［成人向け］は、位置だけを示す（中身は台本の段階で別に作り、利用者が確かめる）。

---

## 段階4（好感度70）：夜明けを一緒に見る

【日付：○日目・夜】
【背景：洞窟の前・夜明け前】
【BGM：静かな曲】
【立ち絵：ノクティア（普通）】

ノクティア「坊や。こんな時間まで、どうしたの。もうすぐ夜が明けるわ」

ユウ「ノクティアさんに、見せたいものがあって」

洞窟の入り口に、昼のあいだに作っておいたものを広げた。木の枠に、葉を何重にも編んで張った、大きな日よけだった。

ユウ「これを立てれば、日が当たらない。……ここからなら、空の色だけは見える」

ノクティア「…………」

ノクティアは、日よけと俺の顔を、何度も見比べた。

ノクティア「……あなた、これを、一日かけて？」

ユウ「カバネに手伝ってもらった。……ノクティアさん、夜明けが嫌いだって言ってたけど」

ユウ「本当は、見たかったんじゃないかと思って。ルカさんと、最後に見るはずだった空を」

【画面：空が、紺から薄紫、それから淡い金色に変わっていく】

二人で、日よけの影の中に座った。

日の光は、ぎりぎりのところで止まっていた。その向こうの空だけが、どんどん明るくなっていく。

ノクティア「……きれい」

ノクティアの声が、震えていた。

ノクティア「何百年ぶりかしら。……焼けないで、この色を見るのは」

ノクティア「ねえ。あなたも、いつかは、わたくしを置いていくのでしょう。人間だもの」

▼選択
- 「先にいなくなるとしても、それまでの時間は、全部あげる」 → ノクティア +8
- 「置いていかない、とは言えない。でも、今日はここにいる」 → ノクティア +6

【選択1のとき】

ノクティア「…………ずるい人」

ノクティアは、俺の肩に、頭をあずけた。

ノクティア「……そんなことを言われたら、また、好きになってしまうじゃない。……ユウ」

【選択2のとき】

ノクティア「……正直ね。いつも」

ノクティア「でも、それが、いちばん信じられるわ。……ユウ」

【合流】

（初めて、名前で呼ばれた）

【画面表示：ノクティアの呼び方が「ユウ」になった】
【画面表示：ノクティアには、GM の「喪失の幻」が効きにくくなった】

## 段階5（好感度90）：結ばれる

【背景：洞窟の奥・夜】
【BGM：夜の曲（やさしい版）】
【立ち絵：ノクティア（照れ）】

ノクティア「ユウ。……今夜は、帰らないで」

ノクティア「あの声は、勝てばルカを返してやると言ったわ。……ずっと、それが欲しかった」

ノクティア「でもね。今は、違うの」

ノクティア「勝っても、わたくしは、ルカを選ばない。……あの人は、もう、ちゃんと眠らせてあげたいの」

ノクティア「わたくしが選ぶのは、ここ。……あなたのいる、この島」

ノクティアは、冷たい指で、俺の頬にふれた。

ノクティア「……わたくしのこと、怖くない？」

ユウ「怖くない」

ノクティア「……ふふ。知ってた」

［成人向け］（ノクティアとの場面。位置だけを決めておき、中身は別に作る）

【背景：洞窟の奥・夜明け】

目を覚ますと、ノクティアは、俺の腕の中で眠っていた。

洞窟の入り口からは、日よけ越しの、やわらかい光が差していた。

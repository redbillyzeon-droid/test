# 個別イベント：ノクティア（段階4〜5）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：夜に「ノクティアと過ごす」を選んだとき、いまの好感度に +5 を足すと70（段階4）・90（段階5）に届いていて、その段階をまだ見ていなければ、会話の代わりに起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。段階4は、段階3を見たあとでないと起きない。段階5は、8日目の中間発表のあと（9日目以降）にだけ起きる（GM の誘いを聞いた前提の台詞があるため）。
- 雨の日の昼に「ノクティアと過ごす」を選んだときは、段階のイベントは起きず、日常の会話を出す（イベントの場面は夜の設定のため。2026-10-17 プロデューサーの決定）。
- 好物つき（2026-10-17 決定。`../gifts.md`、`../../design/life-bond.md` 1-4）：［好物を渡して過ごす］を選んだときは、判定を「いまの好感度 ＋ 5 ＋ 10」にする。渡す短い文のあとにイベントを出し、上がる値に +10（好物）を足す。同じ人には1回だけ。雨の日の昼に渡したときは、イベントは起きず、日常の会話（+10 は足す）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」も出す（例：「ノクティアの好感度 +5（会えた分）＋6」）。段階4・5には「+8（心が近づいた）」はない。選択のない段階5は「+5（会えた分）」だけ。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 心の1行：段階4・5の結果のカードの最後に「ユウの心が、少し強くなった」と出す（数字は出さない。`f.mind` +1 に合わせる。選択のない段階5にも出す）。文は 2026-10-17 の決定のまま（`../../plan.md` の「心（`f.mind`）の見せ方」）。`../ui_text.md` 6章。
- 呼び方：この段階4の途中で、「坊や」から「ユウ」に変わる。
- 段階4は成人向けにしない。段階5の［成人向け］は、位置だけを示す（中身は台本の段階で別に作り、利用者が確かめる）。

## 段階4（好感度70）：夜明けを一緒に見る

【日付：○日目・夜】
【背景：洞窟の前・夜明け前】
【BGM：静かな曲】
【立ち絵：ノクティア（普通）】

ノクティア「坊や。こんな時間まで、どうしたの。もうすぐ夜が明けるわ」

ユウ「ノクティアさんに、見せたいものがあって」

洞窟の入り口に、昼のあいだに作っておいたものを広げた。木の枠に、葉を何重にも編んで張った、大きな日よけだった。

ユウ「これを立てれば、日が当たらない。……ここからなら、空の色だけは見える」

ノクティア「…………」

ノクティアは、日よけと俺の顔を、何度も見比べた。

ノクティア「……あなた、これを、一日かけて？」

ユウ「カバネに手伝ってもらった。……ノクティアさん、夜明けが嫌いだって言ってたけど」

ユウ「本当は、見たかったんじゃないかと思って。ルカさんと、最後に見るはずだった空を」

【画面：空が、紺から薄紫、それから淡い金色に変わっていく】

二人で、日よけの影の中に座った。

日の光は、ぎりぎりのところで止まっていた。その向こうの空だけが、どんどん明るくなっていく。

ノクティア「……きれい」

ノクティアの声が、震えていた。

ノクティア「何百年ぶりかしら。……焼けないで、この色を見るのは」

ノクティア「ねえ。あなたも、いつかは、わたくしを置いていくのでしょう。人間だもの」

▼選択
- 「先にいなくなるとしても、それまでの時間は、全部あげる」 → ノクティア +8、`f.noctia_s4 = 1`
- 「置いていかない、とは言えない。でも、今日はここにいる」 → ノクティア +6、`f.noctia_s4 = 2`

【選択1のとき】

ノクティア「…………ずるい人」

ノクティアは、俺の肩に、頭をあずけた。

ノクティア「……そんなことを言われたら、また、好きになってしまうじゃない。……ユウ」

【選択2のとき】

ノクティア「……正直ね。いつも」

ノクティア「でも、それが、いちばん信じられるわ。……ユウ」

【合流】

## 段階5（好感度90）：結ばれる

【背景：洞窟の奥・夜】
【BGM：夜の曲（やさしい版）】
【立ち絵：ノクティア（照れ）】

ノクティア「あの声は、勝てばルカを返してやると言ったわ。……ずっと、それが欲しかった」

ノクティア「でもね。今は、違うの」

ノクティア「勝っても、わたくしは、ルカを選ばない。……あの人は、もう、ちゃんと眠らせてあげたいの」

ノクティア「わたくしが選ぶのは、ここ。……あなたのいる、この島」

ノクティアは、冷たい指で、俺の頬にふれた。

ノクティア「……わたくしのこと、怖くない？」

ユウ「怖くない」

ノクティア「……ふふ。知ってた」

# 個別イベント：コノハ（段階4〜5）★メインヒロイン

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：朝か昼に「コノハと過ごす」を選んだとき、好感度が70・90に届いていて、その段階をまだ見ていなければ起きる。段階4は、段階3を見たあと。段階5は、8日目の中間発表のあと（9日目以降）にだけ起きる。

- 段階4は成人向けにしない。段階5の［成人向け］は、位置だけを示す。

## 段階4（好感度70）：役に立たなくても

【日付：○日目・昼】
【背景：森の奥・昼】
【立ち絵：コノハ（悲しみ）】

森の奥の、コノハが作った小さな社の前。

コノハは、ひざに顔をうずめていた。足元に、魚を入れる籠が転がっている。空っぽだった。

ユウ「コノハ？」

コノハ「……今日、一匹も、とれなかったの」

コノハ「みんなのごはん、ボクの係なのに。……役に立たなかった」

コノハ「ボクね、役に立たないと、また……」

ユウ「コノハ」

（ここで言う言葉は、もう決まっている）

ユウ「役に立たなくても、ここにいていい」

コノハ「…………」

ユウ「魚がとれない日があっても、コノハは、コノハだ。ここが、コノハの帰る場所だ」

【立ち絵：コノハ（驚き）】

コノハの耳が、ゆっくりと持ち上がった。

コノハ「……ほんと？　何もできなくても？」

ユウ「本当だ」

▼選択
- 「俺も、何もできないけど、ここにいる」と笑う → コノハ +8
- 黙って、頭をなでる → コノハ +6

【選択1のとき】

コノハ「……ふふっ。ほんとだ。ユウ、ボクより、なんにもできない」

コノハ「……でも、いてくれる」

【選択2のとき】

コノハは、しばらく、なでられるままになっていた。

【合流】

【画面：コノハのしっぽが4本になる（光って増える演出）】

コノハ「……あ。また」

コノハ「ねえユウ。ボクね、もう、社に戻らなくてもいいかも。……ここが、いい」

【画面表示：コノハのしっぽが4本になった】
【画面表示：コノハには、GM の「喪失の幻」が効きにくくなった】

## 段階5（好感度90）：結ばれる

【背景：浜辺・夕方】
【BGM：やさしい曲】
【立ち絵：コノハ（照れ）】

【分岐：段階2で油揚げを約束したか（`f.promise_tofu`）と、油揚げを渡したことがあるか（`f.gave_fried_tofu`）】

【約束して、渡したとき】

コノハ「ユウが作ってくれた油揚げ、社でもらったのより、ずっとおいしかった」

コノハ「約束、守ってくれたね」

【約束はしていないが、渡したとき】

コノハ「ユウが作ってくれた油揚げ、社でもらったのより、ずっとおいしかった。……無理かもって、言ってたのに」

【約束したが、まだ渡していないとき】

コノハ「ねえユウ。油揚げの約束、覚えてる？」

コノハ「……あれね、もう、どっちでもいいの。ユウがいれば」

【約束も、渡したこともないとき】

（油揚げの話はしない）

【合流】

コノハ「ボクね、あの声が、社に戻してやるって言ったとき、うれしかったの。……ちょっとだけ」

コノハ「でも、もう決めた。勝っても、ボクは社に戻らない。ユウのいるところが、ボクの帰る場所」

コノハは、俺の手を、両手でぎゅっと握った。

コノハ「……ユウのこと、だいすき」

［成人向け］（コノハとの場面。位置だけを決めておき、中身は別に作る）

【画面：コノハのしっぽが5本になる】

【背景：浜辺・夜】

波の音の中で、コノハは、5本のしっぽで俺をくるんで、すやすやと眠っていた。

# 個別イベント：コノハ（段階4〜5）★メインヒロイン

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：朝か昼に「コノハと過ごす」を選んだとき、いまの好感度に +5 を足すと70・90に届いていて、その段階をまだ見ていなければ、会話の代わりに起きる。段階4は、段階3を見たあと。段階5は、8日目の中間発表のあと（9日目以降）にだけ起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。
- 好物つき（2026-10-17 決定。`../gifts.md`、`../../design/life-bond.md` 1-4）：［好物を渡して過ごす］を選んだときは、判定を「いまの好感度 ＋ 5 ＋ 10」にする。渡す短い文のあとにイベントを出し、上がる値に +10（好物）を足す。同じ人には1回だけ。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」も出す（例：「コノハの好感度 +5（会えた分）＋6」）。段階4・5には「+8（心が近づいた）」はない。選択のない段階5は「+5（会えた分）」だけ。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 心の1行：段階4・5の結果のカードの最後に「ユウの心が、少し強くなった」と出す（数字は出さない。`f.mind` +1 に合わせる。選択のない段階5にも出す）。文は 2026-10-17 の決定のまま（`../../plan.md` の「心（`f.mind`）の見せ方」）。`../ui_text.md` 6章。
- しっぽ：段階4で4本、段階5で5本。
- 段階4は成人向けにしない。段階5の［成人向け］は、位置だけを示す。

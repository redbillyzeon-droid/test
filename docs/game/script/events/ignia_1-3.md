# 個別イベント：イグニア（段階1〜3）

作成：2026-10-16　／　状態：初稿

- 書き方の決まりは `../00_prologue_day1.md` と同じ。
- 起きる条件：昼か夜に「イグニアと過ごす」を選んだとき、いまの好感度に +5 を足すと段階の値（10・30・50）に届いていて、その段階をまだ見ていなければ、会話の代わりに起きる。「みんなと過ごす」と「探索に誘う」では起きない（`../../design/affection.md` 2章）。
- 結果のカード：イベントの回は、選択の値のほかに「+5（会えた分）」と「+8（心が近づいた）」も出す（例：「イグニアの好感度 +5（会えた分）＋8（心が近づいた）＋4」）。台本に【結果のカード】を書いていない段階でも、イベントの終わりにこのカードを出す。
- 呼び方：段階3までは「人の子」。段階4で「ユウ」に変わる。
- GM の正体（人間の転生者であること）は13日目まで伏せる。イグニアは「あの声の主」とだけ呼ぶ。
- 8日目の中間発表で、「島はもとはイグニアの巣」だと5人が知る。段階3では、その先（どうやって奪われたか、なぜ眠っているか、なぜ主人公を待っていたか）を話す。

---

## 段階1（好感度10）：焼き魚

【日付：○日目・昼】
【背景：岩場・昼】
【立ち絵：イグニア（眠り）】

岩の上で、イグニアが丸くなっていた。

魚を一匹、そっと横に置いてみる。

【立ち絵：イグニア（ぼんやり）】

イグニアの鼻が、ひくひくと動いた。片目が開いた。

イグニア「……さかな」

イグニア「……ふぅ」

【効果音：炎】

小さな炎で、魚がこんがり焼けた。イグニアは、それを両手で持って、ゆっくり食べた。

イグニア「……おいしい。……人の子が、くれたさかなは、おいしい」

ユウ「自分で焼いたのに」

イグニア「……くれたのが、人の子だから」

▼選択
- 「また持ってくるよ」 → イグニア +4
- 「たまには、自分で獲ったら？」 → イグニア +2

【選択1のとき】

イグニア「……うん。待ってる」

イグニアは、そう言うと、また目を閉じた。尻尾の先が、ぱたぱたと岩を叩いていた。

【選択2のとき】

イグニア「……めんどう」

【合流】

## 段階2（好感度30）：島の上から

【背景：岩場・夜】
【立ち絵：イグニア（ぼんやり）】

イグニア「……人の子。ちょっと、来て」

岩場のいちばん高いところに、イグニアが立っていた。夜風に、赤銅色の髪がなびいている。

イグニア「……ここから、島が全部、見える」

見下ろすと、月明かりの下に、島のかたちがあった。浜辺、森、川。拠点の焚き火が、小さく光っている。

イグニア「……前は、もっと高く、飛べた。島のまわりを、ひと晩で、何周も」

ユウ「今は、飛べないのか？」

イグニア「……少しだけ。……すぐ、眠くなる」

イグニアは、焚き火の光を指さした。

イグニア「……あの火のまわりに、あんなに集まってるの、久しぶり。……人の子が来てから、島が、あったかい」

▼選択
- 「イグニアも、拠点で一緒に寝ればいい」 → イグニア +5
- 「いつか、飛べるようになるといいな」 → イグニア +4

【選択1のとき】

イグニア「……いいの？」

イグニアは、少しだけ、目を大きく開いた。

イグニア「……じゃあ、明日から。……焚き火の、いちばん近く」

【選択2のとき】

イグニア「……うん。……そのときは、背中に乗せてあげる」

【合流】

## 段階3（好感度50）：失ったもの（一族と、島）

【背景：岩場・夜】
【BGM：静かな曲】
【立ち絵：イグニア（真剣）】

その夜、イグニアは、眠っていなかった。

イグニア「……人の子。話がある」

イグニア「……わたしの前の世界には、竜が、たくさんいた。空が、竜でいっぱいになるくらい」

イグニア「……人間と、戦になった。長い、長い戦。……竜は、一頭ずつ、いなくなった」

イグニア「……最後に残ったのが、わたし。……ひとりで、ずっと眠ってた。起きても、もう誰もいないから」

イグニア「……眠ったまま、終わって。……気づいたら、この島にいた。誰もいない島」

イグニア「……何千年も、ここで、ひとりだった。……でも、それでよかった。もう、何も、なくさないから」

イグニアは、自分の角に、そっと触れた。

イグニア「……何十年か前、あの声の主が、流れついた」

イグニア「……最初は、うれしかった。ひとりじゃなくなるから。……でも、あの声の主は、神さまから、変な力をもらってた。奪う力」

イグニア「……島を、奪われた。わたしの力も、封じられた。……眠ってばかりなのは、そのせい」

【分岐：8日目の中間発表を見たあとかどうか】

【見たあとのとき】

イグニア「……あの日から、あの声の主は、流れついた人たちで、ゲームをしてる。……勝った人は、ひとりもいない」

【見る前のとき】

イグニア「……あの石が光るのは、あの声の主の、ゲームの合図」

【合流】

イグニア「……だから、待ってた。あの声の主に、勝てる人を」

イグニア「……人の子が、浜に倒れてたとき。……なんとなく、この人かもって、思った」

ユウ「どうして、俺なんだ」

イグニア「……分かんない。……でも、さかな、くれたから」

▼選択
- 「勝って、あいつのゲームを終わらせる」 → イグニア +6、`f.promise_end_game = 1`
- 「……俺に、できるのかな」 → イグニア +3

【選択1のとき】

イグニア「…………」

イグニアは、何も言わなかった。

ただ、金色の目が、少しだけ、うるんで見えた。

イグニア「……約束、だよ」

【選択2のとき】

イグニア「……分かんない。……でも、ひとりで、待ってるよりは、いい」

【合流】

# 台本：13日目「GM の正体」と「相棒を決める夜」

作成：2026-10-16　／　状態：初稿

書き方の決まりは `00_prologue_day1.md` と同じ。

この日の役目（`docs/game/outline.md`）：

- GM（黒瀬カイ）が姿を現し、主人公と同じ傷を持つ人間の転生者だと分かる。
- GM が「喪失の幻」を見せて、段階4の場面をまだ見ていないヒロインが揺れる。
- 「段階4に届いている」は、どの台本でも「段階4の場面を見た（`f.ev_<名前>` が 4 以上）」で判定する（好感度の値だけでは判定しない）。
- ノクティアは昼は洞窟から出られないので、朝と昼の浜辺の場面にはいない。夜の作戦会議から加わる。
- 深夜、いちばん好感度の高いヒロインが会いに来て、決戦の相棒になる。
- この日は自由行動がない（すべて固定の場面）。

カイ「だから、奪った。島も、竜の力も。……奪われる前に、奪えばいい。それだけのことさ」

カイ「それからずっと、流れついたやつらで、ゲームをしてる。勝てば、失ったものを一つ返してやる。ちゃんと約束どおりにね」

ユウ「……勝った人は、一人もいないんだろう」

【両方とも見つけているとき】

ユウ「船の日記を読んだ。勝ったやつを一人も見ていない、って書いてあった」

【洞窟の線だけのとき】

【見つけていないとき】

ハクレンの槍の先が、下がった。……白い旗の幻が、風にはためいていた。

## 深夜：相棒を決める

【背景：浜辺・深夜】
【BGM：夜の曲】

眠れなくて、浜に出た。

【分岐：相棒を決める（`outline.md` の「13日目の深夜：相棒を決める」）】

（「段階4以上」は、段階4の場面を見た（`f.ev_<名前>` が 4 以上）こと）

| 状況 | 流れ |
|---|---|
| 5人全員が段階4以上 | 「全員が来る」へ |
| 段階4以上が2人以上（全員ではない） | 「一人ずつ来る」へ。プレイヤーが選ぶ |
| 段階4以上が1人 | そのヒロインの「相棒の夜」へ |
| 段階4以上が誰もいない | いちばん好感度の高いヒロインの「迷いのある相棒の夜」へ |

好感度が同じときの順番（仮）：イグニア → ノクティア → ハクレン → カバネ → コノハ。

### 全員が来る

足音が、ひとつ、ふたつ、……五つ。

【立ち絵：ノクティア、コノハ、カバネ、ハクレン、イグニア】

カバネ「……一人で行かせるわけ、ないでしょ」

コノハ「みんなで、決めてたの！」

ハクレン「守る国の民を、一人で戦わせる守り神がいるか」

ノクティア「夜明けは嫌いだけれど。……今度は、みんなで見ましょう」

イグニア「……ユウ。……みんなで」

▼選択
- 「みんなで行こう」 → 真エンドのルート（`f.partner = "all"`）
- 一人を選ぶ（5人の名前が出る） → そのヒロインの「相棒の夜」へ

### 一人ずつ来る

段階4以上のヒロインが、一人ずつ、浜に来る。それぞれが、短く一言だけ話して、去っていく（台詞は下の「相棒の夜」の、最初の一言を使う）。

▼選択
- 段階4以上のヒロインの名前が並ぶ → 選んだヒロインの「相棒の夜」へ

### 相棒の夜（ヒロインごと）

選んだ（または来た）ヒロインと、短く話す。彼女の「失ったもの」と、GM の誘いを、もう一度確かめ合う。成人向けにはしない（`outline.md` の「13日目の深夜：相棒を決める」）。

| 相棒 | 最初の一言 | 確かめ合うこと |
|---|---|---|
| ノクティア | 「明日は、わたくしが隣に立つわ。……夜明けに強い吸血鬼なんて、いないけれど」 | ルカの幻が来ても、目をそらさずに断ると決める |
| コノハ | 「ユウ！　明日は、ボクがユウを守る番！」 | 社の幻が来ても、「ここが帰る場所」と言うと決める |
| カバネ | 「……あーしで、いいの？　でかいし、骨だし」 | 人間に戻れる幻が来ても、今の自分を選ぶと決める |
| ハクレン | 「明日、私は、お前の盾になる。……それが、守り神の役目だ」 | 国と民の幻が来ても、この島を守ると決める |
| イグニア | 「……ユウ。……封印、明日、ぜんぶ、ほどく」 | 竜の群れの幻が来ても、もう一人ではないと決める |

最後に、ヒロインが言う：「……明日の夜明けに。一緒に」

`f.partner` にヒロインの名前を入れる。

### 迷いのある相棒の夜

段階4に届いたヒロインが誰もいないときだけ。

いちばん好感度の高いヒロインが来るが、言葉が少ない。目を合わせない。

例（コノハのとき）：

コノハ「……ユウ。明日、ボク、ちゃんと、ユウの隣にいられるかな」

コノハ「……あの鳥居、まだ、目の奥に残ってるの」

`f.partner` にヒロインの名前を入れる。`f.partner_wavering = 1`（決戦の中盤で、幻に負けやすい）。

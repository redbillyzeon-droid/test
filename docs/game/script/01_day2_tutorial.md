# 台本：2日目（島の暮らしの始まり・遊び方の説明）

作成：2026-10-16　／　状態：初稿

書き方の決まりは `00_prologue_day1.md` と同じ。

この日の役目：

- 島の暮らしの遊び方（朝・昼・夜に1つずつ行動を選ぶ）を、会話の中で覚えてもらう。
- 探索の流れ（エリアを選ぶ → 結果のカード）を、一度だけ決まった形で体験させる。
- 石碑と GM のゲームについて、5人がどう受け止めているかを短く見せる。
- 長くしない。説明の会話は、1つの場面で3〜5往復までにする（サクサク）。

---

## 朝

【日付：2日目・朝】
【背景：洞窟の入り口・朝】
【BGM：明るい日常の曲】

目を覚ますと、洞窟の入り口から、白い光が差しこんでいた。

（……夢じゃ、なかった）

体を起こすと、腹が鳴った。昨日の焼き魚から、何も食べていない。

【立ち絵：コノハ（笑顔）】

コノハ「おはよ、ユウ！　起きた？　起きたね！」

ユウ「おはよう、コノハ。……早いな」

コノハ「狐は朝が早いの！　ねえねえ、浜のあの石、見た？　昼間は、なんにも書いてないんだよ」

【背景：浜辺・朝】
【立ち絵：カバネ（普通）、ハクレン（真剣）】

浜に出ると、黒い石碑のまわりに、カバネとハクレンが立っていた。昨日の夜に光っていた文字は、跡形もなかった。

ハクレン「十四日目の夜明け、と書いてあったな。……今日を入れて、あと十二日だ」

カバネ「てかさ、前にもあったんだよ。こういう、石が光る夜」

ユウ「前にも？」

カバネ「何人か、流れついたやつがいてさ。光った夜から何日かして、みんな、いなくなった。……どこ行ったかは、知らない」

【立ち絵：カバネ（不機嫌）】

カバネは石碑を軽く蹴って、すぐに背を向けた。

（いなくなった。……ノクティアさんが言っていたのは、このことか）

ハクレン「考えても分からないことは、考えるな。まずは生きることだ」

カバネ「そ。食いもんと、寝る場所。話はそれから」

### 遊び方の説明：一日の流れ

コノハ「じゃあ、ボクが島の暮らしかた、教えてあげる！」

コノハ「一日はね、朝と、昼と、夜があるの。それぞれで、ひとつずつ、やることを決めるんだよ」

コノハ「島を歩いて、食べ物や木を集めたり。誰かと一緒にいたり。おうちを建てたり。疲れたら、休んだり！」

【画面表示：行動の選び方の説明（1枚）】
朝・昼・夜に、1つずつ行動を選びます。
・探索：島のエリアを歩いて、素材や食料を集める
・ヒロインと過ごす：仲良くなる
・建てる・作る：素材で、施設や道具を作る
・鍛える：主人公の能力を上げる
・休む：体力を回復する

ハクレン「あれもこれもと欲張るな。一日にできることは、三つだけだ」

コノハ「今日の朝は、ボクと浜辺を歩こ！　探しかた、見せてあげる！」

### 決まった探索：浜辺（遊び方の説明）

【画面：探索マップ（浜辺・森・川だけが選べる。浜辺が光っている）】
【選ぶ：浜辺】

【背景：浜辺・朝】

コノハ「浜辺はね、魚と、流れてきた木と、きれいな貝がとれるの」

コノハは、波打ちぎわにしゃがみこむと、砂を手で掘りはじめた。しっぽが、ぶんぶん揺れている。

コノハ「あった！　ほら、貝！　……あとね、こういう木も、おうちの材料になるんだよ」

（遊び方の説明のための例外：ふだんの探索は結果が1〜2つだが、ここでは素材を3種類まとめて見せる）

【結果のカード】
浜辺を探索した
・魚 ×2
・木材（流木） ×3
・貝殻 ×1
コノハの好感度が少し上がった

【画面表示：結果のカードの説明（1枚）】
探索すると、手に入れたものがカードで出ます。
素材は「建てる・作る」で使えます。

コノハ「ね、かんたんでしょ？　ほかの場所にも、いろんなものがあるよ。でも、森の奥とか、洞窟とかは、あぶないの」

ユウ「あぶない？」

コノハ「獣がいるの。おっきいイノシシとか。……ユウ、弱そうだから、気をつけてね！」

（悪気がないのは、分かるんだけど……）

→ コノハ +3

## 昼（自由行動）

【日付：2日目・昼】
【次にやること：「建てる・作る」で、作業台を建てられる（木材が3つ必要）】

【背景：森の中の広場・昼】
【立ち絵：カバネ（普通）】

カバネ「お、流木。……それ、作業台にできるよ。あーしが組んでやるし」

カバネ「道具とか作るなら、まず作業台。あとは好きにしな」

【画面表示：自由行動の説明（1枚）】
ここからは、自由に行動を選べます。
迷ったら、画面の右上の「次にやること」を見てください。

【自由行動：行動を1つ選ぶ。`docs/game/system.md` の「行動」】

### この時間に「建てる・作る」→「作業台」を選んだとき（決まった短い場面）

カバネは、慣れた手つきで流木を組んでいった。釘も縄もないのに、木と木が、ぴたりとはまる。

ユウ「すごいな。大工だったのか？」

カバネ「は？　違うし。……昔、手伝ってただけ」

【立ち絵：カバネ（照れ）】

カバネ「……ほら、できた。ウケるくらい、ちゃんとしてんじゃん」

【結果のカード】
作業台を建てた
・木材 −3
・島の発展度が上がった
・道具が作れるようになった
カバネの好感度が少し上がった（施設を一緒に建てた。`system.md` の好感度の決まり）

→ カバネ +3

## 夜（自由行動）

【日付：2日目・夜】
【次にやること：夜は、洞窟でノクティアに会える】

【背景：洞窟の前・夜】

日が落ちると、島は、急に静かになった。

【自由行動：行動を1つ選ぶ】

### この時間に「ノクティアと過ごす」を初めて選んだとき（決まった短い場面）

【立ち絵：ノクティア（微笑み）】

ノクティア「あら、坊や。今夜も来てくれたのね」

ノクティア「……昨日の石の文字、見たのでしょう？　怖くはないの？」

▼選択
- 「怖い。でも、何もしないほうが、もっと怖い」 → ノクティア +3
- 「十二日もあるんだ。なんとかなる」 → ノクティア +1

【選択1のとき】

ノクティア「……ふふ。正直な子は、好きよ」

【選択2のとき】

ノクティア「あら、前向きね。……そういう人ほど、先にいなくなるのよ」

【合流】

ノクティアは、それ以上は何も言わずに、月を見上げた。

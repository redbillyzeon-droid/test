# 日常の短い会話：ノクティア

作成：2026-10-16　／　状態：初稿

- 出し方は `README.md`。会える時間帯：夜（雨の日は昼も）。
- 呼び方：段A・Bは「坊や」、段Cは「ユウ」。
- 一人称は「わたくし」。主人公は「ノクティアさん」と呼ぶ。

---

## 段A：出会ったばかり

### A1　夜風（+5）
時間帯：夜

【背景：洞窟の前・夜】
ノクティア「今夜は、風が冷たいわね。……坊や、もう少しこっちにいらっしゃい」
ノクティア「あら、照れているの？　ふふ。からかいがいがあるわ」

### A2　におい（+5）
時間帯：夜

【背景：洞窟の前・夜】
ノクティア「坊やからは、焚き火と、魚のにおいがする」
ノクティア「……悪くないわ。生きている人のにおいだもの」

### A3　昼の過ごし方（+6）
時間帯：夜

【背景：洞窟の奥・夜】
ユウ「ノクティアさんは、昼のあいだ、何をしてるんだ？」
ノクティア「眠っているわ。……それと、夢を見ているの。ずっと昔の、お城の夢」
ノクティア「坊やの夢も、そのうち見るかもしれないわね」

### A4　雨の昼（+7）
時間帯：昼　条件：雨の日

【背景：洞窟の前・雨の昼】
ノクティア「雨の日は好きよ。お日さまが、隠れてくれるから」
ノクティア「……坊やと、明るいうちに話せるのも、雨の日だけね」

## 段B：打ち解けてきた

### B1　星の名前（+6）
時間帯：夜

【背景：洞窟の前・夜】
ノクティア「あの星はね、わたくしの国では『番人の目』と呼ばれていたの」
ノクティア「眠らずに、夜を見張っている星。……わたくしみたいでしょう？」

### B2　薬の味（+6）
時間帯：夜

【背景：洞窟の奥・夜】
ノクティア「はい、坊や。疲れが取れる薬よ。……苦いけれど、飲みなさい」
ユウ「……っ、にが」
ノクティア「ふふ。いい顔。……ちゃんと、効くわよ」
【結果のカード】体力 +1

### B3　牙（+5）
時間帯：夜

【背景：洞窟の前・夜】
ユウ「ノクティアさん、本当に、血を吸うのか？」
ノクティア「吸ってほしいの？」
ユウ「いや、そういうわけじゃ」
ノクティア「ふふ。……島に来てから、一度も吸っていないわ。赤い果実で、十分だもの」

### B4　カバネのこと（+6）
時間帯：夜　条件：4日目より後

【背景：洞窟の前・夜】
ノクティア「カバネは、毎晩、洞窟の前にごはんを置いていってくれるの。食べないって言っているのに」
ノクティア「……ああいう子が、いちばん、さびしがりなのよ。わたくしと同じで」

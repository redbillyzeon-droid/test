# 「みんなと過ごす」の短い文

作成：2026-10-17　／　状態：初稿

- 出し方は `README.md` の「出し方の決まり」7。その時間帯の文から、まだ見ていないものを1つ選ぶ（順番はランダム）。全部見たら、前回と同じもの以外からランダムに出す。
- 出る人は、その時間帯に会える全員（`README.md` の表）。
  | 時間帯 | 出る人 |
  |---|---|
  | 朝 | コノハ、カバネ、ハクレン |
  | 昼（晴れ） | コノハ、カバネ、イグニア |
  | 夜 | ノクティア、カバネ、イグニア |
  | 雨の日の昼 | コノハ、カバネ、イグニア、ノクティア |
- 雨の日の昼は「雨の日の昼」の文だけを出す（ノクティアが出るため）。晴れた昼は、ノクティアは出ない。
- 段階のイベントは起きない（`../../design/affection.md` 2章 C）。
- 呼び方：段階4の前後で変わる呼び方（「坊や」「アンタ」「貴殿」「人の子」）は、ここでは使わない。段階に関係なく出せるようにするため。コノハだけは最初から「ユウ」。
- 2〜4行、選択肢なし。どの日から出しても話が合う中身にした（嵐や8日目の出来事には触れない）。

結果のカード（どの文も、時間帯ごとに同じ）：

| 時間帯 | 結果のカード |
|---|---|
| 朝 | コノハ・カバネ・ハクレンの好感度 +3 |
| 昼（晴れ） | コノハ・カバネ・イグニアの好感度 +3 |
| 夜 | ノクティア・カバネ・イグニアの好感度 +3 |
| 雨の日の昼 | コノハ・カバネ・イグニア・ノクティアの好感度 +3 |

- かまどを建てていれば（`f.built_stove = 1`）、どれも +4 にして、カードに「みんなでごはん」と添える。

## 朝

### M1　朝ごはん

【背景：拠点・朝】
カバネ「はい、朝ごはん。今日は焼き魚と、果実のやつ」
コノハ「この魚、ボクが獲ったの！　いちばんおっきいの！」
ハクレン「……食べたら、浜を一周走るぞ。全員だ」
カバネ「は？　あーしも？　ウケる。パスだし」

### M2　稽古のまね

【背景：浜辺・朝】
ハクレンが木の枝を振るのを、コノハがまねしている。
コノハ「えいっ！　とおっ！　……ハクレン、どう？」
ハクレン「……悪くない。足は、もう少し開け」
カバネ「朝からよくやるわ。……ほら、水。二人とも飲みな」

### M3　寝坊

【背景：拠点・朝】
コノハ「ねえ、イグニアは？」
カバネ「まだ寝てる。起こしたら火ぃ吹かれるし、ほっとこ」
ハクレン「……起きたら、私が稽古をつける。寝てばかりでは、体がなまる」

## 昼（晴れ）

【背景：浜辺・昼】
コノハ「イグニア、火ちょうだい！　魚、焼くの！」
イグニア「……ふぅ。……はい。……一匹、ちょうだい」
カバネ「焼く前から食べる気じゃん。ウケる」

【背景：岩場・昼】
岩の上で、イグニアが寝ている。そのおなかに頭をのせて、コノハも丸くなっていた。
イグニア「……すぅ」
カバネ「二人とも寝てんの、ウケる。……あーしも、ちょっとだけ寝よ」

### D3　水くみ競争

【背景：川・昼】
コノハ「よーい、どん！　水くみ競争！」
カバネ「待って、あーしの桶のほうがでかいんだけど。不公平じゃね？」
イグニア「……わたし、見てる。……がんばれー」

## 夜

【背景：拠点・夜】
イグニア「……焚き火、弱い。……ふぅ」
ノクティア「ありがとう、イグニア。あなたの火は、本当に頼りになるわね」

【背景：浜辺・夜】

イグニア「……月、まるい。……焼いたら、おいしそう」

【背景：拠点・夜】

イグニア「……すぅ」

## 雨の日の昼

### R1　雨宿り

【背景：洞窟の前・雨の昼】
コノハ「雨だと、お昼にノクティアに会えるね！」
ノクティア「ええ。雨の日は好きよ。……にぎやかなのも、たまにはいいわ」

イグニア「……ふぅ。……みんな、もっと寄って。……あったかい」

【背景：洞窟の奥・雨の昼】
遠くで雷が鳴った。コノハが、カバネの後ろに隠れる。
カバネ「はいはい、だいじょぶだって。……しっぽ、ふくらみすぎ。ウケる」
ノクティア「ここは岩の中よ。雷は届かないわ」
イグニア「……来ても、わたしが、追いはらう」

# 日常の短い会話（「ヒロインと過ごす」）

作成：2026-10-16　／　状態：初稿

2日目以降に「ヒロインと過ごす」を選んだとき、段階のイベント（`../events/`）が起きない回に出る、短い会話。「みんなと過ごす」の短い文は `everyone.md`。

## 出し方の決まり

1. 1人を選んで「過ごす」とき、いまの好感度に +5 を足すと段階の値（10・30・50・70・90）に届いていて、その段階をまだ見ていなければ、会話の代わりに段階のイベントを出す（段階4は段階3を見たあと、段階5は9日目以降）。届かなければ、ここの会話を1つ出す（`../../design/affection.md` 2章）。
   - カバネの嵐の夜の会話（`../02_day4_storm.md`）は、段階のイベントが起きない「カバネと過ごす」の回に、ここの会話より先に出す。
2. 会話は、ヒロインごとに3つの段に分けてある。いまの段の中から、まだ見ていないものを1つ選ぶ（順番はランダム）。
   | 段 | 条件 | 呼び方 |
   |---|---|---|
   | A：出会ったばかり | 段階2の場面をまだ見ていない（`f.ev_<名前>` が 0〜1） | 段階4の前の呼び方 |
   | B：打ち解けてきた | 段階2を見た〜段階4をまだ見ていない（`f.ev_<名前>` が 2〜3） | 段階4の前の呼び方 |
   | C：心が通った | 段階4を見た（`f.ev_<名前>` が 4 以上） | 段階4のあとの呼び方 |
3. その段の会話をすべて見たら、同じ段の中から、もう一度ランダムに出す（前回と同じものは続けて出さない）。
4. 「条件」の欄があるものは、その条件を満たすときだけ選ぶ候補に入れる（例：8日目より後、雨の日）。
5. 好感度は、会話ごとに書いた数だけ上がる（`../../system.md` の「ヒロインと過ごす：+5〜8」）。段階のイベントの回は、+5（会えた分）＋ 段階ボーナス（段階1〜3は +8、段階4・5はなし）＋ イベントの中の選択の値（`../events/`）。
6. 1つの会話は、3〜8行くらい。選択肢は入れない（サクサク遊べるように）。
7. 「みんなと過ごす」を選んだときは、`everyone.md` から、その時間帯の文を1つ出す（雨の日の昼は「雨の日の昼」から）。その時間帯に会える全員の好感度が +3（かまどがあれば +4）。段階のイベントは起きない（イベントは二人きりの場面のため）。

## 会える時間帯（`../../outline.md`）

| ヒロイン | 会える時間帯 |
|---|---|
| ノクティア | 夜（雨の日は昼も） |
| コノハ | 朝、昼 |
| カバネ | 朝、昼、夜 |
| ハクレン | 朝 |
| イグニア | 昼、夜 |

会話の「時間帯」の欄は、その会話が自然に出せる時間帯。会える時間帯の中で、さらに絞っているものがある。

## 変数

| 変数 | 中身 |
|---|---|
| `f.talk_<名前>_<ID>` | その会話を見たら 1（例：`f.talk_konoha_A1`） |
| `f.talk_<名前>_last` | 前回出した会話の ID（続けて同じものを出さないため） |
| `f.talk_everyone_<ID>`、`f.talk_everyone_last` | 「みんなと過ごす」の文で、上と同じ使い方（`everyone.md`） |

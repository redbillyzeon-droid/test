# 日常の短い会話：イグニア

作成：2026-10-16　／　状態：初稿

- 出し方は `README.md`。会える時間帯：昼、夜。
- 呼び方：段A・Bは「人の子」、段Cは「ユウ」。一人称は「わたし」。
- 話し方は、ゆっくり、短く、「……」が多い。
- GM の正体は13日目まで伏せる。「あの声の主」とだけ呼ぶ。

## 段A：出会ったばかり

### A1　ひなたぼっこ（+5）
時間帯：昼

【背景：岩場・昼】
イグニア「……ここ、あったかい。……人の子も、寝る？」
イグニア「……すぅ」
（話している途中で、寝てしまった）

### A2　しっぽ（+5）
時間帯：昼

【背景：岩場・昼】
ユウ「イグニアの尻尾、うろこが光ってきれいだな」
イグニア「……そう？　……もっと、見ていい」
イグニアの尻尾が、ぱたん、と岩を叩いた。

### A3　夜の火（+6）
時間帯：夜

【背景：拠点・夜】
イグニア「……焚き火、消えそう。……ふぅ」
小さな炎で、焚き火が勢いを取り戻した。
イグニア「……おやすみ」

### A4　おなか（+6）
時間帯：昼、夜

【背景：岩場・昼】
イグニア「……人の子。……おなか、すいた」
イグニア「……人の子は、おなか、すいてない？　……じゃあ、半分こ」

## 段B：打ち解けてきた

【背景：岩場・夜】
イグニア「……前の世界の空は、もっと、にぎやかだった。……竜で」
イグニア「……ここの空は、しずか。……しずかすぎる」

時間帯：昼

【背景：拠点・昼】
イグニアが、拠点の屋根の上で丸くなっていた。
イグニア「……ここ、みんなの声が、聞こえるから。……よく眠れる」

### B3　うろこ（+5）
時間帯：昼

【背景：岩場・昼】

### B4　八日目のあと（+7）

イグニア「……ずっと、言えなかったから。……あの声の主が、来てから」

【背景：GM の館・夜明け前】
【BGM：なし】

コノハは、カイの隣に立っていた。

増えていたしっぽが、1本に戻っていた。

ユウ「コノハ！」

コノハ「……ごめん、ユウ。ボク、決めたの」

コノハは、俺を見なかった。鳥居の幻のほうを見つめて、両手を、ぎゅっと握りしめていた。

カイ「……ね。言ったとおりだろう？」

【効果音：衝撃】
【背景：黒】

カイの手が振り下ろされて、目の前が、真っ暗になった。

## 夜：扉の隙間

【背景：崖の上・夜】
【BGM：プロローグの曲】

目を覚ますと、館の外の、崖の上に倒れていた。

体じゅうが痛い。それでも、起き上がった。

（コノハを、連れて帰らないと）

【背景：GM の館の廊下・夜】
【効果音：心臓の音】

館の中は、しんと静まりかえっていた。

廊下の奥に、明かりのもれる部屋があった。

扉が、少しだけ、開いている。

（……この形を、知っている）

アパートの廊下。少しだけ開いた、寝室のドア。

扉の隙間から、声が聞こえた。

コノハ「……ねえ。ボク、ほんとに、帰れるの？」

カイ「ああ。一人前の狐として、社に迎えてもらえる。……決めるのは、君だよ。いつだって、選ぶのは本人だ」

コノハ「……うん。ボクが、決めたの。だれかに、言われたからじゃない」

その隙間の向こうを、俺は、最後まで見ることができなかった。

［成人向け］（コノハとカイの場面。扉の隙間からの声と気配だけで伝える。位置だけを決めておき、中身は別に作る）

コノハ「……ユウ、ごめんね」

コノハの声が、扉の向こうで、小さく言った。

コノハ「ボク、帰る場所が、ほしかったの」

【効果音：心臓の音（速く）】

胸が、つぶれるように痛い。

あの夜と、同じだった。

（また、だ）

（俺の見ていないところで、大事な人が、奪われていく）

## 後日談

【分岐：島の発展度（`f.dev`。決戦の前の値）で背景を変える（2026-10-17 決定。`../../design/life-bond.md` 5章）】

- 0〜1：【背景：拠点・昼（拠点と焚き火だけ）】
- 2〜3：【背景：拠点・昼（施設がいくつか）】
- 4〜6：【背景：拠点・昼（小さな村のよう）】

【BGM：明るい日常の曲】

それから、島は、少しだけ変わった。

【建てた施設ごとに1行ずつ。建てていないものは出さない。順は下のとおり。見張り台は、下のハクレンの行で出す】

- 作業台（`f.built_workbench` ＝ 1 で、壊れていない）：作業台の上には、いつも作りかけの何かがある。
- かまど（`f.built_stove`）：かまどの火は、いまはイグニアが毎朝つけてくれる。
- 畑（`f.built_field`）：畑の大豆は、コノハが毎日のぞきに行く。
- 家（`f.built_house`）：家の奥の暗い部屋は、ノクティアの昼寝の場所になった。
- 船着き場（`f.built_dock`）：船着き場から、ときどき沈没船まで漕ぎ出す。

【発展度が0〜1のときだけ】

島づくりは、まだ始まったばかりだ。……時間は、いくらでもある。

【合流】

封印が解けたイグニアは、よく起きているようになった。……ただし、昼寝は、前と同じくらいする。

【分岐：見張り台を建てたか（`f.built_tower`）】

- 建てたとき：ハクレンは、毎朝、見張り台から島を見回っている。「守る国」の見回りだそうだ。
- 建てていないとき：ハクレンは、毎朝、浜の岩の上から島を見回っている。「守る国」の見回りだそうだ。

【分岐：かまどを建てたか（`f.built_stove`）】

- 建てたとき：カバネは、拠点の横に、小さな食堂を開いた。客は、いつも同じ六人だけど。
- 建てていないとき：カバネは、焚き火の横に、小さな食堂を開いた。客は、いつも同じ六人だけど。

コノハのしっぽは、5本そろった。毎日、ふさふさになっていく。

【分岐：家を建てたか（`f.built_house`）】

- 建てたとき：ノクティアは、家の軒の日よけの下で、毎朝の夜明けを見ている。
- 建てていないとき：ノクティアは、岩陰で、毎朝の夜明けを見ている。

【分岐：12日目の宴で「みんなの世界の歌」を選んだか（`f.feast_songs`）】

【選んだとき】

夜になると、焚き火のまわりで、五つの世界の歌が混ざる。……そこに、最近は、俺の世界の歌も、加わった。

【選ばなかったとき】

夜になると、焚き火のまわりで、誰かが歌いだす。俺の下手な歌に、みんなが笑う。

【合流】

そしてときどき、浜に、誰かが流れつく。

どこかの世界で、何かを失ったひとが。

【立ち絵：コノハ（笑顔）】

コノハ「ユウ！　また誰か来たよ！」

この島は、もう、奪う場所じゃない。

失った者が、もう一度、何かを見つける場所だ。

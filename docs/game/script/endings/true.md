【立ち絵：GM（素顔・崩れた顔）】

カイ「……約束は、約束だ。勝者の願いを、一つ叶える」

カイ「何を取り戻す？　あの女か？　それとも――」

ユウ「この島を、イグニアに返してくれ」

カイ「……は？」

ユウ「俺の願いは、それだけだ」

カイは、信じられないものを見るような目で、俺を見た。それから、5人を見た。

カイ「……お前たちは？　返してほしいものが、あっただろう」

【立ち絵：ノクティア、コノハ、カバネ、ハクレン、イグニア】

ノクティア「……ルカは、もう、眠らせてあげたいの」

コノハ「ボクの帰る場所は、ここ！」

カバネ「人間には戻んない。……今のあーしで、いいって言われたし」

ハクレン「私の国は、この島だ」

イグニア「……わたしの島。……返して」

カイ「…………」

【画面：GM の館が、白い光に包まれる】
【効果音：封印がほどける音】

## カイの去り際

【背景：浜辺・朝】
【立ち絵：GM（素顔・無表情）】

浜辺に、カイが一人で立っていた。白いコートが、半分、透けている。

カイ「……島の主が戻れば、俺の力も、ここでは使えない。……出ていくしかないね」

イグニア「……あなたも、失った人。……だから、追い出すんじゃない。……送りだす」

イグニアが、カイの胸に、そっと手を当てた。

イグニア「……別の世界で、もう一回。……今度は、奪わないで」

カイ「…………」

カイは、何か言いかけて、やめた。

それから、俺を見た。

カイ「ユウ。……お前は、選べたんだな」

ユウ「みんなが、いてくれたからだ」

カイ「……俺にも、いたのかもしれないな。……見ようとしなかっただけで」

【画面：カイの体が、光の粒になって、海の向こうへ消えていく】

（島に残る男は、俺一人になった）

## 後日談

【背景：拠点・昼（家と見張り台がある）】
【BGM：明るい日常の曲】

それから、島は、少しだけ変わった。

封印が解けたイグニアは、よく起きているようになった。……ただし、昼寝は、前と同じくらいする。

ハクレンは、毎朝、見張り台から島を見回っている。「守る国」の見回りだそうだ。

カバネは、拠点の横に、小さな食堂を開いた。客は、いつも同じ六人だけど。

コノハのしっぽは、5本のまま、ふさふさに増えた。

ノクティアは、日よけの下で、毎朝の夜明けを見ている。

【分岐：12日目の宴で「みんなの世界の歌」を選んだか（`f.feast_songs`）】

【選んだとき】

夜になると、焚き火のまわりで、五つの世界の歌が混ざる。……そこに、最近は、俺の世界の歌も、加わった。

【選ばなかったとき】

夜になると、焚き火のまわりで、誰かが歌いだす。俺の下手な歌に、みんなが笑う。

【合流】

そしてときどき、浜に、誰かが流れつく。

どこかの世界で、何かを失ったひとが。

【立ち絵：コノハ（笑顔）】

コノハ「ユウ！　また誰か来たよ！」

この島は、もう、奪う場所じゃない。

失った者が、もう一度、何かを見つける場所だ。

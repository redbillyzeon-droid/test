# 台本：好物を渡す・油揚げの朝

作成：2026-10-17　／　更新：2026-10-17（好物がだぶるときの決まり）　／　状態：初稿

書き方の決まりは `00_prologue_day1.md` と同じ。決まり（数字・条件）は `../design/life-bond.md` 1章（2026-10-17 決定。`../plan.md` の「好物」「油揚げ」）。

## 出し方の決まり

- 「ヒロインと過ごす」の一覧で、その人の好物を持っていて、まだ渡していないとき、［過ごす］と［好物を渡して過ごす］の2つのボタンを出す（文は `ui_text.md` 8章）。
- ［好物を渡して過ごす］を押したら、まず下の「渡す短い文」を出す。そのあと、判定（いまの好感度 ＋ 5 ＋ 10）が段階の値に届いていれば段階のイベント（`events/`）、届かなければ日常の会話（`daily/`）へ進む。
- 渡せるのは、二人きりの「過ごす」のときだけ。「みんなと過ごす」「探索に誘う」「鍛える（ハクレンとの稽古・薬の勉強）」では渡せない。
- 同じ人に渡せるのは1回だけ（+10）。渡したら `f.gave_<好物>` ＝ 1 にして、持ち物から1つ減らす。
- 雨の日の昼のノクティアにも渡せる。そのときは、段階のイベントは起きず、日常の会話へ進む（いまの決まりのまま）。
- 結果のカードには、ほかの上がり方の行に「+10（好物）」を足す（例：「ノクティアの好感度 +5（会えた分）＋8（心が近づいた）＋4 ＋10（好物）」）。
- 好物がだぶるとき（2026-10-17 決定。`../plan.md`「好物がだぶるとき」）：好物、またはその途中の物（大豆の種・大豆）を持っている間と、その人に渡したあとは、その好物が出る結果を、探索のめずらしい結果でも、戦闘のめずらしい報酬でも出さず、別の報酬にする（くわしくは `explore_cards.md` 冒頭の「好物がだぶるとき」）。
  - 好物は、同じものを2つ持つことがない。渡したあとに、もう一度手に入ることもない。
  - 油揚げは1つだけ。大豆の種を一度畑に植えたら、そのあとは大豆の種が出ないので、2つ目の油揚げはできない。
  - イグニアの魚はふつうの素材なので、この決まりに入れない（渡せるのは1回だけ。上の決まりのまま）。
- 〈呼び方〉は、段階4の前と後で変える（`explore_cards.md` の表と同じ。ノクティア：坊や → ユウ、カバネ：アンタ → ユウっち、ハクレン：貴殿 → ユウ、イグニア：人の子 → ユウ。コノハは、はじめから「ユウ」）。

## 1. 好物を渡す短い文

### ノクティア：赤い果実（`f.gift_red_fruit` → `f.gave_red_fruit`）

ノクティア「あら……赤い実。わたくしの好きなもの、覚えていたの？」

ノクティアは、実をひと口かじって、目を細めた。

ノクティア「……ふふ。甘いわね。ありがとう、〈呼び方〉」

【結果のカード】ノクティアの好感度 +10（好物）

### コノハ：油揚げ（`f.gift_fried_tofu` → `f.gave_fried_tofu`）

コノハ「これ……油揚げ！？　ほんとに、ほんとの油揚げ！？」

コノハは、両手で油揚げを持ったまま、しっぽを全部ぶんぶん振った。

【分岐：段階2で油揚げを約束したか（`f.promise_tofu`）】

- 約束したとき：コノハ「約束、守ってくれた！　……ゆびきり、したもんね」
- 約束していないとき：コノハ「ユウ、すごい！　この島で、また食べられるなんて！」

【結果のカード】コノハの好感度 +10（好物）

（`f.gave_fried_tofu` は、コノハの段階5（`events/konoha_4-5.md`）とエンド（`endings/konoha.md`）の台詞の分かれにも使う）

### カバネ：虹色の貝殻（`f.gift_rainbow_shell` → `f.gave_rainbow_shell`）

カバネ「は？　なにこれ、虹色じゃん。……かわいすぎて、ウケる」

カバネは、貝殻を光にかざして、しばらく黙って見ていた。

カバネ「……もらっとく。返せって言っても、返さないし」

【結果のカード】カバネの好感度 +10（好物）

### ハクレン：山頂の白い花（`f.gift_white_flower` → `f.gave_white_flower`）

ハクレン「山頂の花か。……わざわざ、登ったのか」

ハクレンは、花を髪にさそうとして、手を止めた。それから、胸元にそっとしまった。

ハクレン「べ、別に、うれしいわけではない。……枯らさないように、するだけだ」

【結果のカード】ハクレンの好感度 +10（好物）

### イグニア：焼き魚（`f.item_fish` −1 → `f.gave_fish`）

イグニア「……魚。……くれるの？」

イグニアが小さく息を吐くと、魚が、こんがりと焼けた。

イグニア「……おいしい。……〈呼び方〉にもらうと、もっと、おいしい」

【結果のカード】イグニアの好感度 +10（好物）

- 岩場の出会い（`explore_cards.md` の岩-E1）で「魚をあげる」を選んだときも、好物を渡した1回に数える（`f.gave_fish` ＝ 1）。そのあとは［好物を渡して過ごす］を出さない。

## 2. 油揚げの朝（コノハの好物）

行動を使わない。朝の初め（行動を選ぶ前）に、短い文と結果のカードを出す（`../design/life-bond.md` 1-2）。

### 大豆の種を植えた朝

（畑があって、大豆の種を持っているとき。`f.item_soy_seed` −1、`f.soy_plant_day` ＝ その日）

畑の隅に、大豆の種を植えた。土をかぶせていると、コノハがのぞきこんできた。

コノハ「なに植えたの？　ねえ、なに？」

（……まだ、内緒にしておこう）

【結果のカード】大豆の種 −1（3日後の朝に、大豆がとれる）

### 大豆がとれた朝（かまどがないとき）

（植えてから3日後の朝。`f.item_soy` +1）

畑の大豆が、さやごと、ぷっくりふくらんでいた。

（これで豆腐が作れる。……あとは、揚げる火があれば）

【結果のカード】大豆 ×1（かまどを建てると、油揚げになる）
【次にやること：かまどを建てると、大豆で油揚げが作れる】

### 油揚げができた朝

（大豆があって、かまどがあるとき。大豆がとれた朝にかまどがあれば、上の「大豆がとれた朝」の代わりに、この文だけを出す。かまどをあとで建てたときは、建てた次の朝に出す。`f.item_soy` −1、`f.gift_fried_tofu` ＝ 1）

大豆をすりつぶして豆腐にし、かまどの火で揚げた。じゅわっと、いい音がする。

畑の大豆で、油揚げを作った。……コノハのしっぽが、遠くからでも見えた気がした。

【結果のカード】油揚げ ×1（コノハの好物。二人きりで過ごすときに渡せる）

## この台本で使う変数

| 変数 | 使い方 |
|---|---|
| `f.gift_red_fruit`、`f.gift_rainbow_shell`、`f.gift_white_flower`、`f.gift_fried_tofu` | 持っている好物（0か1）。渡したら0 |
| `f.item_fish` | イグニアに渡すと −1 |
| `f.gave_red_fruit`、`f.gave_rainbow_shell`、`f.gave_white_flower`、`f.gave_fish`、`f.gave_fried_tofu` | 渡したら1。1のときは［好物を渡して過ごす］を出さない |
| `f.promise_tofu` | コノハに渡すときの台詞の分かれ（`events/konoha_1-3.md` の段階2） |
| `f.ev_<名前>` | 4 以上なら、〈呼び方〉を段階4のあとのものにする |
| `f.item_soy_seed`、`f.item_soy` | 大豆の種・大豆 |
| `f.soy_plant_day` | 大豆を植えた日（0は植えていない。名前は案）。0でなければ、探索・戦闘で大豆の種を出さない（`explore_cards.md`） |
| `f.built_field`、`f.built_stove` | 畑・かまど。植える・油揚げを作る条件 |

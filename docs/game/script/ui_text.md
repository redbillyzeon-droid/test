作成：2026-10-17　／　更新：2026-10-17（確認役のレビューの指摘：K2・K4 の文、ヒントに H9 と「二人きりで過ごすと」。8章：好物・一緒に建てる・探索マップ、ヒントの8・9。2回目のレビューのあと：「ゆかり」の札、「誰と直す？」、「一人で建てる」の表記、好物つきの印を「いま会える」の顔にも）　／　状態：初稿

- 1行の文（右上の「次にやること」の欄に出るもの）は、全角30字前後まで。入るかどうかは、画面の試作で確かめる。
- `{ }` は、プログラムが入れる値。〈名前〉はヒロインの名前、「ユウ」はプレイヤーが決めた名前に置きかえる。
- 「真エンド」という言葉は使わない（2026-10-17 の決定）。
- 好感度と心（`f.mind`）の数字は出さない（2026-10-17 の決定）。

## 3. 締め切りの警告（K1〜K4・H9）

### 3-1. 右上の1行（「次にやること」の欄）

| 記号 | 文 | 字数 |

- K2 の〈名前〉は、余り（R(名前) − n(名前)）がいちばん大きい人。同じときは、状態画面の並び順（ノクティア → コノハ → カバネ → ハクレン → イグニア）で先の人（案）。
- K2 の「会おう」は、いまの時間帯に〈名前〉に会えないときも同じ文にする（会える時間帯は状態画面で分かるため）。
- H9 は 9日目の朝だけ、1回だけ（`f.hint_day9_shown`）。

### 3-2. 1日のまとめの警告

まとめの「警告」の欄に出す。2行まで（K4 は、きつい人の行を足す）。

**K1**

```
もう、決戦までに誰とも心を通わせられない。
このままでは、決戦の相棒は迷ったまま、幻に負ける。
やり直すなら、手動セーブか、今朝の自動セーブから。
```

- 3行目は、自動セーブ「毎朝」が今朝の1つしかないため（`../design/screens.md` 4-1）。

**K2**

```
まだ、誰とも心が通っていない。
決戦の相棒になれるのは、心が通った人だけ。
会える時間帯に、二人きりで会いに行こう。〈名前〉なら、急げばまだ間に合うかもしれない。
```

- 〈名前〉は 3-1 と同じ人。
- 「かもしれない」にしたのは、式が成り立っても間の会話が足りずに届かないことがあるため（`../design/screens.md` 3-3 の (d)）。

**K3**（まとめに1回だけ。`f.warn_all_lost = 1` にする）

```
5人全員と心を通わせるのは、もう間に合わない見込み。
一人でも心が通えば、その人が決戦の相棒になれる。
```

- c4 ＝ 0 で K1・K2 も出ているときは、K1・K2 を上に出す。

**K4**（まだ会う必要がある人がいて、その時間帯の余りが0のときだけ）

```
全員と心を通わせるなら、もう寄り道はできない。
{きつい人の行}
```

{きつい人の行} は、余りが0の式だけ。2つ以上あるときは、式の番号の小さい順に2つまで：

| 式 | 文 |
|---|---|
| (1) | 朝の残り{R朝}回は、全部ハクレンと過ごす |
| (2) | 夜の残り{R夜}回は、全部ノクティアと過ごす |
| (3) | 朝と昼の残り{R}回は、全部ハクレンかコノハと過ごす |
| (4) | 昼と夜の残り{R}回は、全部ノクティアかイグニアと過ごす |
| (5) | 朝と夜の残り{R}回は、全部ハクレンかノクティアと過ごす |
| (6) | 残り{R}回は、全部まだ心が通っていない人と過ごす |

- 「過ごす」は、二人きりで過ごすことと、ハクレンとの稽古（2章の回数と同じ数え方）。
- 式の左辺の人がもう段階4以上（n ＝ 0）のときは、その人の名前を出さない（例：(3) でハクレンが段階4なら「全部コノハと過ごす」）。
- 状態画面（2章）のきつい人の行は、余りが1以下で出す、いまの文のまま。

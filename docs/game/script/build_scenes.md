# 台本：一緒に建てる（ゆかりの人の短い場面）

作成：2026-10-17　／　状態：初稿

書き方の決まりは `00_prologue_day1.md` と同じ。決まり（数字・条件）は `../design/life-bond.md` 2章（2026-10-17 決定。`../plan.md` の「一緒に建てる」）。

## 出し方の決まり

- 建てるとき、「誰と建てる？」の画面で、その時間帯に会える人から2人まで手伝ってもらえる（0人・1人も選べる）。手伝った人は好感度 +3。
- その施設の「ゆかりの人」が手伝うと、その人は +5。その施設を**初めて建てたとき**だけ、下の短い場面を出す（選択肢なし）。ゆかりの人が手伝わないときは、場面を出さずに結果のカードだけ。
- 段階のイベントは起きない（二人きりではないため）。
- カバネが手伝うと、ユウの力 +1（`../system.md` の「力仕事（カバネと建築）」）。
- 嵐で壊れた作業台を直すときは、2人まで +3。ゆかりの +5 と短い場面はない。画面の題は「誰と直す？」で、「ゆかり」の札は出さない（`ui_text.md` 8-2）。
- 〈呼び方〉は、段階4の前と後で変える（`gifts.md` の決まりと同じ）。

| 施設 | ゆかりの人 | 会える時間帯 | 場面 |
|---|---|---|---|
| 作業台 | カバネ | 朝・昼・夜 | `01_day2_tutorial.md` の「作業台を選んだとき」 |
| かまど | イグニア | 昼・夜 | 下の1 |
| 畑 | コノハ | 朝・昼 | 下の2 |
| 家 | ノクティア | 夜（雨の日は昼も） | 下の3 |
| 見張り台 | ハクレン | 朝 | 下の4 |
| 船着き場 | カバネ | 朝・昼・夜 | 下の5 |

結果のカード（どの施設も同じ形）：

```
〈施設〉を建てた
・{素材} −{数}
・島の発展度が上がった
〈ゆかりの人〉の好感度 +5（一緒に建てた）、〈もう1人〉の好感度 +3
（カバネが手伝ったとき）ユウの力 +1
```

---

## 1. かまど（イグニア）

川の粘土を積み上げて、かまどの形にした。イグニアが、横からのぞきこむ。

イグニア「……ここに、火、入れるの？」

イグニアが小さく息を吐くと、かまどの奥に、ぽっと火がともった。

イグニア「……あったかい。……ここ、昼寝に、よさそう」

## 2. 畑（コノハ）

コノハ「ここ、ボクが耕す！　まかせて！」

コノハは土を掘るのが速すぎて、畝の半分が、ただの穴になった。

コノハ「えへへ……。ねえユウ、ここに何植えるの？　おいしいもの？」

（……何を植えるかは、まだ内緒だ）

## 3. 家（ノクティア）

ノクティア「壁も屋根もあるのね。……奥の部屋には、窓をつけないでくれる？」

ユウ「暗い部屋がいいのか？」

ノクティア「昼に眠れる場所が、洞窟のほかにもあったら……少しだけ、うれしいの」

ノクティアは、まだ木の匂いのする柱に、そっと手をあてた。

## 4. 見張り台（ハクレン）

ハクレンは、組み上がったばかりの見張り台に、いちばんに登った。

ハクレン「……島の端から端まで、見える。守るものが見えるのは、いいものだな」

ハクレン「ここを私の持ち場にする。〈呼び方〉、異論はないな？」

## 5. 船着き場（カバネ）

カバネ「でかいのは、あーしの出番。〈呼び方〉は、そっち押さえてな」

カバネは、太い丸太を一人で抱えて、次々に海へ打ちこんでいった。

カバネ「……ほら、できた。これで、あの船まで行けんじゃん。ウケる、マジで港っぽい」

| `f.ev_<名前>` | 4 以上なら、〈呼び方〉を段階4のあとのものにする |

# 台本：4日目の固定イベント「嵐」

作成：2026-10-16　／　状態：初稿

書き方の決まりは `00_prologue_day1.md` と同じ。

この場面の役目（`docs/game/outline.md`）：

- 建てた施設が壊れて、みんなで建て直す。島づくりの大切さを体で覚える。
- カバネが一瞬だけ、巨大な骸骨の腕を出して、みんなを守る（段階4の「本当の姿」への伏線）。
- コノハは雷が苦手（`characters.md`）。主人公がそばにいるかどうかを選ぶ。

起きる時間：4日目の朝〜昼。この日の朝と昼の行動は、この場面（嵐と建て直し）に置きかわる。夜だけ自由行動。

分岐に使う変数：家を建てたか（`f.built_house`）、作業台を建てたか（`f.built_workbench`）。

---

## 朝：嵐が来る

【日付：4日目・朝】
【天気：嵐】
【背景：浜辺・嵐】
【BGM：なし】
【効果音：強い風、波】

目を覚ますと、洞窟の外が、夜のように暗かった。

風が、島じゅうの木を、根こそぎ引き抜こうとしているみたいだった。

【立ち絵：ハクレン（真剣）】

ハクレン「起きろ、貴殿。嵐だ。拠点が持たない」

【分岐：家を建てているかどうか】

【家を建てていないとき】

拠点に駆けつけると、葉っぱで葺いた屋根が、半分めくれ上がっていた。積んであった木材が、風に転がっていく。

【作業台を建てているときだけ】作業台も、風にあおられてきしんでいる。

カバネ「ちょ、マジ無理！　屋根、押さえて！」

【家を建てているとき】

家は、壁が少しきしむだけで、ちゃんと立っていた。ただ、外で乾かしていた木材が、風にさらわれかけている。

カバネ「家は平気！　外の荷物、中に入れて！」

【合流】

【効果音：雷】

そのとき、すぐ近くに雷が落ちた。耳が、しびれるほどの音だった。

【立ち絵：コノハ（悲しみ）】

コノハ「ひゃっ……！」

コノハが、両耳を押さえて、その場にしゃがみこんだ。しっぽが、体に巻きついている。

▼選択
- 「コノハ、こっちだ」とそばに行く → コノハ +5、`f.storm_choice = 1`
- 「カバネ、手伝う！」と屋根を押さえに行く → カバネ +5、`f.storm_choice = 2`

【コノハのそばに行ったとき】

ユウ「コノハ。大丈夫、ここにいる」

コノハの肩に手を置くと、小さな体が震えていた。

コノハ「……ご、ごめんね。ボク、雷だけは、だめなの。社にいたころから、ずっと」

ユウ「謝らなくていい。こわいものは、こわいでいい」

コノハ「……うん」

コノハが、俺の服のすそを、ぎゅっとつかんだ。

【カバネを手伝いに行ったとき】

屋根の端に飛びついて、体重をかける。腕が、風に持っていかれそうになる。

カバネ「アンタ、軽すぎ！　もっと腰落として！」

ユウ「こうか！」

カバネ「……そ。やるじゃん」

【合流】

### カバネの腕

【効果音：めきめきと木が裂ける音】

拠点のすぐ横の大木が、根元から裂けた。

太い幹が、こっちに倒れてくる。コノハが、その真下にいた。

（間に合わない――）

【画面：白く光る】
【効果音：骨がきしむ音】

次の瞬間、俺たちの頭の上に、巨大な白い腕が伸びていた。

人の背丈より太い、骨だけでできた腕。それが、倒れてきた大木を、受け止めていた。

腕は、カバネの肩から生えていた。

【立ち絵：カバネ（驚き）】

カバネ「……っ」

腕は、ひと呼吸のあいだに、消えた。大木は、拠点の横に、どさりと転がった。

カバネは、自分の肩を押さえて、こっちを見なかった。

カバネ「……今の、見んなし」

ユウ「カバネ、今のは――」

カバネ「見んなって言ってんの！」

【立ち絵：カバネ（不機嫌）】

カバネは、雨の中に走っていった。

【立ち絵：ハクレン（真剣）】

ハクレン「……追うな。今は、あれの好きにさせてやれ」

## 嵐のあと

【日付：4日目・昼】
【背景：浜辺・昼】
【天気：晴れ】
【BGM：明るい日常の曲（静かな版）】

昼前には、嘘のように空が晴れた。

拠点は、ひどいありさまだった。

【分岐：家を建てているかどうか】

【家を建てていないとき】

【結果のカード】
嵐で、拠点が壊れた
・木材 −3
・食料 −2
・【作業台を建てているときだけ】作業台が壊れた（木材2で直せる）

【家を建てているとき】

【結果のカード】
嵐で、外の荷物が少し流された
・木材 −1
家のおかげで、被害は少なかった

【合流】

【立ち絵：コノハ（笑顔）、ハクレン（普通）】

コノハ「……みんなで、直そ！　ボク、木、いっぱい集めてくる！」

ハクレン「私は、石を運ぶ。……カバネは」

【立ち絵：イグニア（ぼんやり）】

イグニア「……ぬれた木、かわかす。……ふぅ」

イグニアが息を吐くと、濡れた木材から、白い湯気が上がった。

（ノクティアさんは、晴れた昼は外に出られない。……あとで、様子を見に行こう）

浜の端に、カバネが一人で座っていた。こっちに背を向けて、黙って、壊れた屋根の葉を編み直していた。

（あとで、ちゃんと話そう）

【画面表示：建て直しで、4人の好感度が少しずつ上がった】

→ コノハ +2、カバネ +2、ハクレン +2、イグニア +2

【次にやること：壊れたものは「建てる・作る」で直せる】

（夜は、自由行動）

## 夜（追加の場面）：カバネと話す

条件：この日の夜に「カバネと過ごす」を選んだとき。選ばなかったときは、この場面は5日目以降の最初の「カバネと過ごす」で起きる。そのときは、日付と背景をその日の時間帯に合わせる（台詞はそのまま使える）。

【日付：4日目・夜】
【背景：拠点・夜】
【立ち絵：カバネ（普通）】

カバネは、焚き火の前で、ひざを抱えていた。

カバネ「……アンタさ。嵐のときの、気持ち悪くなかったん」

▼選択
- 「助けてくれて、ありがとう」 → カバネ +5
- 「ちょっと、驚いた。でも、気持ち悪くはない」 → カバネ +3

【選択1のとき】

カバネ「…………は？」

カバネは、ぽかんと口を開けた。

カバネ「……そこ？　ウケる。……ほんと、ウケる」

カバネは、顔をひざにうずめた。笑っているのか、泣いているのか、分からなかった。

【選択2のとき】

カバネ「……ふーん。驚いたは、驚いたんだ」

カバネ「ま、正直なのは、悪くないし」

【合流】

カバネ「……あれ、あーしの、本当のやつ。全部出すと、もっとでかい」

カバネ「人間はさ、だいたい、あれ見ると逃げるんだよね。前の世界でも、そうだった」

【分岐：1日目に「骨だよな？」と言ったか（`f.kabane_bone`）】

【言ったとき】

カバネ「アンタ、最初に会ったとき、骨って言ったよね。……あれ、けっこう刺さったんだから」

ユウ「……ごめん」

カバネ「いーよ、もう。……今日、逃げなかったし」

【言わなかったとき】

カバネ「アンタは、最初から、あーしのこと、ちゃんと『カバネ』って呼んだよね。……ちょっとだけ、うれしかった」

【合流】

カバネは、焚き火に枝を一本放りこんで、立ち上がった。

カバネ「……寝る。おやすみ、アンタ」

## この台本で決まる変数

| 変数 | 変化 |
|---|---|
| `f.weather` | 朝は「嵐」、昼から「晴れ」 |
| `f.storm_choice` | 雷のときの選択（1＝コノハのそばに行った、2＝カバネを手伝った）。日常の会話（`daily/konoha.md` の B3）で使う |
| `f.aff_konoha` | そばに行くと +5。建て直しで +2 |
| `f.aff_kabane` | 手伝うと +5。建て直しで +2。夜の会話で +5 または +3 |
| `f.aff_hakuren` / `f.aff_ignia` | 建て直しで +2 |
| `f.item_wood` / `f.item_food`（食料。魚・果実などとは別に数える、ごはん1回分の単位） | 家がないとき −3 / −2。家があるとき木材 −1 |
| `f.workbench_broken` | 家がなく、作業台を建てていたとき 1（木材2で直すと 0） |
| `f.kabane_arm_seen` | 1（参考の記録。嵐は固定イベントなので、段階3以降では必ず 1。分岐には使っていない） |
| `f.storm_talk_done` | カバネの夜の会話をすると 1 |

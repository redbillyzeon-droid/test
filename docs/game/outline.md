# シナリオの骨組み

作成：2026-10-05　／　状態：案。キャラクターは `characters.md`、全体の方針は `plan.md`。

成人向けの場面は、この文書では位置だけを「［成人向け］」で示します。中身は台本を書く段階で作ります。

## 全体の流れ

| 日 | 内容 |
|---|---|
| プロローグ | 主人公は、恋人の浮気を目撃したショックで死ぬ。神の声はなく、気づくと島の浜辺にいる。コノハに見つけられる |
| 1日目 | 5人と出会う（コノハ → カバネ → ハクレン → イグニア、夜にノクティア）。洞窟で寝る |
| 2〜12日目 | 島の暮らし。朝・昼・夜に行動を1つずつ選ぶ（下の「行動」） |
| 4日目 | 固定イベント：嵐。拠点が壊れ、みんなで建て直す（建築の大切さを知る） |
| 8日目 | 固定イベント：浜に壊れた船の破片。イグニアが「また誰か来る」とつぶやく |
| 12日目の夜 | 固定イベント：宴。5人とそろって話す最後の夜 |
| 13日目 | 黒瀬カイが漂着する。カイは5人を見て「全部もらう」と宣言する。夜に分岐（NTRルート） |
| 14日目 | 決戦 |
| エピローグ | 結末に応じたエンド |

## 島の暮らし（2〜12日目）

### 時間帯ごとに会えるヒロイン

| 時間帯 | 会えるヒロイン |
|---|---|
| 朝 | コノハ、ハクレン、カバネ |
| 昼 | コノハ、カバネ、イグニア（雨の日はノクティアも） |
| 夜 | ノクティア、イグニア、カバネ |

### 行動

| 行動 | 効果 |
|---|---|
| ヒロインと過ごす | そのヒロインの好感度が上がる。一定の値で個別イベントが進む |
| 採集・釣り・狩り | 食料が増える。一緒に行ったヒロインの好感度も少し上がる |
| 建築 | 島の発展度が上がる（拠点 → 家 → 見張り台 → 船着き場）。決戦の守りが強くなる |
| 稽古（ハクレン） | 主人公の戦う力が上がる |
| 料理 | 食料を使って好物を作る。渡すと好感度が大きく上がる |

食料が足りない日が続くと、次の日の行動が1回減ります。

### 好感度と個別イベント

好感度は 0〜100。段階ごとに個別イベントが1つずつ進みます。

| 段階 | 好感度 | 内容 |
|---|---|---|
| 1 | 10 | 打ち解ける。呼び方が変わる前の、ちょっとした会話 |
| 2 | 30 | そのヒロインの日常に入る（コノハと釣り、カバネと料理など） |
| 3 | 50 | 過去を打ち明ける（`characters.md` の「過去」） |
| 4 | 70 | 物語の軸の山場。悩みに主人公が答える。呼び方が変わる。［成人向け］ |
| 5 | 90 | 結ばれる。［成人向け］ |

段階4に達すると、そのヒロインはカイの魅了にかからなくなります。

#### 段階3・4の内容（案）

| ヒロイン | 段階3：打ち明けること | 段階4：主人公の答え |
|---|---|---|
| ノクティア | 愛した人間を何度も見送ったこと | 夜明けを一緒に見る。「先にいなくなるとしても、それまでの時間は全部あげる」 |
| コノハ | 社を追い出されたこと | 「役に立たなくても、ここにいていい」。しっぽが4本になる |
| カバネ | 自分が骨から生まれた妖怪であること | 巨大な骸骨の姿を見ても逃げない。「でかくてかっこいい」 |
| ハクレン | 守る国がなくなったこと | 「俺とこの島を守ってほしい」。ハクレンが、守るものを選び直す |
| イグニア | 島は自分が作った場所で、みんなを呼んだのは自分だということ | 「呼んでくれてありがとう」 |

## 13日目：黒瀬カイの来訪と分岐

1. 朝：カイが漂着する。主人公と同じ転生者だと分かる。
2. 昼：カイが魅了の力を見せる。好感度が段階4に届いていないヒロインが、少しのあいだ、ぼんやりとカイを見つめる。
3. 夕方：カイは「明日、全部もらいに来る」と言って森に消える。
4. 夜：作戦会議。コノハが「ボクが一人で様子を見てくる！」と言い出す。

| 選択 | 結果 |
|---|---|
| 「一人で行かせる」 | **NTRルート**へ |
| 「だめだ、みんなで動こう」 | 通常ルート。14日目の決戦へ |

### NTRルート（コノハ）

- コノハは偵察に出たまま戻らない。
- 翌朝、コノハはカイの隣に立っている。しっぽの数は1本に戻っている。
- コノハはカイの側について、主人公たちの前に立つ。
- 決戦は起きず、残りの4人はコノハを人質に取られて手が出せない。
- ［成人向け］（コノハとカイの場面。位置だけを決めておき、台本の段階で作る）
- 結末：主人公は島の外れの洞窟で、ひとりで夜明けを迎える。**NTRエンド**。

## 14日目：決戦

コマンド式のバトルです。主人公は3回の行動で、カイの「支配の力」（HPのようなもの）を0にすれば勝ちです。

### 主人公の行動

| コマンド | 内容 |
|---|---|
| 呼びかける | ヒロインを1人選んで支援を頼む。そのヒロインの技が出る |
| 耐える | カイの攻撃を受け流す。稽古の回数が多いほど効く |
| 言葉をぶつける | カイの心に届く言葉を選ぶ。正しい言葉なら大きく効く（12日間の出来事がヒントになる） |

### ヒロインの技（好感度で強さが変わる）

| ヒロイン | 技 |
|---|---|
| ノクティア | 夜の帳：カイの魅了を1回打ち消す |
| コノハ | 狐火：小さく、何度も効く |
| カバネ | 本当の姿：巨大な骸骨で守る。段階4以上でないと出ない |
| ハクレン | 西方の守り：主人公への攻撃を防ぐ |
| イグニア | 竜の息吹：段階4以上で、最後の1回だけ使える大技 |

### カイの行動

- 毎ターン、好感度が段階4に届いていないヒロインに魅了をかける。かかったヒロインはその後、支援しない。
- 島の発展度が低いと、カイの攻撃が拠点に届き、主人公の行動が1回減る。

### 勝ち負けの目安

- 勝つには、段階4以上のヒロインが2人以上いて、島の発展度が「見張り台」以上であることが目安。
- 数字は台本とあわせて、試しに遊んで調整する（いまは目安で、確かめていない）。

## 制作の進め方（案）

1. この骨組みを利用者が確認する。
2. プロローグ〜1日目の台本を書く（文章のみ）。利用者が読んで、文体と雰囲気を確かめる。
3. 好感度・食料・発展度の変数と、日にちの進め方を `.ks` ファイルで作る。
4. 台本を順に `.ks` にしていく。PC のティラノビルダーで取り込んで、遊んで確かめる。
5. 決戦の数字を、遊びながら調整する。

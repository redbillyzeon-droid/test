# シナリオの骨組み

作成：2026-10-05　／　更新：2026-10-05（GM との対決の流れに変更）　／　状態：案。キャラクターは `characters.md`、全体の方針は `plan.md`。

成人向けの場面は、この文書では位置だけを「［成人向け］」で示します。中身は台本を書く段階で作ります。

## 物語の芯

- 島に集められたのは、全員「大きなものを失った者」。
- ゲームマスター（GM）は「勝てば、失ったものを一つ取り戻せる」と約束する。
- GM の狙いは「失った者は、目の前の絆より、失ったものを選ぶ」と証明すること。
- 主人公は、恋人ミサキに裏切られて死んだ男。GM と同じ傷を持っている。最後に「取り戻す」より「いまある絆」を選べるかが問われる。

## 冒頭のフック（ミサキと先輩）

| 場面 | 内容 | 狙い |
|---|---|---|
| プロローグ | ミサキの誕生日。指輪を持って早く帰ると、ミサキと先輩の浮気を目撃して、ショックで死ぬ | 最初の数分で、プレイヤーを主人公の痛みに引きこむ |
| タイトル表示 | 死の直後にタイトル。続けて、暗闇で GM の声「ようこそ、失った者よ」 | 「これは何の話だ」と思わせる |
| 1日目の夜 | 石碑に GM のルールが浮かぶ。最後の一文は「お前は、あの女を取り戻したいか」 | GM が主人公の過去を知っていると分かる |
| 8日目 | GM の「中間発表」。主人公は、ミサキが一人で主人公の墓の前にいる幻を見せられる。先輩の姿はない | ミサキは本当はどう思っていたのか、という引っかかりを作る |
| 13日目 | GM が姿を現す。GM も婚約者を親友に奪われた男だと分かる | 主人公と GM が「同じ傷を持つ者」だと分かる |
| 14日目（決戦） | GM の最後の手：あの夜のドアの隙間の場面を、もう一度見せる | 主人公が過去と向き合う |
| 真エンド | 勝者の願いで、ミサキを取り戻すことも選べる。主人公はそれを選ばない | プロローグの傷に、答えを出す |
| NTRルート | コノハと GM の場面を、ドアの隙間から見てしまう | プロローグと同じ構図で、傷をもう一度えぐる |

## 全体の流れ

| 日 | 内容 |
|---|---|
| プロローグ | ミサキと先輩の浮気を目撃して死ぬ → タイトル → GM の声 |
| 1日目 | 5人と出会う（コノハ → カバネ → ハクレン → イグニア、夜にノクティア）。夜、浜の石碑に GM のルールが浮かぶ |
| 2〜12日目 | 島の暮らし。朝・昼・夜に行動を1つずつ選ぶ（下の「行動」） |
| 4日目 | 固定イベント：嵐。拠点が壊れ、みんなで建て直す。カバネが一瞬だけ巨大な骸骨の腕を出して、みんなを守る |
| 8日目 | 固定イベント：GM の中間発表。5人それぞれに「失ったもの」の幻が見える。主人公にはミサキの幻。その夜、5人がそれぞれの「失ったもの」を少しずつ打ち明け合う |
| 12日目の夜 | 固定イベント：宴。5人とそろって話す最後の夜。「勝ったら、何を取り戻す？」と誰も聞けない |
| 13日目 | GM（黒瀬カイ）が姿を現す。夜に分岐（NTRルート） |
| 14日目 | 決戦 |
| エピローグ | 結末に応じたエンド |

## 1日目の夜：GM のルール（石碑の文）

> ようこそ、失った者たちの島へ。
> 十四日目の夜明け、私と勝負してもらう。
> 勝てば、失ったものを一つ取り戻せる。
> 負ければ、残っているものも、すべていただく。
> ――ユウ。お前は、あの女を取り戻したいか。

## 島の暮らし（2〜12日目）

### 時間帯ごとに会えるヒロイン

| 時間帯 | 会えるヒロイン |
|---|---|
| 朝 | コノハ、ハクレン、カバネ |
| 昼 | コノハ、カバネ、イグニア（雨の日はノクティアも） |
| 夜 | ノクティア、イグニア、カバネ |

### 行動

| 行動 | 効果 |
|---|---|
| ヒロインと過ごす | そのヒロインの好感度が上がる。一定の値で個別イベントが進む |
| 採集・釣り・狩り | 食料が増える。一緒に行ったヒロインの好感度も少し上がる |
| 建築 | 島の発展度が上がる（拠点 → 家 → 見張り台 → 船着き場）。決戦の守りが強くなる |
| 稽古（ハクレン） | 主人公の戦う力が上がる |
| 料理 | 食料を使って好物を作る。渡すと好感度が大きく上がる |

食料が足りない日が続くと、次の日の行動が1回減ります。

### 好感度と個別イベント

好感度は 0〜100。段階ごとに個別イベントが1つずつ進みます。

| 段階 | 好感度 | 内容 |
|---|---|---|
| 1 | 10 | 打ち解ける。呼び方が変わる前の、ちょっとした会話 |
| 2 | 30 | そのヒロインの日常に入る（コノハと釣り、カバネと料理など） |
| 3 | 50 | 失ったものを打ち明ける（`characters.md` の「失ったもの」） |
| 4 | 70 | 物語の軸の山場。悩みに主人公が答える。呼び方が変わる。［成人向け］ |
| 5 | 90 | 結ばれる。「勝っても、失ったものより、ここを選ぶ」と口にする。［成人向け］ |

段階4に達すると、そのヒロインには GM の「喪失の幻」が効かなくなります。

#### 段階3・4の内容（案）

| ヒロイン | 段階3：失ったものを打ち明ける | 段階4：主人公の答え |
|---|---|---|
| ノクティア | 最後の恋人ルカを見送った夜のこと | 夜明けを一緒に見る。「先にいなくなるとしても、それまでの時間は全部あげる」 |
| コノハ | 社を追い出されて、帰る場所をなくしたこと | 「役に立たなくても、ここにいていい。ここが帰る場所だ」。しっぽが4本になる |
| カバネ | 自分はもと人間で、名前をなくしたこと | 巨大な骸骨の姿を見ても逃げない。カバネの本当の名前を一緒に探す |
| ハクレン | 守る国と、信じてくれる人々をなくしたこと | 「俺が信じる。俺とこの島を守ってほしい」 |
| イグニア | 一族の最後の一頭で、島を GM に奪われたこと | 「この島を、あなたに返したい」。イグニアが初めて、はっきり目を覚ます |

## 13日目：GM の正体と分岐

1. 朝：浜に、白いコートの男が立っている。仮面を外すと、30歳くらいの人間の男。名前は黒瀬カイ。
2. 昼：カイが自分の過去を話す。婚約者を親友に奪われ、自分から命を絶ったこと。最初にこの島に来て、イグニアから島を奪ったこと。
3. カイ「お前も同じだ、ユウ。明日、お前は仲間より、あの女を選ぶ」
4. カイが「喪失の幻」を見せる。好感度が段階4に届いていないヒロインが、少しのあいだ、自分の失ったものの幻に見とれる。
5. 夕方：カイは「明日の夜明けに」と言って森に消える。
6. 夜：作戦会議。コノハが「ボクがあいつの居場所、見てくる！　役に立ちたいんだ！」と言い出す。

| 選択 | 結果 |
|---|---|
| 「一人で行かせる」 | **NTRルート**へ |
| 「だめだ。役に立たなくても、そばにいてくれ」 | 通常ルート。14日目の決戦へ |

### NTRルート（コノハ）

- コノハは一人で森に入ったまま戻らない。
- 夜更け、主人公はコノハを探して森の奥の小屋にたどり着く。戸が少しだけ開いている。
- 隙間から、コノハとカイの姿が見える。プロローグのドアの隙間と、同じ構図。［成人向け］（位置だけを決めておき、台本の段階で作る）
- コノハは「社に戻れる」という幻に心を奪われている。「ユウ、ごめんね。ボク、帰る場所がほしかったの」
- 主人公の胸が、プロローグと同じように痛む。
- 翌朝、コノハはカイの隣に立っている。しっぽは1本に戻っている。決戦は起きず、残りの4人はコノハを盾にされて手が出せない。
- 結末：カイ「ほら。人は必ず裏切る」。主人公は島の外れで、ひとりで夜明けを迎える。**NTRエンド**。

## 14日目：決戦

コマンド式のバトルです。主人公は、GM の「支配の力」（HPのようなもの）を0にすれば勝ちです。

### 主人公の行動

| コマンド | 内容 |
|---|---|
| 呼びかける | ヒロインを1人選んで支援を頼む。そのヒロインの技が出る |
| 耐える | GM の攻撃を受け流す。稽古の回数が多いほど効く |
| 言葉をぶつける | GM の心に届く言葉を選ぶ。正しい言葉なら大きく効く（12日間の出来事がヒントになる） |

### ヒロインの技（好感度で強さが変わる）

| ヒロイン | 技 |
|---|---|
| ノクティア | 夜の帳：GM の「喪失の幻」を1回打ち消す |
| コノハ | 狐火：小さく、何度も効く |
| カバネ | 本当の姿：巨大な骸骨で守る。段階4以上でないと出ない |
| ハクレン | 西方の守り：主人公への攻撃を防ぐ |
| イグニア | 竜の息吹：段階4以上で、最後の1回だけ使える大技。封印が解けて、竜の姿に戻る |

### GM の行動

- 毎ターン、好感度が段階4に届いていないヒロインに「喪失の幻」を見せる。幻にかかったヒロインは、その後、支援しない（GM の側にはつかない）。
- 島の発展度が低いと、GM の攻撃が拠点に届き、主人公の行動が1回減る。
- 最後の手：主人公に、あの夜のドアの隙間の場面を見せる。選択肢が出る。

| 選択 | 結果 |
|---|---|
| 「……ミサキを、取り戻したい」 | 主人公の心が折れる。決戦に負ける（鬱エンド） |
| 「あの夜は、もう終わったんだ」 | 段階4以上のヒロインが2人以上いれば、反撃できる。足りなければ、言葉だけが空回りして負ける |

### 勝ち負けの目安

- 勝つには、段階4以上のヒロインが2人以上いて、島の発展度が「見張り台」以上であることが目安。
- 数字は台本とあわせて、試しに遊んで調整する（いまは目安で、確かめていない）。

## エンディング

| エンド | 条件 | 内容 |
|---|---|---|
| 真エンド | 決戦に勝つ | GM の支配が崩れる。勝者の願いとして「失ったものを一つ取り戻せる」と告げられる。主人公はミサキを選ばず、「この島をイグニアに返してほしい」と願う。5人も、それぞれの失ったものより島を選ぶ。カイは「……俺は、選べなかったのにな」と言い残して、島を去る。最後の場面は、いちばん好感度の高いヒロインとの後日談（5種類）。［成人向け］ |
| 鬱エンド | 決戦に負ける | 主人公は、ドアの隙間の幻の中に閉じこめられる。何度も、あの夜をくり返す。島では、5人が GM の新しいゲームの駒として、次の「失った者」を待っている |
| NTRエンド | 13日目の夜に「一人で行かせる」 | 上の「NTRルート」のとおり |

### 真エンドの選択肢（案）

勝者の願いで、何を取り戻すかを選ばせます。

| 選択 | 結果 |
|---|---|
| 「この島を、イグニアに返してほしい」 | 真エンド |
| 「ミサキと、やり直したい」 | 特別エンド「やり直しの朝」（案）：主人公はあの夜の朝に戻る。ミサキの誕生日の朝。主人公が何を選ぶかは描かずに終わる。島の5人のことは、もう覚えていない |

「やり直しの朝」を入れるかどうかは、利用者の判断を待つ（エンドが1つ増える）。

## 制作の進め方（案）

1. この骨組みを利用者が確認する。
2. プロローグ〜1日目の台本を直す（GM の声と石碑のルールを入れる）。
3. 好感度・食料・発展度の変数と、日にちの進め方を `.ks` ファイルで作る。
4. 台本を順に `.ks` にしていく。PC のティラノビルダーで取り込んで、遊んで確かめる。
5. 決戦の数字を、遊びながら調整する。

# シナリオの骨組み

作成：2026-10-05　／　更新：2026-10-05（GM との対決の流れに変更）　／　状態：案。キャラクターは `characters.md`、全体の方針は `plan.md`。

成人向けの場面は、この文書では位置だけを「［成人向け］」で示します。中身は台本を書く段階で作ります。

発売時の成人向け場面は**12**：段階5（5人分）、個別エンド（5）、真エンド（1）、NTRエンド（コノハ、1）。段階4は成人向けにしない（2026-10-07、利用者の判断）。

## 物語の芯

- 島に集められたのは、全員「大きなものを失った者」。
- ゲームマスター（GM）は「勝てば、失ったものを一つ取り戻せる」と約束する。
- GM の狙いは「失った者は、目の前の絆より、失ったものを選ぶ」と証明すること。
- 主人公は、恋人ミサキに裏切られて死んだ男。GM と同じ傷を持っている。最後に「取り戻す」より「いまある絆」を選べるかが問われる。

## 冒頭のフック（ミサキと先輩）

| 場面 | 内容 | 狙い |

| プロローグ | ミサキの誕生日。指輪を持って早く帰ると、ミサキと先輩の浮気を目撃して、ショックで死ぬ | 最初の数分で、プレイヤーを主人公の痛みに引きこむ |
| タイトル表示 | 死の直後にタイトル。続けて、暗闇で GM の声「ようこそ、失った者よ」 | 「これは何の話だ」と思わせる |
| 1日目の夜 | 石碑に GM のルールが浮かぶ。最後の一文は「お前は、あの女を取り戻したいか」 | GM が主人公の過去を知っていると分かる |
| 8日目 | GM の「中間発表」。主人公は、ミサキが一人で主人公の墓の前にいる幻を見せられる。先輩の姿はない | ミサキは本当はどう思っていたのか、という引っかかりを作る |
| 13日目 | GM が姿を現す。GM も婚約者を親友に奪われた男だと分かる | 主人公と GM が「同じ傷を持つ者」だと分かる |

| NTRエンド | 決戦に負けたあと、相棒と GM の場面を、ドアの隙間から見てしまう | プロローグと同じ構図で、傷をもう一度えぐる |

## 1日目の夜：GM のルール（石碑の文）

> ようこそ、失った者たちの島へ。
> 十四日目の夜明け、私と勝負してもらう。
> 勝てば、失ったものを一つ取り戻せる。
> 負ければ、残っているものも、すべていただく。
> ――ユウ。お前は、あの女を取り戻したいか。

### 好感度と個別イベント

好感度は 0〜100。段階ごとに個別イベントが1つずつ進みます。

| 段階 | 好感度 | 内容 |
|---|---|---|
| 1 | 10 | 打ち解ける。呼び方が変わる前の、ちょっとした会話 |
| 2 | 30 | そのヒロインの日常に入る（コノハと釣り、カバネと料理など） |
| 3 | 50 | 失ったものを打ち明ける（`characters.md` の「失ったもの」） |
| 4 | 70 | 物語の軸の山場。悩みに主人公が答える。呼び方が変わる。成人向けにはしない（心が通う場面にする） |
| 5 | 90 | 結ばれる。「勝っても、失ったものより、ここを選ぶ」と口にする。［成人向け］ |

段階が高いほど、GM の「喪失の幻」に強くなります。決戦では、段階5なら幻をはっきり断り、段階4なら迷い、段階3以下なら負けます（下の「14日目：決戦」）。

## 13日目：GM の正体と分岐

1. 朝：浜に、白いコートの男が立っている。仮面を外すと、30歳くらいの人間の男。名前は黒瀬カイ。
2. 昼：カイが自分の過去を話す。婚約者を親友に奪われ、自分から命を絶ったこと。何十年も前にこの島に転生し、先に住んでいたイグニアから島を奪ったこと。
3. カイ「お前も同じだ、ユウ。明日、お前は仲間より、あの女を選ぶ」
4. カイが「喪失の幻」を見せる。好感度が段階4に届いていないヒロインが、少しのあいだ、自分の失ったものの幻に見とれる。
5. 夕方：カイは「明日の夜明けに」と言って森に消える。
6. 夜：作戦会議。5人がそろって、明日の戦い方を話し合う。誰も「勝ったら何を取り戻すか」を口にしない。

## 13日目の深夜：相棒を決める

更新：2026-10-05（利用者の案「好感度の高いヒロインと GM に挑む構図」を採用）

作戦会議のあと、眠れずに浜へ出ると、ヒロインが会いに来る。来るのは、いちばん好感度の高いヒロイン。

| 状況 | 流れ |
|---|---|
| 段階4以上のヒロインが1人 | そのヒロインが来る。「明日は、わたしが隣に立つ」。そのまま相棒になる |
| 段階4以上のヒロインが2人以上 | その全員が、一人ずつ浜に来る。プレイヤーが、誰と戦うかを選ぶ |
| 5人全員が段階4以上 | 5人がそろって浜に来る。「一人で行かせるわけないでしょ」。選択肢に「みんなで行こう」が加わる（真エンドへ） |
| 段階4以上が誰もいない | いちばん好感度の高いヒロインが来る。ただし、迷いを抱えたまま（決戦で幻に負ける危険がある） |

好感度が同じときは、あとで決める順番（案：イグニア → ノクティア → ハクレン → カバネ → コノハ）で選ぶ。

相棒が決まった夜、そのヒロインとの会話で、彼女の「失ったもの」とGMの誘いをもう一度確かめ合う（成人向けにはしない）。

## 14日目：決戦

相棒のヒロインと二人で、GM に挑みます。ほかの4人は、島の発展度に応じて後ろから支える（拠点を守る、道を開くなど）役になります。

### 決戦の流れ

1. **前半：力の勝負**。コマンド式のバトル。主人公と相棒で、GM の「支配の力」（HPのようなもの）を削る。
2. **中盤：相棒への誘い**。GM が相棒に「失ったもの」の幻を見せる（ノクティアにはルカ、コノハには社、など）。相棒の好感度で結果が決まる。
3. **後半：主人公への誘い**。GM が主人公に、ミサキと先輩のあの夜を見せる。相棒が隣にいることで、主人公は幻を振り切れるかが問われる。
4. **決着**：相棒の大技で GM を倒す。

### 主人公と相棒の行動

| コマンド | 内容 |
|---|---|
| 相棒に頼む | 相棒の技を出す（下の表） |
| 耐える | GM の攻撃を受け流す。稽古の回数が多いほど効く |
| 言葉をかける | 相棒、または GM に言葉をかける。12日間の出来事を覚えていれば、正しい言葉を選べる |

### 相棒の技

| 相棒 | 通常の技 | 大技（段階4以上） |
|---|---|---|
| ノクティア | 夜の帳：GM の攻撃を1回打ち消す | 紅の契り：主人公の血を受けて、真の力を出す |
| コノハ | 狐火：小さく、何度も効く | 五尾の狐火：しっぽの数だけ、強くなる |
| カバネ | 骨の盾：攻撃を防ぐ | 本当の姿：巨大な骸骨になって、GM を押しつぶす |
| ハクレン | 西方の守り：主人公への攻撃を防ぐ | 白虎の牙：守るものがいるときだけ使える、一撃必殺 |
| イグニア | 小さな火：少しずつ削る | 竜の息吹：封印が解けて、竜の姿に戻る |

### 中盤：相棒への誘い（勝ち負けの分かれ目）

| 相棒の好感度 | 結果 |
|---|---|
| 段階5 | 相棒は幻をはっきり断る。「わたしが選ぶのは、こっち」。大技が強くなる |
| 段階4 | 相棒は迷う。主人公が「言葉をかける」で正しい言葉を選べば、幻を振り切る。まちがえると、相棒は幻に負ける（「負け方とエンド」へ） |
| 段階3以下 | 相棒は幻に負ける。GM の側に立ち、主人公は一人になる（「負け方とエンド」へ） |

### 後半：主人公への誘い

GM が、あの夜のドアの隙間を見せる。

| 選択 | 結果 |
|---|---|
| 「……ミサキを、取り戻したい」 | 主人公の心が折れる。決戦に負ける（鬱エンド） |
| 相棒の名前を呼ぶ | 相棒が手を握る。幻が消え、決着へ |

### 負け方とエンド

| 負け方 | エンド | 意味 |
|---|---|---|
| 相棒が幻に負ける（中盤） | コノハなら NTR エンド。ほかの相棒は、発売時は鬱エンド（アップデートでそれぞれの NTR エンドを追加） | 絆が足りず、相棒を奪われる |
| 主人公が「ミサキを取り戻したい」を選ぶ（後半） | 鬱エンド | 主人公自身が過去に負ける |

### 全員で挑む場合（真エンドのルート）

5人全員が段階4以上で「みんなで行こう」を選んだときだけ。5人それぞれの大技を順に使える。GM は5人に同時に誘いをかけるが、誰も揺れない。このルートで負けるのは、主人公がミサキを選んだときだけ（鬱エンド）。

### 勝ち負けの目安

- 相棒が段階5なら、ほぼ勝てる。段階4なら、言葉の選び方と島の発展度しだい。段階3以下なら負ける。
- 数字は台本とあわせて、試しに遊んで調整する（いまは目安で、確かめていない）。

### NTR エンド（相棒ごと）

更新：2026-10-06（利用者の案「NTR エンドは個別エンドの派生で、相棒と挑んで負けた展開」を採用）

**共通の流れ**

1. 決戦の中盤、相棒が「失ったもの」の幻に負ける。相棒はぼんやりと GM の隣に歩いていく。
2. 主人公は GM に倒され、気を失う。
3. 夜、主人公は目を覚まし、相棒を探して GM の館（もとはイグニアの巣）にたどり着く。扉が少しだけ開いている。
4. 隙間から、相棒と GM の姿が見える。プロローグのドアの隙間と、同じ構図。［成人向け］（位置だけを決めておき、台本の段階で作る）
5. 相棒の言葉（下の表）。主人公の胸が、プロローグと同じように痛む。
6. GM「ほら。人は必ず裏切る」。
7. 結末：主人公は島の外れで、ひとりで夜明けを迎える。

**相棒ごとのちがい（案）**

| 相棒 | 負けた幻 | 相棒の言葉（案） | 最後の一枚 |
|---|---|---|---|
| ノクティア | 生き返ったルカ | 「ごめんなさい、坊や。……もう、見送るのは嫌なの」 | ノクティアが、GM の腕の中で夜明けを迎えている |
| コノハ | 一人前として社に戻る自分 | 「ユウ、ごめんね。ボク、帰る場所がほしかったの」 | しっぽが1本に戻ったコノハが、GM の足元で丸くなっている |
| カバネ | 人間に戻った自分 | 「あーし、人間に戻りたかったんだ。……アンタじゃ、それはくれないじゃん」 | タトゥーの消えた腕で、GM にしがみつくカバネ |
| ハクレン | 自分を信じる民と国 | 「私は……守るものが、ほしかった。それが、貴殿でなくても」 | GM の前にひざまずき、槍をささげるハクレン |
| イグニア | 一族の竜たち | 「……ひとりは、もう、さむい」 | 封印がさらに強まり、GM のそばで眠り続けるイグニア |

**発売時に作るのはコノハだけ**（2026-10-06、利用者の判断）。ほかの4人の行は、アップデートで追加するときの案として残しておく。アップデートまでは、コノハ以外の相棒が幻に負けると鬱エンドに進む。

## 制作の進め方（案）

1. この骨組みを利用者が確認する。
2. プロローグ〜1日目の台本を直す（GM の声と石碑のルールを入れる）。
3. 好感度・食料・発展度の変数と、日にちの進め方を `.ks` ファイルで作る。
4. 台本を順に `.ks` にしていく。PC のティラノビルダーで取り込んで、遊んで確かめる。
5. 決戦の数字を、遊びながら調整する。
